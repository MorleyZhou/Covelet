安装

常用网站，就在新标签页。

整理网站，搜索网页，随手记下想法。

Covelet 是 Chrome 和 Edge 的新标签页扩展，无需注册 Covelet 账号。

安装到 Chrome 安装到 Edge

整理常用网站

添加网站，用文件夹和拖拽安排位置。

顺手搜索

搜索网页，也能查找当前浏览器中的网站和便笺。

随手记录

用便笺记录想法，把想读的链接加入稍后读。

调整外观

选择背景、图标大小和布局，按自己的习惯安排桌面。

隐私

数据默认保存在浏览器中

本地加密保存

网站、便笺和设置保存在当前浏览器中，不会上传到 Covelet。

源代码

扩展不收集使用统计

同步、每日壁纸、网页搜索和手动获取网站信息会联网。各项权限的用途可在「隐私自查」查看。

本网站使用 Cloudflare Web Analytics 统计访问情况。 隐私政策

同步

自备存储同步（Beta）

连接自己的存储服务，在多台设备间同步网站、便笺和设置。内容加密后直接发送到你的存储，不经过 Covelet 服务器。

使用自己的存储

支持 WebDAV，可连接坚果云、Nextcloud 等服务。

冲突时，由你选择

出现冲突时，可比较本机和云端版本，再选择保留哪一个。

R2、OSS、GitHub 和 GitLab 也可选，目前均为 Beta。

备份

留一份独立的备份。

把数据导出为文件，保存在浏览器之外。

导出数据备份

备份网站、文件夹、便笺和设置。备份文件未加密，也包含隐藏内容，请妥善保存。

带上已有书签

支持导入浏览器导出的书签 HTML 文件，导入前可预览。

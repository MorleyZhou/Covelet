可验证、不会变质的私人起始页

无账号 · 本地加密 · 数据只在你自己的存储里

Covelet 是 Chrome / Edge 新标签页扩展。导航和便笺用 AES 存在本机。跨设备时，同步到你自备的 WebDAV（坚果云或 Nextcloud）。没有 Covelet 业务服务器，也不中转密文。

Chrome 安装 Edge 安装

无账号

不用注册账号，也不经我们中转 OAuth。

本地 AES

导航与便笺在本机加密；权限和数据位置可在扩展里自查。

自备存储

真云渠道目前是 WebDAV（坚果云 / Nextcloud）。R2、OSS、GitHub、GitLab 等仍为 Beta。我们不说「五家全通」，也不宣称已可靠多设备随便切。

无遥测

无广告、无第三方分析、无使用统计。

隐私

主张怎么核对

本站是静态介绍页，不处理用户数据，不上传导航或便笺，也不挂 PostHog 或统计像素。扩展内可自查权限与数据位置（「隐私体检」随 0.3 提供）。上面这些说法都可以对照产品和本站行为核对。

隐私政策 · support@morley.work

本站不会做

不设登录，不收邮箱，不挂统计像素，不把起始页做成广告位。页面只介绍产品，并链到商店安装。

同步

自备存储，怎么工作

首个真云渠道是 WebDAV（坚果云 / Nextcloud）。其余渠道目前为 Beta。

  1. 01

    选渠道

    优先 WebDAV（坚果云 / Nextcloud）；其余为 Beta。

  2. 02

    最少字段 + 测连

    只填连接所需信息，然后测连。

  3. 03

    设同步密码并首次同步

    其他设备用同一目标和同步密码即可。

保存不等于已验证，以测连成功为准。测连失败可以继续纯本机用，本地数据不受影响。多设备冲突时按整条记录二选一；不会静默合并，你会看清选了哪一份。

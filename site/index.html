可验证、不会变质的私人起始页

无账号 · 本地加密 · 数据只在你自己的存储里

Covelet 是 Chrome / Edge 的新标签页扩展。导航和便笺在本机用 AES 加密保存。跨设备时，同步到你自己的 WebDAV（坚果云或 Nextcloud）。没有 Covelet 业务服务器，也不中转密文。

Chrome 安装 Edge 安装

无账号

不用注册。我们也不中转 OAuth。

本地 AES

导航和便笺在本机加密。权限和数据位置，可在扩展里查看。

自备存储

真云目前是 WebDAV（坚果云 / Nextcloud）。其余仍是 Beta。

无遥测

扩展没有广告，没有第三方分析，没有使用统计。永远不会加 PostHog。

隐私

隐私

这页只介绍产品，不会碰你的导航或便笺。扩展零遥测，不加 PostHog。官网可用无 Cookie 的 Cloudflare Web Analytics 看访问量，只在本站，不进扩展，不关联身份。扩展里可做「隐私自查」，随 0.2.2 提供。

本站不会

这里没有登录，也不收邮箱。起始页不会变成广告位。若有站点统计，只用官网无 Cookie 的 Cloudflare Web Analytics。页面介绍产品，并链到商店安装。

同步

用你自己的存储同步

真云目前是 WebDAV（坚果云 / Nextcloud）。其余仍是 Beta。

  1. 01

    选渠道

    优先 WebDAV（坚果云 / Nextcloud）。其余为 Beta。

  2. 02

    填最少字段，测连接

    只填连接需要的信息，然后测连。

  3. 03

    设同步密码并首次同步

    其他设备用同一目标和同步密码即可。

保存成功不等于已验证，以测连结果为准。测连失败仍可只用本机，本地数据不动。多设备冲突时整条记录二选一，不会悄悄合并。

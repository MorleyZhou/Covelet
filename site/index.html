安装

常用网站，就在新标签页。

整理网站，搜索网页，随手记下想法。

Covelet 是 Chrome 和 Edge 的新标签页扩展。无需 Covelet 账号，数据默认在当前浏览器中加密保存。需要跨设备时，可连接自己的存储服务。

顺手搜索

搜索网页，也能查找当前浏览器中的网站和便笺。

调整外观

隐私

数据保存与联网用途

默认保存在当前浏览器

网站、便笺和设置在当前浏览器中加密保存。无需注册 Covelet 账号，也没有 Covelet 业务服务器接收这些内容。

源代码

联网用途可以查看

扩展不收集使用统计，也不自动上传日志。同步、每日壁纸、搜索和手动获取网站信息等功能会联网；可在「隐私自查」查看权限与用途。

官网可使用 Cloudflare Web Analytics 统计页面访问，与扩展数据分开。详见隐私政策。 隐私政策

同步

自备存储同步（Beta）

需要跨设备时，可连接自己的存储服务。同步内容加密后直接发送到指定存储，不经过 Covelet 服务器。

  1. 01

    连接存储

    推荐 WebDAV，可配置坚果云、Nextcloud 等服务。先准备好保存文件夹和应用密码。

  2. 02

    测试连接

    确认能够读取保存文件夹。测试不会上传内容，也不验证写入或同步密码。

  3. 03

    填写同步密码

    首次使用空目录时设置新密码；其他设备填写相同目录和原来的同步密码，再开始同步。

保存配置不会开始同步。自动同步默认关闭；开启后，仅在 Covelet 页面打开且连接已解锁时运行。

冲突时，由你选择

发生冲突时，先比较版本，再选择采用哪一组完整内容。选择会影响同组的其他修改，请先查看范围。

R2、OSS、GitHub 和 GitLab 也可选，目前均为 Beta。请保留独立备份；同步密码无法找回。

备份

留一份独立的备份。

把数据导出为文件，保存在浏览器之外。需要恢复时，先预览，再选择恢复内容和方式。

导出数据备份

可备份网站、文件夹、外观、便笺、稍后读和桌面方案。备份文件未加密，也包含隐藏的内容，请妥善保存。

带上已有书签

选择浏览器导出的书签 HTML 文件，在本机预览后导入。默认保留已有网址；导入内容会按你的同步设置参与同步。

恢复前会在当前浏览器保留副本。它不能代替独立的备份文件。同步连接凭据、同步密码和隐藏密码不会自动加入备份。

# Covelet

Covelet 是一个浏览器新标签页插件，网站导航、搜索、外观、布局及视觉增强作为免费基础功能。当前开发版无需 Covelet 账号，没有广告和推广链接，无 Covelet 业务服务器。全部本机持久数据统一保存在加密 IndexedDB；扩展提供 GitHub 贡献、世界时钟、便笺、稍后读、标签快照和自选存储的全量加密同步。所有内置扩展业务数据与图片／图标统一同步，浏览器原生同步已停用。账号、收费和部署暂缓，当前未实现购买校验。

网页搜索默认通过 Chrome Search API 交给浏览器当前默认搜索提供商；用户主动选择其他引擎或打开网址后，直接访问所选目标。Covelet 不再预置百度额外搜索项，旧数据中匹配内置标识 `baidu` 且规范化后的名称、模板仍为旧预置的记录会清理；其他标识的自定义引擎或名称／模板有实质修改的记录保留。浏览器默认搜索继续遵循用户自己的浏览器设置，不修改其提供商。选择 Bing 每日背景时，插件向 Bing 获取图片信息和图片，并在该设备缓存。新增网站的名称和图标识别直接访问用户授权的目标站，不使用第三方图标代理。可选跨设备同步只把加密数据直接发送到用户自选存储。搜索词、网址列表、图片和使用行为不上传给 Covelet 开发者。

## 项目状态

图标获取按真实图片内容识别格式，支持响应头与图片内容不一致的站点，普通小尺寸图标可以使用。编辑窗口及工具栏弹窗可通过“获取图标”直接获取当前地址，并针对实际图片域名申请可选权限；同地址可主动重新获取，失败保留已有图片并显示具体原因。明暗变体缺失可回退本地基础图片，丢失的本地资源可通过明确保存的 URL 修复绑定；无来源的自定义图片需要重新选择或从完整备份恢复。日常打开和刷新继续只读本地缓存。

图标在日常打开、刷新和预览时只读取加密 IndexedDB。确认导入或恢复时，先恢复备份内的图片，再以最多三个并发任务补齐缺失的原图及明暗变体，显示进度；同一地址只处理一次。新导航 ZIP v2 与完整备份包含实际缓存的图标，可离线恢复，并兼容旧 ZIP。已经导入的旧数据可在“备份与恢复中心 → 补齐缺失图标”修复；跨域受限的图片可从失败结果按图片域名授权后重试，不会在每次刷新时重复获取。已有有效图片、隐私状态、原始网址及图标地址均保留。

2026-10-23 已完成本机持久化调整：Covelet 内全部功能扩展的数据、导航与外观、便笺／稍后读／快照及回收站、时钟运行状态、GitHub 缓存、同步元数据、隐私标记、恢复点和图片缓存统一通过 AES-256-GCM 加密后保存到 IndexedDB。图片使用二进制 Blob 编解码，不转换为 Base64。浏览器原生同步的界面和运行逻辑已停用；设置页保留本机备份、恢复、导入和回收站。

设备密钥是不可导出的 CryptoKey，保存在同一 IndexedDB 的独立密钥对象仓库，与隐藏密码和自选存储同步密码相互独立。运行中的同源应用可以使用这把密钥；这项静态加密不能阻止拥有同源应用权限或浏览器配置文件访问能力的人使用设备密钥，也不能替代设备锁屏及备份保管。旧数据迁移先验证解密后的内容与原文一致，再清理旧副本；发生错误或冲突时保留已有副本，迁移被旧页面阻塞时应关闭旧版页面后重试。

- **统一检索**：首页搜索导航与文件夹、便笺标题和正文、稍后读标题和完整网址，结果直接打开对应内容，不依赖桌面上是否放有工具组件。支持本机别名、多词匹配和近似中文拼音首字母；多音字匹配不保证准确。不读取浏览历史或索引浏览器标签。
- **选择性迁入**：设置 → 数据 → 导入网址与书签，支持网址列表、Markdown 链接及书签 HTML。可按文件夹／条目筛选选择、指定目标屏幕或已有文件夹，默认跳过桌面已有及批内重复的完整 URL。新项只占空位，满后新建屏幕；导入可通过提示撤销，已有配置变更后不能覆盖恢复。
- **桌面方案与分享**：设置 → 外观，或桌面空白处右键，打开三套内置方案、JSON 导入、预览与本机方案管理。默认只分享外观及无内容组件布局；公开网址必须逐项选择，私密项、GitHub 账号、工具正文、搜索引擎与图片资源不导出。仅应用外观不改条目；应用组件布局会使用新屏幕并复用原组件 ID，保留内容和运行状态。方案文件限 256 KB，本机最多保存 20 份；已应用的方案可撤销。
- **内容隐藏**：设置 → 搜索 → 内容别名与隐私标记，可标记网站、文件夹、组件、便笺和阅读项，也可在桌面右键快速标记。首页眼睛按钮开启或关闭隐藏；标记文件夹同时遮住子网址，搜索、预览和工具栏弹窗遵循隐藏状态。受保护编辑窗口由中性遮罩保护，未保存草稿保留，公开内容和其他功能照常使用。首次开启设置隐藏密码，关闭须验证；该密码只控制可见性，本机持久化加密由独立设备密钥负责。

别名、私密标记和隐藏状态使用独立的 `covelet.content.preferences.v1` 逻辑记录；命名桌面方案使用 `covelet.desktop-templates.v1`。这些记录均通过统一加密存储保存。完整 JSON 备份纳入别名、私密标记和命名方案；恢复保留当前设备的隐藏开关。统一加密同步传播别名、标记和方案，当前隐藏开关及隐藏密码留在本机；旧导航 ZIP 与独立工具 JSON 的内容范围不变。

- **完整恢复中心**：设置 → 数据统一导出七类内容，导航内部连同 ZIP 本地图片资源封装；兼容旧 ZIP 和工具 JSON。支持预览、默认追加或选择类别替换、修订冲突保护、最多两份恢复前副本，以及不覆盖并发更新的失败回退。未处理的失败恢复点会阻止普通新导入。
- **布局撤销与工具回收站**：编辑布局提供最近 50 步会话内撤销／重做和快捷键；完成或取消后清空。便笺、稍后读和快照删除后保留 30 天，回收站最多 200 条，与活动工具内容合计 4 MiB；恢复不静默覆盖现有版本。
- **全部数据加密同步**：通过既有自选存储连接统一同步桌面、所有内置扩展业务数据与图像，替代分开的导航与工具开关；采用 AES-GCM、分块与整记录并发版本保留。离线仍可使用本机内容；不增加 Covelet 服务，真实云账号往返尚未测试。

当前为持续迭代的本地开发源码。界面保留全屏背景、中央搜索和无背景卡片的导航，使用右键或键盘上下文菜单管理网址。时间已移入独立时钟组件；图标默认 64px、每行 8 个，可调 2 至 12 个并自由放置，窄窗口按空间减列；保留滚动但隐藏默认滚动条。导航优先使用官网高清图标，完整底图与透明标志分别处理圆角和留白，获取失败再回退文字；用户可修改图标地址和背景色。整体参考 Apple HIG 的层级、排版与克制材质。背景提供 Bing 每日壁纸与颜色；浏览器默认搜索入口使用放大镜，有Logo的额外引擎选中后只显示图标，无Logo显示名称。

当前能力包括多屏桌面、跨屏拖拽、单层文件夹、网站名称／图标识别、本地检索、搜索桥、外观布局、书签 HTML 导入、ZIP 恢复、快照和默认关闭的自选存储加密同步。组件按行 × 列统一为迷你 1×1、小 2×2、中 2×4、大 4×4，与图标共用六行网格；每行默认 8 个图标，数量可调。短窗口保留完整网格，分页移到导航下方，避免遮挡最后一行。新安装包含六个可删除的普通网址，右上角添加；不向已有配置重新补回默认站点。最新检查与平台边界见[验证记录](docs/验证记录.md)；冻结的 v0.1.0 包保留原发布范围和验证结论。

扩展默认展示全部，按“开发工具”“时间工具”“记录与阅读”“浏览管理”“数据同步”分类并支持本地搜索。GitHub、时钟、便笺、稍后读是桌面组件；标签快照、自定义存储同步是功能扩展。免费增强统一为“视觉增强”。当前开发以 Chrome 为目标，其他浏览器发布暂缓。详见[扩展与组件](docs/扩展与组件.md)。

时钟提供指针／数字显示、世界时钟、时区对照、倒计时和计时，已移除闹钟；使用设备时间与原生时区数据库，不联网授时。样式、尺寸、时区、位置及运行状态均参与已开启的统一加密同步，通知仍受当前设备权限与运行状态影响。便笺、稍后读、标签快照和回收站一起同步，也可继续按既有范围导出／导入；未开启同步时内容仍在本机使用。图标默认 64px、间距 24px、内容宽度 1120px、每行 8 个，窗口变化不改写保存偏好。采用系统字体、React 和包内 WASM，不依赖 Naive UI 或 Apple 品牌资产。

## 导航与网站识别

- 首页只有一个桌面，不提供分组标签或管理入口。旧配置、旧备份和同步副本里的分组按原顺序合并到桌面，保留网址、文件夹和独立记录。
- 全新配置提供 Google、YouTube、GitHub、X、ChatGPT、Grok 六个可编辑、删除的默认网址，右上角添加网站；既有空桌面不自动补入。书签 HTML 导入保留在设置 → 数据，没有专门的新建文件夹入口。
- 导航支持圆点、左右按钮、键盘、滚轮与鼠标／触摸横向滑动切屏，拖拽时也可用滚轮切换目标屏。每屏六行，保存行列位置并保留空格；普通单项拖拽及文件夹操作继续可用。
- 在导航区域长按左键或右键选择“编辑布局”。普通点击／空格多选，无需 Shift，选中仅显示蓝色勾选；方向键定位，Ctrl／Cmd+A 多选当屏。拖动显示真实图标／冻结组件，垃圾桶删除需确认。当前会话可撤销／重做最近 50 步，按钮和 Ctrl／Cmd+Z、Ctrl／Cmd+Shift+Z、Ctrl+Y 可用；文字编辑不抢占。Enter／完成保存，Esc／取消放弃草稿，历史随会话结束清空，真实版本冲突不会覆盖已有数据。
- 添加一屏只在编辑模式出现；屏幕管理显示缩略图并可添加、前往和删除，至少保留一屏，空白屏可保存。删屏将网站与整个文件夹按顺序追加到最后一屏末尾，满后续屏；该屏组件只撤下展示、保留数据，在扩展中心可重新添加。
- 把网址图标拖到另一个网址图标中心可建文件夹，拖到已有文件夹中心可移入；打开文件夹后可拖到桌面接收区域移出。主屏幕支持自由放置，文件夹内部保留顺序整理且不嵌套；右键或 Shift+F10／上下文菜单键打开管理菜单，没有图标角落按钮。
- 文件夹创建、位置移动和排序只通过拖拽完成；右键菜单保留编辑、删除等操作，取消“移动到”“向前移动”“向后移动”。
- 打开文件夹后直接编辑顶部名称，Enter 或移开焦点保存，Escape 取消本次修改；输入法组词确认不误提交，没有专门的重命名按钮。名称更改沿用普通配置保存、备份和已开启的自选存储同步规则。
- 六个默认站点使用随包提供的官网高清图片。新增网址可尝试标准 touch 图标及浏览器已有缓存，不为每个新站申请页面访问权限；“获取高清图标”可按需授权读取网站发布的 touch／manifest 资源，名称也可手动修改或授权补全。不会为既存导航、书签或恢复项批量识别。
- 图标无需选择类型或品牌，用户可修改图标地址及背景色；默认背景色为 `#f5f5f7`。完整图案铺满圆角，透明标志保留留白；失败回退文字。新增图标上传入口取消，旧版合法本地图片及兼容备份保留。
- 浏览器工具栏按钮可添加当前网页，表单支持修改名称、网址和图标，保存才写入，取消不保存。只读取用户点击后的当前标签页，不枚举浏览历史；所有运行代码随包提供。
- 识别不使用 Covelet 代理或第三方 favicon 服务。主页／manifest 请求省略 Cookie 和 Referer，直接图像显示不发送 Referer，其他网络层行为由浏览器管理；详见[隐私说明](docs/隐私说明.md)。异步结果不得覆盖后续手动编辑，权限可在浏览器中撤销。

## 搜索引擎图标

必应、Google和DuckDuckGo使用包内官方彩色Logo，选中后隐藏文字；浏览器默认搜索显示放大镜。下拉菜单始终保留名称，自定义引擎没有Logo时用地球占位，选中后回退为名称。按钮的可访问名称和悬停提示仍说明当前引擎。

新增／保存引擎修改先读本机缓存与浏览器原生图标，不申请新站点权限；已有授权才同源补充读取。缓存原始字节参与统一加密同步，旧导航 ZIP 范围不变，既存引擎不批量抓取。图标流程使用 `favicon`，不申请 `history` 或 `tabs`；标签快照另按用户操作申请可选 `tabs`。浏览器默认地球图标会被过滤，不当作真实 Logo；普通网页使用回退。

## 背景与同步边界

- 新安装默认使用 Bing 每日背景，在本机加密缓存单张图片并参与已开启的统一加密同步，不上传给 Covelet。各设备复用有效当日缓存，缺失或过期时按日直接向 Bing 刷新；现有导航／完整备份范围不因此扩大。背景设置只提供等大的 Bing 每日壁纸和颜色入口，内置图仅用于离线回退和旧配置兼容。接口失败时显示旧缓存或内置背景，并冷却 15 分钟后重试。
- 点击颜色打开独立浮层，支持单色及最多 8 色渐变、色相／饱和度／亮度／HEX、渐变方向、预设或自定贝塞尔曲线。颜色间的实际 CSS 插值随曲线改变；颜色、方向和曲线作为普通背景配置参与备份及已开启的同步，不包含图片。浮层不撑高设置弹窗，短窗口可在浮层内部滚动；不再提供恢复默认外观按钮。
- 设置修改自动保存，不显示常规“正在保存”状态栏；保存失败时保留错误、重试及冲突重新载入入口，关闭前仍等待待保存修改完成。
- 不再提供用户壁纸上传。旧版壁纸选择在加载或恢复时迁移到 Bing 模式；已有旧资源不立即销毁，旧版备份继续校验但不再导入壁纸资源。统一加密同步同时传递图标地址、显示方式、背景色与原始图像资源，保留本地图标 ID；收到同 ID／地址的新图片后重读缓存，缺少有效图片时再按既有规则回退。
- 浏览器原生同步的界面和运行逻辑已停用，不再作为跨设备能力提供。扩展中心的自选存储加密同步保持默认关闭，只有用户配置、授权并解锁后才工作；不依赖 Chrome 或 Edge 账号互通。
- 原有浏览器同步容量、分片和发布间隔不再是当前产品功能。旧版已经提交到浏览器厂商的副本不会因移除开关而自动消失；用户仍需通过相应浏览器管理历史云端数据。ZIP 与完整 JSON 继续用于独立备份和迁移。

Bing 的公开图片信息接口没有已确认的第三方稳定性承诺。图片授权、署名和缓存展示条件仍需在上架前核查；接口可访问或 `wp` 字段不代表取得使用许可。该发布核查不影响本轮按已确认方向实现。

## 本地运行

使用 Node.js 22 或更高版本。在 `app` 目录安装依赖后执行普通网页预览：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

普通入口为 `http://127.0.0.1:4173/`，新配置包含六个用户指定的默认网址，并保留已有本地数据。开发预览 `http://127.0.0.1:4173/?demo=1` 使用同样的初始导航；该模式仅存在于开发构建，改动不持久化。删除、恢复或同步不会重新初始化默认站点。

扩展开发使用 `npm run dev:extension`，由 WXT 0.21.4 生成 `app/dist/extension-dev`，不自动打开或修改用户浏览器。该目录含本地热更新与重载所需的开发配置，仅用于开发，不可作为发布包。网页开发继续使用 Vite；既有 Sites 构建脚手架继续保留。产品界面和数据层共用同一份 React 代码，不分别维护两套实现。

网页预览没有 Chrome 扩展的默认搜索 API；调用时显示提示，不偷偷改用某个搜索引擎。额外引擎和直接访问网址仍可由用户显式选择；网页预览不能访问真实自选存储同步。正式扩展与网页预览均使用加密 IndexedDB 保存本机持久数据；既有 `chrome.storage.local`／网页存储与独立图片缓存只用于兼容迁移，成功校验后清理旧副本。自选存储凭据只保留在会话存储，不作为本机持久数据写入。

站点名称／图标识别需要扩展的运行时主机授权，普通网页预览不会通过代理绕过跨域限制；不能将预览中的手动添加视作真实扩展识别已通过。

开发服务器为 Bing 预览提供固定来源的本地代理，以处理普通网页的跨域限制；该开发分支不进入扩展构建。正式扩展凭声明的最小主机权限直接访问 Bing，不依赖开发服务器或 Covelet 代理服务。

对外品牌使用 Covelet；既有 `owntab.local.v1`、`owntab.sync.v1.*` 和旧 IndexedDB 标识仅作为历史数据与迁移兼容标识，不代表仍提供浏览器原生同步或使用旧产品品牌。`owntab-backup` 备份格式继续兼容。

## 测试和扩展打包

生成供手动加载测试的已解压目录：

```powershell
cd app
npm run build:unpacked
```

该命令只运行 WXT 生产构建，使用已有包内 WASM，输出 `app/dist/extension`，不执行测试、WASM 检查、扩展静态检查或 ZIP 打包，也不依赖开发服务器。打开 Chrome 的 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的该目录，然后新建标签页。再次构建后，在扩展管理页点击 Covelet 的重新加载按钮，再打开新的标签页。页面预览的站点数据与已安装扩展各自存储，互不自动迁移。

完整的测试和发布检查另行执行，不包含在上面的本地构建命令中：

```powershell
cd app
npm test
npm run build:extension
```

扩展生产构建由 WXT 完成并执行项目静态检查，输出目录仍为 `app/dist/extension`，ZIP 为 `app/dist/covelet-0.1.0.zip`；打包的新标签入口为 `newtab.html`，由 `chrome_url_overrides.newtab` 引用。Manifest 唯一源为 `app/extension.manifest.json`。在 Chrome 或 Edge 的扩展管理页通过“加载已解压的扩展程序”选择输出目录，可进行真实扩展验收。该操作需要用户自行在目标浏览器执行；当前任务未修改浏览器的已安装扩展。

打包检查涵盖 Manifest、CSP、包内资源和常见远程执行／网络调用模式。Bing 请求固定到 `https://www.bing.com/`；网站识别虽在清单中声明 HTTP／HTTPS 可选来源范围，但运行时只申请实际目标来源并校验同源资源，不批量取得全部站点授权。运行代码和依赖随包发布。开发服务器的本地模块请求和热更新连接不属于发布包行为。静态检查不能证明真实浏览器默认搜索、站点授权与抓取、跨设备同步、离线网络行为或商店审核已经通过。

## 开发中：本地 WASM 视觉增强

后续开发新增可选的壁纸自适应配色与图标视觉适配，WASM 随扩展包提供，不支持远程下载或用户上传可执行插件。两个模块默认关闭，只在本机分析已有图片，保留原图和用户手动外观；配置同步及 ZIP 只携带开关，不携带派生色板或处理图。详细边界与验收目标见[本地 WASM 视觉增强](docs/本地WASM视觉增强.md)。本节不表示已经更新 v0.1.0 商店提交包。

## 开发中：自定义存储同步

扩展 → 数据同步提供 R2、阿里云 OSS、GitHub、GitLab 和 HTTPS WebDAV 配置。WASM 随包提供，负责摘要、签名及同步状态计算；数据通过 Web Crypto 加密后直接发送到用户选择的存储。自动同步默认关闭，凭据和密码仅在浏览器会话中保留；网页预览不能访问真实云端。云端配置同步处理导航与外观，便笺／稍后读通过独立默认关闭的工具同步和 `tools-v1` 目录处理；图片文件、密钥、密码和存储目标地址均不随配置或工具正文传播。

本机加密范围已覆盖 Covelet 内全部功能扩展的持久记录，不代表这些记录已经全部接入云同步。目前自选存储仍只同步既有可移植配置，以及单独开启的便笺／稍后读；统一同步每个新增命名空间属于后续工作，时钟运行、快照、回收站、缓存及设备密钥不会因此上传。

自选存储可使用 GitHub／GitLab 私有仓库及已有的 WebDAV 空间；坚果云免费套餐有流量与频率限制，Nextcloud 是否免费托管取决于用户的服务商。R2 有免费额度，OSS 不标注为永久免费。详细接入、额度来源、冲突恢复及限制见[自定义存储同步](docs/自定义存储同步.md)。本节是开发能力，未更新商店提交或公开隐私页。

# Covelet

Covelet 是一个浏览器新标签页插件，网站导航、搜索、外观、布局及视觉增强作为免费基础功能。当前开发版无需 Covelet 账号，没有广告和推广链接，无 Covelet 业务服务器。配置默认保存在本机，可选浏览器原生同步；扩展提供 GitHub 贡献、世界时钟、便笺、稍后读、标签快照和自选存储的加密配置同步。扩展订阅定价方向为 6 美元／年，账号、收费和部署暂缓，当前未实现购买校验。

网页搜索默认通过 Chrome Search API 交给浏览器当前默认搜索提供商；用户主动选择其他引擎或打开网址后，直接访问所选目标。Covelet 不再预置百度额外搜索项，旧数据中匹配内置标识 `baidu` 且规范化后的名称、模板仍为旧预置的记录会清理；其他标识的自定义引擎或名称／模板有实质修改的记录保留。浏览器默认搜索继续遵循用户自己的浏览器设置，不修改其提供商。选择 Bing 每日背景时，插件向 Bing 获取图片信息和图片，并在该设备缓存。新增网站的名称和图标识别直接访问用户授权的目标站，不使用第三方图标代理。启用浏览器同步时，可同步配置由浏览器厂商处理。搜索词、网址列表、图片和使用行为不上传给 Covelet 开发者。

## 项目状态

当前为 0.1.0 后续本地开发源码。界面保留全屏背景、中央搜索和无背景卡片的导航，使用右键或键盘上下文菜单管理网址。时间已移入独立时钟组件；图标默认 64px、每行 8 个，可调 2 至 12 个并自由放置，窄窗口按空间减列；保留滚动但隐藏默认滚动条。导航优先使用官网高清图标，完整底图与透明标志分别处理圆角和留白，获取失败再回退文字；用户可修改图标地址和背景色。整体参考 Apple HIG 的层级、排版与克制材质。背景提供 Bing 每日壁纸与颜色；浏览器默认搜索入口使用放大镜，有Logo的额外引擎选中后只显示图标，无Logo显示名称。

当前能力包括多屏桌面、跨屏拖拽、单层文件夹、网站名称／图标识别、本地检索、搜索桥、外观布局、书签 HTML 导入、ZIP 恢复、快照和默认关闭的原生配置同步。组件按行 × 列统一为迷你 1×1、小 2×2、中 2×4、大 4×4，与图标共用六行网格；每行默认 8 个图标，数量可调。短窗口保留完整网格，分页移到导航下方，避免遮挡最后一行。新安装包含六个可删除的普通网址，右上角添加；不向已有配置重新补回默认站点。最新检查与平台边界见[验证记录](docs/验证记录.md)；冻结的 v0.1.0 包保留原发布范围和验证结论。

## 导航与网站识别

- 首页只有一个桌面，不提供分组标签或管理入口。旧配置、旧备份和同步副本里的分组按原顺序合并到桌面，保留网址、文件夹和独立记录。
- 全新配置提供 Google、YouTube、GitHub、X、ChatGPT、Grok 六个可编辑、删除的默认网址，右上角添加网站；既有空桌面不自动补入。书签 HTML 导入保留在设置 → 数据，没有专门的新建文件夹入口。
- 导航支持圆点、左右按钮、键盘、滚轮与鼠标／触摸横向滑动切屏，拖拽时也可用滚轮切换目标屏。每屏四行，保存行列位置并保留空格；普通单项拖拽及文件夹操作继续可用。
- 在导航区域长按左键或右键选择“编辑布局”。普通点击／空格多选，无需 Shift，选中仅显示蓝色勾选；方向键定位，Ctrl／Cmd+A 多选当屏。拖动显示真实图标／冻结组件，垃圾桶删除需确认。Enter／完成保存，Esc／取消放弃草稿，真实版本冲突不会覆盖已有数据。
- 添加一屏只在编辑模式出现；屏幕管理显示缩略图并可添加、前往和删除，至少保留一屏，空白屏可保存。删屏将网站与整个文件夹按顺序追加到最后一屏末尾，满后续屏；该屏组件只撤下展示、保留数据，在扩展中心可重新使用。
- 把网址图标拖到另一个网址图标中心可建文件夹，拖到已有文件夹中心可移入；打开文件夹后可拖到桌面接收区域移出。主屏幕支持自由放置，文件夹内部保留顺序整理且不嵌套；右键或 Shift+F10／上下文菜单键打开管理菜单，没有图标角落按钮。
- 文件夹创建、位置移动和排序只通过拖拽完成；右键菜单保留编辑、删除等操作，取消“移动到”“向前移动”“向后移动”。
- 打开文件夹后直接编辑顶部名称，Enter 或移开焦点保存，Escape 取消本次修改；输入法组词确认不误提交，没有专门的重命名按钮。名称更改沿用普通配置保存、备份和已开启的原生同步规则。
- 六个默认站点使用随包提供的官网高清图片。新增网址可尝试标准 touch 图标及浏览器已有缓存，不为每个新站申请页面访问权限；“获取高清图标”可按需授权读取网站发布的 touch／manifest 资源，名称也可手动修改或授权补全。不会为既存导航、书签或恢复项批量识别。
- 图标无需选择类型或品牌，用户可修改图标地址及背景色；默认背景色为 `#f5f5f7`。完整图案铺满圆角，透明标志保留留白；失败回退文字。新增图标上传入口取消，旧版合法本地图片及兼容备份保留。
- 浏览器工具栏按钮可添加当前网页，表单支持修改名称、网址和图标，保存才写入，取消不保存。只读取用户点击后的当前标签页，不枚举浏览历史；所有运行代码随包提供。
- 识别不使用 Covelet 代理或第三方 favicon 服务。主页／manifest 请求省略 Cookie 和 Referer，直接图像显示不发送 Referer，其他网络层行为由浏览器管理；详见[隐私说明](docs/隐私说明.md)。异步结果不得覆盖后续手动编辑，权限可在浏览器中撤销。

## 搜索引擎图标

必应、Google和DuckDuckGo使用包内官方彩色Logo，选中后隐藏文字；浏览器默认搜索显示放大镜。下拉菜单始终保留名称，自定义引擎没有Logo时用地球占位，选中后回退为名称。按钮的可访问名称和悬停提示仍说明当前引擎。

新增／保存引擎修改先读本机缓存与浏览器原生图标，不申请新站点权限；已有授权才同源补充读取。缓存不进同步／ZIP，既存引擎不批量抓取。图标流程使用 `favicon`，不申请 `history` 或 `tabs`；标签快照另按用户操作申请可选 `tabs`。浏览器默认地球图标会被过滤，不当作真实 Logo；普通网页使用回退。

## 背景与同步边界

- 新安装默认使用 Bing 每日背景，由各设备独立获取并在 IndexedDB 缓存单张图片，不上传给 Covelet、不写入浏览器同步，也不放入导出的备份。背景设置只提供等大的 Bing 每日壁纸和颜色入口，内置图仅用于离线回退和旧配置兼容。接口失败时显示旧缓存或内置背景，并冷却 15 分钟后重试。
- 点击颜色打开独立浮层，支持单色及最多 8 色渐变、色相／饱和度／亮度／HEX、渐变方向、预设或自定贝塞尔曲线。颜色间的实际 CSS 插值随曲线改变；颜色、方向和曲线作为普通背景配置参与备份及已开启的同步，不包含图片。浮层不撑高设置弹窗，短窗口可在浮层内部滚动；不再提供恢复默认外观按钮。
- 设置修改自动保存，不显示常规“正在保存”状态栏；保存失败时保留错误、重试及冲突重新载入入口，关闭前仍等待待保存修改完成。
- 不再提供用户壁纸上传。旧版壁纸选择在加载或恢复时迁移到 Bing 模式；已有旧资源不立即销毁，旧版备份继续校验但不再导入壁纸资源。原生同步传递网站图标的 HTTP(S) 地址、显示方式和背景色，不传图片文件或本地资源 ID。旧本地图标保留，其他设备按图标地址显示或回退。
- 同步默认关闭。用户在数据设置中主动开启后使用 `chrome.storage.sync`，需要登录浏览器并开启扩展同步；不保证 Chrome 与 Edge 账号之间互通。浏览器厂商会处理启用同步后的配置，Covelet 不接收这些数据。
- 同步存在 100KB 总量、每项 8KB、512 项及写入频率限制；每设备副本、删除记录和分片元数据也占容量，因此可同步的有效配置小于 100KB。实现按实体和设置字段合并、保留可恢复的并发冲突及删除记录，持久化至少 10 秒的发布间隔；超限或失败提示原因，本地完整数据继续保留。API 接受写入不表示其他设备已收到，ZIP 仍用于完整迁移与独立备份。

Bing 的公开图片信息接口没有已确认的第三方稳定性承诺。图片授权、署名和缓存展示条件仍需在上架前核查；接口可访问或 `wp` 字段不代表取得使用许可。该发布核查不影响本轮按已确认方向实现。

## 本地运行

使用 Node.js 22 或更高版本。在 `app` 目录安装依赖后执行普通网页预览：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

普通入口为 `http://127.0.0.1:4173/`，新配置包含六个用户指定的默认网址，并保留已有本地数据。开发预览 `http://127.0.0.1:4173/?demo=1` 使用同样的初始导航；该模式仅存在于开发构建，改动不持久化。删除、恢复或同步不会重新初始化默认站点。

扩展开发使用 `npm run dev:extension`，由 WXT 0.21.4 生成 `app/dist/extension-dev`，不自动打开或修改用户浏览器。该目录含本地热更新与重载所需的开发配置，仅用于开发，不可作为发布包。网页开发继续使用 Vite；既有 Sites 构建脚手架继续保留。产品界面和数据层共用同一份 React 代码，不分别维护两套实现。

网页预览没有 Chrome 扩展的默认搜索与原生同步 API；调用时显示提示，不偷偷改用某个搜索引擎或伪造跨设备同步成功。额外引擎和直接访问网址仍可由用户显式选择。预览使用本地网页存储；正式扩展以 `chrome.storage.local` 为本地数据主副本，按用户开关把可移植配置写入 `chrome.storage.sync`，设备图片缓存在本地资源存储。

站点名称／图标识别需要扩展的运行时主机授权，普通网页预览不会通过代理绕过跨域限制；不能将预览中的手动添加视作真实扩展识别已通过。

开发服务器为 Bing 预览提供固定来源的本地代理，以处理普通网页的跨域限制；该开发分支不进入扩展构建。正式扩展凭声明的最小主机权限直接访问 Bing，不依赖开发服务器或 Covelet 代理服务。

对外品牌使用Covelet；为兼容既有用户，内部的`owntab.local.v1`、`owntab.sync.v1.*`、IndexedDB命名及`owntab-backup`备份格式继续保留。这些是持久数据兼容标识，不代表仍使用旧产品品牌。

## 测试和扩展打包

```powershell
cd app
npm test
npm run build:extension
```

扩展生产构建由 WXT 完成并执行项目静态检查，输出目录仍为 `app/dist/extension`，ZIP 为 `app/dist/covelet-0.1.0.zip`；打包的新标签入口为 `newtab.html`，由 `chrome_url_overrides.newtab` 引用。Manifest 唯一源为 `app/extension.manifest.json`。在 Chrome 或 Edge 的扩展管理页通过“加载已解压的扩展程序”选择输出目录，可进行真实扩展验收。该操作需要用户自行在目标浏览器执行；当前任务未修改浏览器的已安装扩展。

打包检查涵盖 Manifest、CSP、包内资源和常见远程执行／网络调用模式。Bing 请求固定到 `https://www.bing.com/`；网站识别虽在清单中声明 HTTP／HTTPS 可选来源范围，但运行时只申请实际目标来源并校验同源资源，不批量取得全部站点授权。运行代码和依赖随包发布。开发服务器的本地模块请求和热更新连接不属于发布包行为。静态检查不能证明真实浏览器默认搜索、站点授权与抓取、跨设备同步、离线网络行为或商店审核已经通过。

## 开发中：本地 WASM 视觉增强

后续开发新增可选的壁纸自适应配色与图标视觉适配，WASM 随扩展包提供，不支持远程下载或用户上传可执行插件。两个模块默认关闭，只在本机分析已有图片，保留原图和用户手动外观；配置同步及 ZIP 只携带开关，不携带派生色板或处理图。详细边界与验收目标见[本地 WASM 视觉增强](docs/本地WASM视觉增强.md)。本节不表示已经更新 v0.1.0 商店提交包。

## 开发中：自定义存储同步

扩展 → 数据同步提供 R2、阿里云 OSS、GitHub、GitLab 和 HTTPS WebDAV 配置。WASM 随包提供，负责摘要、签名及同步状态计算；数据通过 Web Crypto 加密后直接发送到用户选择的存储。自动同步默认关闭，凭据和密码仅在浏览器会话中保留；网页预览不能访问真实云端。云端同步导航与外观配置，图片文件、密钥、密码和存储目标地址均不随配置传播。

免费渠道优先考虑现有浏览器原生同步、GitHub／GitLab 私有仓库及已有的 WebDAV 空间；坚果云免费套餐有流量与频率限制，Nextcloud 是否免费托管取决于用户的服务商。R2 有免费额度，OSS 不标注为永久免费。详细接入、额度来源、冲突恢复及限制见[自定义存储同步](docs/自定义存储同步.md)。本节是开发能力，未更新商店提交或公开隐私页。

## 连接方法

1. 在服务商处准备独立目录／仓库和凭据。GitHub 使用限单仓库 Contents 读写的细粒度令牌；GitLab 的 Repository Files 写接口需要 `api` 范围，免费用户可用专用账号的个人访问令牌，账号计划允许时可用项目令牌；`write_repository` 不等于 REST 文件写权限。[GitLab 权限](https://docs.gitlab.com/api/repository_files/)、[项目令牌计划限制](https://docs.gitlab.com/user/project/settings/project_access_tokens/)。R2 使用限目标 Bucket 的对象读写凭据；OSS 使用限目标 Bucket／目录的 RAM GetObject、PutObject、ListObjects 权限，无需删除或账户管理权限。
2. WebDAV 使用个人文件接口及应用密码；例如坚果云基地址 `https://dav.jianguoyun.com/dav/`，Nextcloud 通常为 `https://你的域名/remote.php/dav/files/用户名/`。先在基目录内创建 `covelet` 保存目录，再填写同名目录；插件不自动创建、删除或扫描其他目录。它不支持公共分享链接的特殊认证方式。[Nextcloud 接口](https://docs.nextcloud.com/server/stable/developer_manual/client_apis/WebDAV/basic.html)
3. 在扩展 → 数据同步 → 自定义存储同步填写连接、凭据和至少 12 字符的同步密码。点击「保存配置」单独保存，不需再保存外观。扩展只申请所选 HTTPS 来源的访问权限，保存不联网，也不代表已验证云端连接。
4. 点击「立即同步」验证并同步；其他设备填写相同目标、目录和同步密码。浏览器重启后重新输入凭据及同步密码「解锁」。网页预览只能配置和检查状态，真实连接需要加载 Chrome／Edge 扩展。
5. 可勾选「解锁后自动同步」再保存连接；默认关闭。自动同步仅在 Covelet 页面打开并且会话已解锁时工作，变更约 15 秒后合并，定期拉取只在页面可见时执行，间隔至少 60 秒。关闭页面不运行后台同步。

凭据及同步密码只保存在 `chrome.storage.session`，不同扩展标签共享当前会话；浏览器重启、重新加载扩展或手动锁定后需要重新输入。网页预览使用内存，不把秘密写入 localStorage、sessionStorage、导航配置、ZIP 或浏览器同步。普通目标配置和设备同步元数据只存本机。

## 数据、加密和 WASM 分工

同步内容是导航网址／名称、文件夹与顺序、搜索引擎、图标背景色、外观和布局偏好，以及视觉增强开关。真实图标图片、壁纸、派生图像／色板、凭据、同步密码、存储目标和本机同步开关不传播。目标设备缺少的图片使用文字回退，本机已有图片保留。

包内 `sync-core.wasm` 使用固定版本 RustCrypto SHA-256／HMAC-SHA256，并提供三方状态计算，10,773 字节，零宿主导入、固定 2 MiB 内存、单次输入至多 1 MiB。它不执行网络请求，也不载入用户或远程代码。合并复用既有实体因果协议；浏览器 Web Crypto 执行 PBKDF2-SHA256（210,000 次）派生及 AES-256-GCM 认证加密。不同对象使用随机盐和 IV；同一待提交对象重试复用已经持久化的密文与文件名。

HTTPS 请求仅访问用户授权的精确来源，不携带 Cookie／页面来源，不跟随重定向，无 Covelet 代理。R2 使用 S3 SigV4，OSS 使用原生 OSS V4，GitHub／GitLab 使用文件 API，WebDAV 使用 PROPFIND／GET／条件 PUT。存储服务仍能看到连接 IP、时间、密文大小和文件名中的设备随机标识、递增版本；加密不等于匿名。用户需要自行保管同步密码；当前没有密码找回或对现有云端记录重新加密的改密流程。

## 合并、失败与限制

每个设备追加带随机设备 ID、时钟及 SHA-256 的不可变快照。每轮选取各设备最新记录，校验摘要、解密和完整结构后再合并。并发修改与删除保留可恢复版本，同步配置页可恢复所选版本。结果未知时下次先核对同一对象，避免生成重复提交；不会凭部分读取覆盖本机。

锁定阻止后续请求，已发出的请求可能完成；此时保留待提交记录，下次解锁核对，不宣称撤回了服务器写入。有未提交版本或未处理冲突时不能切换目标，以免丢失只有本机保留的版本。原有导航的修订检查防止同步覆盖另一标签的新编辑。

当前边界：单对象 768 KiB、解密前明文 512 KiB、最多 100 个设备、每轮所读对象合计 4 MiB、控制器最多 2,000 条快照。还受 GitHub 1,000 项、坚果云 750 项及服务商频率等更小限制。超限会明确停止并保留本机数据，不删除旧云端记录；历史清理与空间轮换工具尚未实现。请保留 ZIP 独立备份，尤其在服务商达到配额之前。用户自行清空目录、改写快照、修改存储策略或删除设备记录可能影响历史恢复。

# 扩展升级与本机工具

2026-10-21，未发布的开发源码。本轮按用户要求只开发功能，未运行测试、静态检查、应用构建或浏览器验收。生成包内 `tools-core.wasm` 是必要资源生成，不是通过验证的证据；真实 Chrome 权限、存储服务连接、视觉和交互仍待后续用户要求验收。冻结 v0.1.0、线上商店与 Google Sites 隐私政策未修改。

## 现有扩展

### 时钟

- 桌面保持展示用途，点击后打开时钟、世界时钟、时区对照、倒计时、计时五个页签，不恢复闹钟。
- 设置支持系统／指定桌面时区、1–8 个世界时钟、预置城市与手动 IANA 时区。尺寸、样式与时区选择通过既有配置同步；当前时间和计时运行状态仍只在本机。
- 时区及夏令时使用浏览器的 `Intl` 数据库，表针和计时使用原有包内时钟 WASM。世界时钟显示 UTC 偏移、相对设备时区的时差及跨日关系，不联网授时或定位。
- 对照页选择参考时区、日期和时间。春季跳时不存在的时间会提示，秋季重复时间提供两次实例选择；范围 1970–2100。所选日期使用该日期的时区偏移，不能把今天的偏移用于未来日期。

### 自定义存储同步

- 解锁后浏览所选存储中已有的不可变加密修订，按设备过滤，逐个读取与解密，不批量下载全部历史。界面先显示每台设备的修订号，解密后显示该完整快照的时间。
- 差异分为导航与组件、搜索引擎、外观与布局；展开查看当前／历史值，包内 WASM 计算文字变化高亮。用户勾选项目后再次确认恢复。
- 新发布修订的加密明文包含 `format: covelet-sync-revision`、版本、创建时间、因果文档和当时的完整可移植配置。摘要、AES-GCM 认证、密码、来源权限及大小限制继续生效，外层加密格式与对象命名不变。
- 仍可读取原来的裸因果文档。旧修订只对其记录过的实体比较，不把缺少的实体视为删除，并明确显示“旧修订”说明。不能把某台设备的旧修改记录冒充整个账户的历史桌面。
- 恢复不会倒退设备因果时钟。它是一次新的本机配置编辑，由下一次常规同步生成新操作；默认不选中差异，当前配置的修订与 WASM 摘要必须仍匹配预览，预览十分钟后失效，锁定／更换连接后不能继续恢复。
- 恢复子网站会选择必要的缺失文件夹；只删除文件夹而未选择删除其子导航时，子导航会留在桌面。普通配置保存会保留恢复前的本机配置快照。工具正文、标签快照、时钟运行状态及图片字节不由历史恢复改写。
- 旧构建无法读取新加密明文／新组件配置；多设备使用时均需更新到支持本功能的构建。源码未发布，不宣称已实现旧构建向前兼容。明文仍限 512 KiB，完整配置与因果记录合计超限会停止上传、保留本机数据，不裁掉历史或正文以求成功。

| 扩展 | 分类 | 桌面 | 功能 |
| --- | --- | --- | --- |
| 便笺 | 记录与阅读 | 迷你／小／中／大 | Folio 富文本、标题、置顶、本地搜索、预览、复制、保存与删除确认 |
| 稍后读 | 记录与阅读 | 迷你／小／中／大 | 链接添加／编辑、未读／已读／归档、本地搜索、浏览器阅读清单单次导入 |

便笺和稍后读的桌面仅显示摘要，点击后打开可最大化的工具弹窗；正文不直接充满桌面。未保存的便笺及链接表单关闭时确认放弃，编辑记录保存时校验原修订。便笺现使用 Folio JSON 编辑与预览，兼容旧纯文本／Markdown；文档图片按其地址加载，不接入图片上传服务。详见[弹窗与 Folio 数据兼容说明](组件弹窗与Folio-2026-10-21.md)。

浏览器工具栏添加表单可选择“网站导航”或“稍后读”。保存稍后读使用当前表单的名称与网址，不自动抓取文章、不记录阅读行为。取消不保存；列表中的阅读状态由用户明确修改。

### 标签和阅读权限

- `tabs` 和 `readingList` 仅列入可选权限。用户点击“保存当前窗口”或“从浏览器阅读清单导入”时才请求对应权限，不在安装或打开新标签页时请求。
- 标签快照只读取当前窗口的普通 HTTP(S) 页面标题、完整网址与固定状态，按标签顺序保存并去重。排除隐身标签和浏览器内部页面，不读取正文、不监视标签变化、不关闭现有标签、不申请 `history` 权限。
- 标签可包含 URL 的查询参数／片段，它们可能是敏感信息，数据仅在本机。一次最多保存 1000 个标签；一次打开最多选择 50 个，需确认；创建新窗口后部分打开失败会报告已打开数量，原快照保留。
- 阅读清单导入是去重合并，不修改／删除浏览器原有条目，不持续订阅其变化。稍后读始终可以手动添加，不依赖该权限。[Chrome Reading List API](https://developer.chrome.com/docs/extensions/reference/api/readingList)
- `tabs` 用于得到标题、网址等敏感字段；创建标签本身通常无需此权限。工具栏仍用已有 `activeTab` 读取当前页面，没有扩成全窗口扫描。[Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs)、[可选权限](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)

### 本机存储和备份

- 工具数据在单独的 `covelet.tools.v1` 本机记录中，开发 demo 使用独立键。导航配置仅保存便笺／稍后读组件尺寸与位置，不将正文或快照塞进 `chrome.storage.sync`，也不加入原有导航 ZIP 或自定义配置同步。
- Folio 接入后，内部工具记录与导出版本采用 `2`，继续读取／导入版本 `1`；新增有界 `document` 字段及一致的正文投影。键名保留，加载不自动写盘；旧开发构建不支持新版本。
- 三项工具共用“工具数据 → 导出／导入”。导出 JSON 包含三者的完整数据；导入只合并新 ID，已有本机记录和重复阅读网址保留，不静默覆盖。文件限制 5 MiB，导入后整份本机记录仍限 4 MiB。
- 便笺最多 200 条、每条正文 60000 个 UTF-16 单元；稍后读最多 500 条；标签快照最多 50 份、合计最多 3000 个标签。受限记录验证和浏览器事务锁处理并发；存储不足时不写入新数据。
- 移除／撤下便笺和稍后读组件不清空这些工具内容。删除记录需要二次确认；数据可通过独立导出迁移，未接入 Covelet 账号或新收费服务。
- `tools-core.wasm` 随包提供，负责文字统计／本地匹配、UTF-8 差异与网址去重。宿主负责界面、浏览器权限、数据库及网络 API，没有远程或用户上传 WASM 执行入口。[内核说明](../app/wasm/tools-core/README.md)

## 免费增强

- 高清识别综合 touch／manifest 声明和实际解码尺寸，比较最多五个候选，不把第一个 96px 图片直接当作最佳图。尝试标准 touch／192px 路径，排除仅为 monochrome 用途的 manifest 资源；最多读取两个 manifest，总时限 12 秒，失败保留原图。
- 已获授权的网站识别复用同次根首页的声明，不二次读取首页；没有授权时仍只尝试当前输入来源的常规图片，不为每个图标发起授权、不批量扫描现有导航。
- 新便笺和稍后读所有尺寸接入局部壁纸背景与前景色适配；图片颜色不变。字体加载结束及可视视口变化时重新取样，派生色仍不进入配置或同步。
- 编辑模式支持方向键／Home／End 在当屏图标与跨格组件间定位，Ctrl／Cmd+A 将当屏条目加入多选；不改变现有位置、跨屏选择、删除确认或 Enter 保存／Esc 取消规则。

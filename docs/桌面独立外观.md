# 桌面独立外观

每个逻辑桌面可分别设置背景、遮罩和模糊。未设置的字段继续继承全局值；清空覆盖不会删除桌面身份或名称。主题、布局、网格和组件配置仍使用原有规则。响应式溢出屏属于同一逻辑桌面；整理操作把溢出屏提升为独立桌面时，只有原桌面保留原身份和外观。

背景支持纯色、既有渐变、内置 `alpine` 和当前随机壁纸。随机壁纸仅保存 `{kind:"bing",value:"daily"}` 这一通用模式，来源、轮换周期和当前照片仍由本设备统一管理。外观记录不携带照片 URL、上传图片、来源或轮换配置。

配置位于 `settings.desktopPages[page].appearance`，可选字段为 `background`、`shade`（0–90）和 `blur`（0–40）。省略字段表示继承；空对象在验证时移除。`prepareDesktopAppearance` 按逻辑桌面 ID 找回目标，并要求原导航 revision；局部补丁中的 `null` 删除该字段，整个补丁为 `null` 时恢复全部继承。新身份只在确实增加覆盖时创建。

完整备份、导航 ZIP、恢复点和同步均保留这些字段。追加恢复按目标页重新映射桌面身份；局部覆盖中的继承字段使用接收端全局值。旧配置默认全部继承。已发布的 0.5.1 验证器不支持新的桌面元数据，会拒绝读取，而不会安全地回退或移除覆盖；兼容性测试使用该版本的冻结模型源码，仅重写模块导入地址。

桌面方案目前只有数据引擎，没有分享或应用界面。本版没有新增该界面。引擎的 `createDesktopTemplate` 默认不携带局部外观；显式设置 `includeDesktopAppearances:true` 才生成可选的 `desktopAppearances` 数组。它仅包含已选公开网站或公开组件所代表桌面的相对页码和安全外观字段，不包含桌面身份、名称或仅有私密内容的页面。

应用这类方案且 `appearance:true` 时，相对外观映射到新建的逻辑桌面，即使没有同时应用网站或组件也会创建这些页面；返回值的 `addedDesktopAppearances` 明确给出数量。已有桌面的覆盖不会被套用到任意编号页。`appearance:false` 忽略该数组，旧方案仍保持原有行为。

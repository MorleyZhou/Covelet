# Covelet 0.2.1 A+ 范围

0.2.1 是尚未提交的候选补丁，Chrome 线上版本为 0.2.0。代码实现起点 main `13095d9` 含开发中的 17 项工具，须剥离后接近线上范围，再进行 A+ 权限削减；该提交不是产品基线。

核心功能为网站／单层文件夹、搜索、布局与外观、Bing 每日壁纸、时钟／世界时钟／时区对照／倒计时／秒表、便笺、手动稍后读、GitHub 公开贡献和可选自选存储加密同步。扩展中心只管理核心组件。八种语言保留。17 项扩展工具包、窗口标签快照与浏览器阅读清单导入及界面全部移除。

本机业务数据使用统一加密 IndexedDB。浏览器原生同步停用；自选存储同步默认关闭，按需授权具体来源，使用独立同步密码加密传输，设备密钥、隐藏密码与状态和会话凭据保留在设备。旧数据不因移除功能而静默清空；历史标签集合仅为兼容保存／导出，不提供浏览器操作或独立恢复入口。

保持导航和图片缓存的离线显示、显式获取和失败保留、加密写入、跨页面版本守卫、布局撤销和导入预览。备份恢复支持导航、便笺、稍后读、可用回收站、桌面方案和隐私偏好；恢复前保存副本，拒绝覆盖并发新编辑。导出 JSON/ZIP 不是密码加密文件。

必需权限 storage、search、favicon、activeTab、scripting、alarms；可选命名权限仅 notifications。固定 Bing 主机保留，HTTP(S) 可选主机范围只按用户动作申请具体来源。activeTab 下的当前页查询不等于读取窗口标签集合。无广告、遥测或 Covelet 数据服务器。

验收需运行单元测试和生产包静态检查，记录失败及修复；实际浏览器、真实服务和商店审核须分别验收，不从构建通过推断。只开一个 PR，不合并，不向两店提交。支持：support@morley.work。

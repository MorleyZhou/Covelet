# Covelet 产品需求

日期：2026 年 10 月 19 日。状态：开发中；以下条目为产品目标和待验收标准，不表示已全部实现。

Covelet 是浏览器新标签页插件，围绕网站导航、搜索、外观和布局，让用户快速访问网站，并自行整理页面。核心功能免费且无需 Covelet 账号，配置以本机为主副本，可选浏览器原生同步；插件没有广告，不向开发者收集使用行为。新安装默认使用 Bing 每日背景，会向 Bing 获取图片信息及图片。

## 2026-10-22 恢复、撤销与工具同步（最新）

完整备份 JSON 覆盖导航、文件夹、布局与外观、便笺、稍后读、标签快照、工具回收站、命名桌面方案、别名与隐私标记；保留旧导航 ZIP 和工具 JSON 的导入。恢复按类别选择追加或替换，写入前校验并保存恢复点；最多保留两份副本，版本冲突不覆盖，失败回退也不得覆盖后来的编辑。凭据、密码、同步目标、临时缓存和时钟运行状态不包含在备份中。

布局编辑会话提供最近 50 步撤销／重做，保存或取消后清空；文字编辑保留自己的撤销行为。便笺、稍后读及手动标签快照删除进入本机回收站，30 天、最多 200 条，与工具共享 4 MiB；恢复保留 ID，冲突不覆盖，永久删除和清空需要确认。

便笺和稍后读可独立开启自选存储加密同步，默认关闭，复用现有连接与会话密码，在独立 tools-v1 目录中传输。保留并发版本和删除墓碑，失败不妨碍离线使用，不同步快照、回收站或凭据。实现、测试和未验收边界见[本轮开发记录](恢复撤销与工具同步-2026-10-22.md)。本轮用户已明确授权测试，取代先前暂缓测试的约定。

## 2026-10-22 免费桌面开发

本轮按用户确认的顺序实现自有内容统一检索、选择性网址迁入、桌面方案与安全分享、隐私展示模式。功能范围、入口、本机数据键和迁移边界以 README 的本轮说明及 app/AGENTS.md 最新约定为准。四项均不依赖 Covelet 账号或支付，不引入浏览历史索引、自动标签监控或远程可执行模块。旧的扩展订阅设想不构成本轮购买或解锁承诺。

桌面方案是可公开检查的声明式配置，不是完整备份；默认不含网址、账户、便笺／阅读正文和私密内容。别名、隐私标记与本机命名方案由后续完整 JSON 备份迁移，仍不加入旧导航 ZIP 或配置同步。四项初次开发只刷新解压目录，后续测试结果以本轮开发记录为准。

## 2026-10-21 时钟精简与组件视觉（最新）

时钟移除独立闹钟功能，弹窗只提供时钟、倒计时与计时；倒计时完成通知保留。兼容读取并迁移旧本机闹钟数据，原闹钟模式回到时钟，旧闹钟字段和计划移除，排队事件不再提醒；保留倒计时／计时记录及通知偏好，不重置组件。

时钟桌面去掉固定白色内盘，刻度与表针使用适合当前背景的前景色。视觉增强还控制时钟、GitHub 各尺寸的组件背景，按各自位置的壁纸生成带色调的半透明底色及内部文字／控件配色；尊重明确的浅色／深色主题，关闭后恢复主题底色，不新增装饰边框、外发光或图片请求。派生颜色仅在当前设备显示，不保存或同步。本轮未运行测试、检查、构建或浏览器验收。

## 2026-10-21 迷你组件与时钟交互

组件新增迷你 1×1，保留小 2×2、中 2×4、大 4×4，统一行 × 列定义。迷你与普通导航图标对齐，仍支持自由定位、跨屏拖动、默认多选和垃圾桶确认；尺寸进入既有配置、备份及同步，不重置其他选项或本机运行数据。GitHub 迷你展示所选时间总贡献及最近七天色点，不绑定或改变时间范围。

时钟组件在桌面只展示时间（指针／数字），迷你隐藏日期，不展示功能切换。点击或键盘激活后，在独立弹窗中使用时钟、倒计时、计时、闹钟。关闭弹窗不停止已启动的计时或提醒，未保存的新闹钟表单放弃；保留原本机数据、通知授权和浏览器运行限制。弹窗与底层布局交互隔离，支持关闭、Esc 和焦点返回。当前仅修改源码，未运行测试、检查、构建或浏览器验收。

## 2026-10-21 编辑布局与屏幕管理

极简模式退出产品；旧开关只做兼容并关闭。拖拽中允许滚轮切屏，普通单项拖动与文件夹操作仍可直接使用。导航区域长按左键或右键提供“编辑布局”，进入后图标与组件轻微晃动，普通点击／触摸或空格键增减选择，无需 Shift；选中仅显示蓝色勾选标记，不加蓝色外圈。保留图标叠层／数量的批量拖动、减少动态效果及键盘焦点操作。

“添加一屏”只在编辑时出现，屏幕管理提供实际内容缩略图及添加、前往、删除操作，至少保留一屏。显式空屏可保存。删除屏幕将其中网站和整个文件夹按显示顺序追加到最后一屏最后一个导航之后，跳过已有占位，满后自动续屏；不删除网址或拆散文件夹。组件只撤下展示，保留原 ID、配置及本机数据，可在扩展中心重新使用，不自动挪到其他屏幕。

编辑使用独立草稿，Enter／完成保存，Esc／取消放弃未保存修改；保存前不写本地配置或同步，有真实版本冲突时拒绝覆盖。完成右侧提供垃圾桶，可拖入或点击删除所选项，始终二次确认、默认聚焦取消；确认仅修改草稿。删除文件夹前说明包含的网站数量，明确删除的时钟仅在保存成功后清理本机数据。页面提示为“点击多选 / Esc 退出编辑 / Enter 保存”。本轮只生成必要的包内 WASM，按用户要求不主动运行测试、检查、应用构建或浏览器验收。

视觉增强默认开启且保留显式关闭。自动图标配色只调整背景，绝不反转或染色 Logo；结合各位置壁纸色调与标志明暗选底色，手动颜色优先。文字按实际字形及最弱局部比较黑白对比度，考虑细线干扰；复杂背景增加轻微文字支持，平整可读背景不加额外效果。算法随安装包提供，不上传像素或增加识别请求。

## 2026-10-21 导航、自由布局与组件修订

本节覆盖下文历史的仅文字回退、默认站点不带品牌图片、紧密顺序排布、搜索上方时间、没有贡献时间选项等限制。所有网站优先展示真实图标，六个默认站点使用随包提供的官网高清图片；新增网站查找 touch 等高清资源，已有网站可显式重新获取，失败保留可用图片或回退文字。图标完整底图与透明标志分别处理，避免双重留白，不增加装饰外框或光晕。

浏览器工具栏提供当前网页的添加／编辑表单，名称、地址、图标地址及背景可改，保存才写入、取消不保存；只在点击后读取当前标签页信息。原生同步携带图标 HTTP(S) 地址而非图片文件。网站内容权限不自动逐站申请，显式元数据获取才按来源授权，直接图标加载的数据流需准确披露。

主屏幕支持保留空格的行列定位、同一网格的图标和组件自由拖动、滚轮及鼠标／触摸滑动切屏；保留叠放文件夹和跨屏移动，合并提示不被边缘裁切。尺寸仍按行 × 列：小 2×2、中 2×4、大 4×4；GitHub 独立提供近一周、近一月、近半年、近一年。

移除搜索上方时间和相应开关，在扩展中新增时钟，支持指针／数字、倒计时、计时、闹钟。运算 WASM 随包提供；运行状态与闹钟仅保存在本机，系统通知按需授权。背景“纯色”更名为“颜色”；移除恢复默认外观和数据页多余提示，保留书签导入及真正错误的处理路径。

按用户要求，本轮不主动运行测试、构建或浏览器验收。实现范围与未验收边界见[开发改动](开发改动-2026-10-21.md)。

## 2026-10-20 背景与设置保存修订

设置在常规修改和自动保存时不新增底部状态栏，避免弹窗高度变化；真正失败时保留错误、重试及冲突重新载入操作，关闭前继续刷新待保存修改。

背景入口只保留等大的“Bing 每日壁纸”和“纯色”。移除山间湖泊选项和独立柔和渐变按钮；点击纯色后打开独立浮层，支持单色、最多 8 色的渐变、色相／饱和度／亮度／HEX、方向及贝塞尔曲线。曲线可用预设、拖动或键盘／数值调整，实际改变颜色插值。浮层不参与设置弹窗的高度计算，短窗口保持标题与关闭按钮可见，内容在内部滚动。

颜色、方向和曲线随普通背景配置保存、备份及可选同步；校验颜色数量、范围、字段和生成 CSS 的一致性。旧版颜色、渐变及内置背景仍可读取，不删除用户数据；内置图片保留为每日壁纸的离线回退，不再展示为可选壁纸。没有新增请求、账户或图片同步。

## 产品范围

首版只提供四个面向用户的模块。ZIP备份导出／恢复、设置和权限管理作为基础保障，不扩展成独立工具平台。

| 模块 | 首版范围 | 用户目标 |
| --- | --- | --- |
| 网站导航 | 可删除的六个初始网址、右上角添加、网址管理、单层拖拽文件夹、自动识别网站名称和图标 | 快速添加、找到和打开网站 |
| 搜索 | 浏览器默认搜索、显式选择其他引擎、自定义引擎、已保存网址检索、直接访问网址 | 尊重浏览器设置，清楚地知道操作将去哪里 |
| 外观 | Bing 每日背景、内置背景、纯色与渐变、深浅主题、图标与文字样式、简洁本机时间日期 | 默认易读，允许适度个性化 |
| 布局 | 多屏网格、统一组件尺寸、每行数量、宽度、图标大小、间距、窗口自适应 | 整理稳定，调整后保持顺序 |

以下功能不进入产品范围：

- 效率组件，包括日历工具、待办、便笺、倒数日、番茄钟和习惯打卡；仅保留本轮明确确认的简洁本机时间日期显示。
- 在线信息，包括天气、热榜、新闻、行情、汇率、每日内容和推荐信息流。
- 扩展工具，包括 AI、翻译、PDF、媒体处理和小组件市场。
- OwnTab 账号、运营方云同步、会员、广告、赞助图标和联盟推广；不设置 OwnTab 登录引导。用户主动启用原生同步时说明浏览器账号要求。

首版也不提供分组、自由画布、动态壁纸、用户壁纸上传、在线壁纸库、第三方图标代理、搜索联想、浏览历史检索或自定义脚本。这些能力不作为本版的隐含承诺。浏览器原生配置同步是数据保障能力，不扩展成账号或云盘系统。

Bing 每日背景已由用户确认，作为新安装默认背景，不属于在线信息组件。每台设备独立获取并缓存，不同步或备份图片。保留内置、纯色、渐变背景和失败回退；图片授权、版权标注、接口稳定性及第三方请求披露在上架前复核。

2026 年 10 月 19 日追加的明确要求：网站区不再有整块背景卡片，图标默认缩小；搜索栏上方显示本机时间日期；整体参考 Apple Design 的层级、排版、材质与反馈；下拉选择采用统一的自定义组件，不显示浏览器原生 `select` 外观，不引入 Naive UI。这一要求覆盖早期“无时钟日期”和旧稿下沿大面板的限制，其余范围保持不变。

同日后续明确要求：移除左上 OwnTab 标题、图标右上菜单按钮及常驻“拖拽整理／叠放建文件夹”文字；通过右键管理网站和文件夹，保留 Shift+F10／上下文菜单键的等效入口；缩短搜索与导航间距；隐藏默认滚动条而保留滚动。桌面默认每行 8 个图标，用户可调整 2 至 12 个，窄窗口按实际可用空间减少列数。

同日最新图标要求：取消图标类型、品牌选项和新增图标上传入口。实际获取到合法站点图标就显示图片，否则自动显示名称文字；不以随包品牌图标或域名匹配伪装成功获取。用户可以修改网站和文件夹图标背景色，默认 `#f5f5f7`，图片和文字都使用该背景。已有合法本地图片与兼容备份保留，旧预设经严格校验后回退为文字，不删除用户既存图片。

同日搜索与文件夹追加要求：不再预置百度额外搜索项，仅迁移匹配旧内置标识 `baidu`、且规范化后名称和模板仍未实质修改的记录；其他标识的自建引擎或名称／模板实质修改的记录保留。浏览器默认搜索继续通过 `chrome.search.query` 跟随浏览器设置，插件不替换用户的浏览器默认提供商。文件夹名称在打开后的顶部标题处直接编辑，Enter 或失焦保存，Escape 取消本次编辑，兼容输入法组词；不再显示专门的重命名按钮。

同日最新范围收紧：正式首次使用和开发 `?demo` 均从空桌面开始，网站通过网格加号图标添加；取消专门新建文件夹、右键“移动到”和前后移动；设置→数据保留书签HTML导入。手动创建文件夹、移入／移出和排序靠拖拽完成，书签导入及ZIP恢复仍可带入文件夹；右键保留编辑及删除。ZIP备份恢复、已有用户导航和兼容数据继续保留，这次精简不删除既有配置。

## 网站导航

### 网址管理

- 支持添加、编辑、打开和删除网址；每项包含名称、URL 和图标。
- 用户可以自定义名称；长名称显示省略效果，同时提供查看完整名称的方式。
- 默认在当前页打开，保留中键和修饰键等浏览器常用打开方式；设置中可以选择默认在新标签打开。
- 新增网站时输入 URL，可从目标网站自动识别名称和图标；保存前可检查、修改名称和图标背景色，无需选择图标类型或品牌，识别失败仍可用文字图标保存。
- 首次识别某个站点时，由用户点击识别入口触发浏览器的该站点访问授权；已授权的目标可在输入有效 URL 后自动识别。授权只针对实际目标来源，不在安装时取得所有网站访问权限。
- 识别仅请求目标来源的根首页，不发送输入 URL 的路径、查询参数或片段；从首页读取名称并获取同源图标，不经 OwnTab 服务器、搜索服务或第三方 favicon 代理。不读取浏览历史、整个书签库或用户已打开的页面。
- 请求不附带 Cookie 或来源页；只作名称和图片数据处理，不执行目标站脚本或嵌入远程页面。跨来源重定向和图标不得绕过原有权限；异步结果不能覆盖用户刚修改的名称或背景色，也不能写入已关闭、切换记录或切换地址的表单。更换网址来源时旧来源图片及时回退为文字，不因新请求失败而残留上一个网站的图标；同源路径变化不必丢弃有效图片。
- 支持 HTTP 和 HTTPS 地址，保留用户输入的查询参数和片段；插件不额外添加推广参数或跳转中间页。
- 拒绝可执行或不受支持的协议，例如 `javascript:`、`data:` 和 `file:`。可识别的无协议域名补全为 HTTPS，并在保存前展示最终地址；本地或特殊地址要求用户明确输入支持的协议。

### 桌面和文件夹

首页只有一个桌面，桌面中放网址或文件夹，文件夹中只能放网址。不提供分组标签、分组切换或分组管理；没有嵌套文件夹，也没有同时属于多个位置的同一条记录。

- 初次使用及开发演示提供六个用户指定的普通网站，全部可编辑删除；右上角添加网站。已有本地网址不因升级清空或自动补回默认站点；主屏幕支持分页。
- 支持文件夹重命名、排序与删除；可以把网址移入或移出文件夹。重命名直接在打开文件夹的顶部名称中编辑，不使用独立重命名按钮或专用表单。
- 标题 Enter 或失焦时保存合法的新名称，Escape 恢复已保存名称且不关闭文件夹；避免 Enter 后失焦重复提交，输入法组合中的 Enter／Escape 交由输入法处理，不误提交或取消整个名称编辑。空名称、非法值和并发写冲突不覆盖已保存名称；保留可见焦点与可访问名称。
- 旧数据、备份和同步中存在的多个分组收敛到同一桌面：保留全部网址和既存文件夹，按原分组顺序及组内顺序合并，不因取消分组丢失或去重用户条目。底层兼容字段不作为产品分组重新显示。
- 同一 URL 可以存在多条独立记录，不在兼容迁移时擅自删除。
- 删除非空文件夹时，将其中网址移到桌面，保持相对顺序；界面在执行前说明结果。
- 移动或删除网址后，原文件夹剩余一个网址时自动展开回原桌面位置，空文件夹自动移除；旧数据迁移本身不因此删除既存文件夹。
- 删除网址提供撤销操作；移动和重命名不改变 URL。

### 整理操作

- 拖拽采用类似 iOS 的图标整理方式：把一个网址图标拖到另一个网址图标中心，显示合并提示，松开后创建包含这两项的文件夹；新文件夹可重命名。
- 拖到已有文件夹中心时，显示接收提示，松开后把网址移入；打开文件夹后，可以把内部网址拖到桌面的接收区域移出。
- 拖到图标边缘或图标间的排序位置时按插入标记排序，不意外创建文件夹；文件夹不能放入另一文件夹。
- 拖到无效区域或取消操作，内容和顺序保持原样。
- 空桌面和空文件夹提供可识别的放置区域。
- 手动创建文件夹通过叠放网址图标完成，不提供显式新建入口；书签导入和ZIP恢复可带入文件夹；位置移动、移入／移出和排序只通过拖拽完成，右键菜单不提供移动到或前后移动。
- 网址链接或文件夹按钮聚焦后，可用 Shift+F10／上下文菜单键打开保留的编辑／删除菜单，Escape 可关闭并返回触发项；不宣传已经提供键盘移动替代。
- 不为图标显示右上角菜单按钮，不在桌面常驻显示拖拽说明；实际拖动中的接收与排序反馈继续保留。

### 图标

- 网站图标自动来自目标站点实际识别后保存在本机的合法图片，或由名称生成的文字；不提供图标类型、品牌选项或新增本地图标上传，不进行域名到品牌资源的自动匹配。
- 已有合法本地图片和旧备份中的合法图标仍可加载、恢复及导出，不因取消新增入口删除；旧预设图标必须先通过既有格式／值校验，再转换为名称文字，不继续展示内置品牌图案。
- 每个网站或文件夹可保存可选 `iconBackground`，只接受 `#RRGGBB`，缺省显示为 `#f5f5f7`；背景色适用于图片、文字及文件夹表面。可用颜色入口及实时预览调整，异步识别不重置手动背景。
- 自动获取仅接受同源 PNG、JPEG、WebP、ICO，校验后重编码保存到本机；拒绝远程 SVG、data、blob 及可执行内容。图标不可用时显示文字图标，不在每次新标签显示时请求目标站。
- 自动识别的 HTML 上限为 512KiB，每张候选图标 1MiB，单次请求超时 5 秒；最多检查 3 个声明图标和 `/favicon.ico` 回退。解码上限为 400 万像素、单边 4096 像素，超过限制保留手动编辑路径。
- 设置→数据提供浏览器书签HTML导入；仅解析用户选择的文件，不读取或修改浏览器书签库。OwnTab ZIP备份恢复用于完整迁移。
- 不承诺直接兼容 iTab 或其他产品的私有备份格式。

### 设置中的书签导入

- 在设置→数据中选择浏览器导出的HTML文件，首页加号只用于添加单个网站。
- 文件在本机惰性解析，不执行脚本或加载嵌入资源，不批量联网获取站点名称与图标；导入网站默认使用名称文字。
- 导入前显示新增网站、文件夹、重复和无效地址摘要；确认后增量添加，保留已有导航，同位置规范化URL去重，多次导入复用同名目标文件夹。
- 多层书签文件夹按完整路径转换为桌面上的单层文件夹，不引入嵌套文件夹。
- 文件上限5MB，网址与文件夹总数上限2000；危险协议、坏引用及越界计划不能写入配置。

## 搜索

### 搜索引擎

- 每次打开新标签页时，网页搜索初始项固定为“浏览器默认”，由 `chrome.search.query` 交给浏览器当前默认搜索提供商；不自行读取或猜测其品牌，选中入口仅显示放大镜并通过可访问名称和悬停提示说明当前选择。
- “浏览器默认”项始终保留，不可删除或由自定义引擎替代。搜索输入和本地候选检索不发起网络请求。
- 可以显式选择必应、Google、DuckDuckGo 等其他搜索选项，或新增、编辑、排序和删除自定义引擎；界面提交前清楚显示当前选择。OwnTab 不再预置百度额外选项；旧配置／备份／同步中仅移除标识为 `baidu`、规范化后名称为“百度”且模板仍等价历史预置的记录，其他标识自建项及名称／模板实质修改项保留。仅首尾空格、URL默认端口等规范化差异不视作实质修改；迁移重复执行结果一致，不新增字段或改变用户引擎标识。
- 取消的是 OwnTab 预置额外项，不改变用户浏览器设置；若浏览器自身默认提供商为百度，浏览器默认入口仍按 Chrome Search API 正常执行，不做隐式拦截或替换。
- 非默认引擎选择只作用于当前新标签页，不持久化为下次新标签页的默认选项。保存的是引擎配置和排序，不是替换浏览器默认项的偏好。
- 官方 FAQ 允许多搜索选项，但要求顶部或默认选项尊重浏览器默认设置，并未细述非默认选项的具体提交实现。每次新标签重置到“浏览器默认”是 OwnTab 的保守实施策略，不将其表述为官方明确要求的重置机制。非默认引擎 URL 提交在上架前仍需结合实际实现复核。
- 自定义模板只允许 HTTP 或 HTTPS，使用一个 `{query}` 占位符，且只能出现在路径段或查询参数值中。协议、主机和端口固定；占位符不得出现在协议、主机、端口、用户信息或片段中。
- 提交时按占位符所在部分编码关键词，确保关键词不能改变目标的协议、主机或端口，也不能插入额外参数；模板不执行脚本。
- 默认搜索使用 Chrome Search API，不手拼固定引擎 URL；用户显式选择其他引擎时才按其模板直接访问目标。不经过 OwnTab 服务，不使用 `chrome_settings_overrides.search_provider`，不修改浏览器默认搜索引擎。
- 不保存搜索历史，输入过程不请求联想词、纠错或其他在线接口。

### 搜索引擎图标

- 必应、Google、DuckDuckGo使用随扩展打包的官方彩色Logo，选择后搜索栏仅显示Logo和下拉箭头；内置身份与实际模板来源都匹配时才使用对应品牌，改到其他来源不沿用旧品牌。
- 浏览器默认搜索使用放大镜，不显示提供商文字或猜测浏览器默认引擎的Logo。所有下拉项保留名称；自定义无图标时列表用地球，选中后显示名称。有图标则选中只显示图标，加载失败也有回退。
- 添加或保存修改时自动尝试获取自定义图标，权限请求在原始手势中针对实际来源发起；根首页与同源图片沿用既有网站识别的安全限额和处理规则，不发送模板路径、关键词、Cookie或来源页。
- 图标请求失败不回滚引擎、不阻止保存或搜索。输入框Enter添加引擎，输入法组词确认不提交整个设置。
- 图标按来源存于独立本地缓存，最多32个来源，不进入配置、同步或ZIP；缓存不可用时允许本次会话显示。既有、导入或同步配置只查缓存，不批量静默联网。

### 已保存网址检索

- 本地候选仅来自用户已保存的网址，匹配名称和域名，展示桌面或文件夹位置以区分同名项。
- 支持中文子串和不区分大小写的英文匹配；拼音及首字母匹配不作为首版必需项。
- 候选列表支持方向键选择、Enter 执行、Esc 关闭；无候选时仍可直接提交网络搜索。
- 在没有选中本地候选时，Enter 执行清楚标示的默认动作；界面区分“搜索”和“打开网址”。
- 明确包含 HTTP 或 HTTPS 协议，或可明确识别为域名的输入，可提供直接访问动作；其他内容按搜索处理，不在输入时预访问候选地址。
- 只打开用户明确提交或选中的目标，不自动启动多个网页。

## 外观

- 沿用方案 3 的全屏背景、中央搜索与下沿网站导航结构，按最新反馈移除包围网站区的整块背景卡片，网址图标和名称直接显示在背景上。内置背景应有可说明的来源或授权；不复用其他产品的品牌标志。
- 新安装默认使用 Bing 每日背景，提供随插件打包且来源可说明的内置背景、纯色和渐变背景。不提供用户壁纸上传。
- 提供浅色、深色和跟随系统三种主题；跟随系统不发起网络请求。
- 支持背景遮罩或模糊、图标形状与大小、网址名称显示和基本文字样式。
- 无论背景如何变化，搜索框、网址名称和操作控件都应保持可读；背景加载失败时保留可用的基础主题。
- Bing 背景只在本机缓存，不上传至 OwnTab、不进入浏览器同步或新备份；旧版用户壁纸选择在加载或恢复时迁移为 Bing 模式。既存旧资产不立即销毁，旧备份仍须校验，但不再导入壁纸资源。
- 重置外观只影响外观设置，不删除网址、文件夹或自定义搜索引擎。
- 默认减少持续动画，响应系统的减少动态效果偏好。

### 视觉语言与本机时间日期

- 参考 Apple HIG 的清晰层级、有限字重、统一圆角、充分间距和克制的透明材质；网页实现保留跨平台的交互习惯，不宣称是原生 Apple 系统材质。
- 玻璃或模糊效果集中在搜索框、菜单和弹窗等功能表面，不为所有网址添加背景卡片；菜单与弹窗使用足够实的底色，避免复杂 Bing 图片降低可读性。
- 使用本机系统字体和打包图标，不加载在线字体，不打包 Apple 字体或品牌资产。网址名称保持清晰的文字层级；图标缩小不能同时缩小至难以点击的操作区域。
- 搜索栏上方默认显示小时、分钟及日期，提供隐藏开关。按设备本地时间和时区显示，不请求网络授时、地理位置或日历，不显示秒针、天气、倒数日或问候语。
- 页面从隐藏恢复可见时及时刷新时间，跨日日期更新；显示开关属于可同步外观设置，当前时间和设备时区不写入同步或备份。
- 下拉选择使用统一样式的 React 控件，保留明确标签、当前值、打开状态、键盘方向键／Home／End、Enter 选择、Escape 取消及可见焦点；长列表与窄窗口可以滚动，不让弹层超出可用区域。
- 按钮、输入框、开关、选项和弹窗采用统一样式及状态反馈。交互动画简短，减少动态效果时不依赖动画传达结果。

参考依据为 Apple 官方 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Typography](https://developer.apple.com/design/human-interface-guidelines/typography)、[Layout](https://developer.apple.com/design/human-interface-guidelines/layout) 与 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)，于 2026 年 10 月 19 日查阅。具体网页尺寸和 CSS 为 OwnTab 的实现选择，不把 Apple 原生平台的建议数字直接当作网页规范。

### Bing 每日背景

- 图片信息固定来自 `https://www.bing.com/HPImageArchive.aspx`，图片仅允许同一 HTTPS 主机的 `/th` 地址。所有脚本和业务逻辑仍随插件打包。
- 背景请求使用省略凭据、不发送来源页的策略；不携带导航、搜索词、图标或用户配置。Bing 仍会收到 IP、时间和请求路径等连接信息，界面和隐私说明不得宣传为匿名或零联网。
- 各设备按日刷新信息，在独立 IndexedDB 中缓存单张图片；命中当日缓存时复用，不为每次新标签重复下载。失败后冷却 15 分钟，优先使用旧缓存，再回退内置背景，不阻塞搜索或导航；页面重新可见或定时检查也需尊重缓存和冷却。
- 显示接口返回的版权说明及可验证的来源链接；纯数据处理，不渲染远程 HTML 或执行脚本。
- 用户可主动刷新，或改选内置、纯色、渐变；不在 Bing 模式时停止后续每日背景请求。缓存不代表用户壁纸收藏或图库。
- 接口可访问、返回 `wp` 字段或插件免费均不构成使用许可；具体图片的展示、缓存和署名条件属于发布核查项。

## 布局

- 使用网格布局，不提供任意坐标的自由画布。
- 支持调整每行图标数量、内容宽度、图标大小和图标间距；不提供分组导航。
- 新安装默认网站图标为 64px、间距 24px、内容最大宽度 1120px、每行 8 个；每行数量可在 2 至 12 个之间调整。支持的旧配置、备份和同步副本缺少此选项时补为 8，保留已有个性化尺寸，不把设计更新当作重置用户配置。上述数值为 OwnTab 的网页设计参数。
- 用户设置的每行数量作为目标列数；可用宽度不足时减少实际列数，避免挤压图标或横向溢出。调整窗口或样式只改变排列方式，不改变用户保存的逻辑顺序。
- 文件夹打开后提供清楚的返回路径，关闭后保留原来的桌面位置。
- 页面、弹窗或菜单过长时可以正常滚动，隐藏默认滚动条；不以禁用滚动裁掉图标、编辑菜单、设置或文件夹内容。
- 主要操作在窄窗口和放大显示时仍可使用；长网址、长名称、空内容和大量内容均有明确表现。
- 支持通过明确的极简开关隐藏网址区域，只保留搜索和背景；提供持续可发现的恢复入口。

## 页面和主要操作

首页只围绕本机时间日期、搜索、桌面网格、文件夹、网址和编辑入口组织，不增加分组切换、问候语或信息卡片。沿用方案 3 的总体构图，并按最新反馈移除网站区背景卡片、左上标题、图标角落菜单按钮与常驻拖拽提示，缩小默认图标并收紧搜索和导航间距；时间日期默认开启且可隐藏。

首次打开时，用户可以使用搜索、六个普通默认网址或右上角添加入口。没有 Covelet 登录引导或推广内容，不提供显式新建文件夹入口；书签导入位于设置→数据。原生同步默认关闭，只在用户主动启用时说明浏览器账号要求。

| 操作 | 主要过程 | 结果 |
| --- | --- | --- |
| 添加网站 | 输入 URL，按站点授权自动识别名称和图标，按需手动修改后保存 | 当前桌面或文件夹出现该网址，重新打开后仍保留；未授权或识别失败仍可手动添加 |
| 整理网站 | 叠放建文件夹、拖入／拖出及边缘排序 | 内容不丢失，位置与顺序清楚可见 |
| 使用搜索 | 输入内容，保留浏览器默认或显式选择其他引擎、本地候选，提交 | 默认搜索走 Chrome Search API，其他目标明确可见，提交前不联网 |
| 更换背景 | 选择 Bing、内置背景、纯色或渐变 | Bing 按日获取并在本机缓存，其他背景离线生效，内容保持可读 |
| 调整布局 | 修改每行数量、宽度、尺寸与间距 | 重新排布，网址逻辑顺序不变 |
| 完整恢复 | 选择备份文件，校验并预览，确认替换 | 恢复配置和网站图标；壁纸按选择由设备自行获取 |
| 启用原生同步 | 阅读浏览器账号及数据接收方说明，打开开关 | 提交可移植配置，展示同步状态或失败原因，本地数据保留 |

设置只承载导航、搜索、外观、布局及数据管理。帮助和关于页面说明版本、开源信息、隐私行为和权限用途。

## 数据和隐私

### 本地数据

- 桌面中的文件夹、网址、排序、搜索引擎配置、外观与布局设置以本地为主副本；非默认引擎的临时选择不保存为下一次的默认项。
- 获取到的站点图片和旧版合法本地图标作为本地资源管理，不依赖原始文件路径；图片不进入同步，远端显示文字图标。图标背景色随网址／文件夹配置正常保存、备份和同步。Bing 缓存单独管理，不作用户壁纸保存。
- 多个 OwnTab 标签页之间同步本地改动。已打开的编辑表单遇到同一记录变化时提示冲突，不静默覆盖其他页面的新内容。
- 保存失败时明确显示失败，并保留可重试的用户输入，不把失败状态显示为已保存。
- 本地数据不等于独立备份。卸载扩展、更换浏览器配置或设备前，需要导出完整备份。

### 浏览器原生同步

- 默认关闭；通过数据设置中的明确开关启用，不创建 OwnTab 账号或服务器。启用前说明网址等配置将交给浏览器厂商，用户需登录浏览器并开启相应同步；不承诺 Chrome 与 Edge 账号互通。
- 使用 `chrome.storage.sync` 同步桌面网址、文件夹、排序、搜索引擎配置及可移植外观／布局设置，包含每行图标数量。主题和背景模式可以同步，Bing 图片由各设备独立获取；旧同步副本的分组兼容数据合并后不重新显示分组界面。
- 不同步图片二进制及本地资产引用、Bing 缓存、快照、备份、搜索文字或本机同步开关。远端自定义图片图标以文字回退，不产生失效资源。
- 以每设备独立副本、分片和完整性提交头传输配置；使用逻辑计数及因果信息合并实体，外观布局按字段合并。不同设备新增的记录都保留；删除保留记录，避免旧设备让条目重现；同项并发修改保留可恢复的冲突版本。
- 预检 Chrome 的总量 100KB、每项 8KB、最多 512 项及写频限制，持久化至少 10 秒的发布间隔，避免开多个页面或重启后绕过节流。分片不能突破总量，设备副本、删除记录及分片元数据也占容量，不承诺本地最大条目数均能同步；容量不足、同步关闭或网络不可用时不截断本地数据，明确显示状态和可重试错误。
- 成功写入同步存储不代表其他设备已经接收，界面不得作此保证。离线先保存本地，恢复后合并；没有 OwnTab 服务端的即时送达或在线设备检测。
- 关闭开关停止 OwnTab 后续同步行为，不宣称浏览器厂商的云端副本已删除；用户通过浏览器数据控制管理云端记录。ZIP 仍用于独立备份及无法使用原生同步的迁移。

### 完整备份和恢复

- 完整备份使用带版本号的 OwnTab ZIP 文件，包含配置清单、网址与容器数据、引擎、布局、外观及被引用的自定义网站图标；不包含 Bing 缓存或用户壁纸。
- 资源与配置之间有可校验的引用关系，不产生失效的图标引用。Bing 模式恢复的是模式配置，不保证另一设备显示同一张图片；旧壁纸配置按迁移规则转为 Bing。
- 完整恢复采用校验后整体替换，执行前展示摘要并说明覆盖范围；设置中的书签HTML导入采用增量添加、同位置去重并保留现有内容。
- 恢复前保留上一份本地快照；损坏、缺失资源、未知版本、超限或恶意文件均在替换前拒绝，原数据保持可用。
- 普通数据变更保留有限的本地恢复快照，具体数量和容量在实现前确定。快照也保存在扩展内，不能替代导出文件。
- 插件升级需要迁移旧版本数据，迁移失败保留原数据并提供恢复路径。

### 网络行为

| 行为 | 插件是否发起网络请求 |
| --- | --- |
| 新安装默认 Bing 背景、Bing 模式按日刷新 | 向 `www.bing.com` 请求信息和图片，本地缓存 |
| 新增网站的名称和图标识别 | 用户授予目标来源权限后，直接请求目标来源根首页和同源图标；不发给第三方代理 |
| 手动编辑、整理网址和输入搜索文字 | 本地处理；开启同步后，可同步配置通过浏览器服务传递，搜索输入不传递 |
| 更换内置、纯色、渐变背景及调整样式 | 不因背景资源联网；开启同步后，相关配置可同步 |
| ZIP备份导出和恢复 | 文件解析和打包在本地；恢复后的配置可按已开启的同步／Bing模式正常工作 |
| 用户提交网络搜索或打开网址 | 直接导航至用户选择的目标 |

搜索引擎和被访问网站会按各自方式处理用户主动发送的信息。OwnTab 在本机处理必要内容，不向开发者上传搜索词、网址列表、图片、设备标识或使用记录。

“不上传给开发者”不等于“不处理用户数据”。保存网址、图片和设置仍是本地用户数据处理；依据 Chrome Web Store 用户数据规范，隐私政策及商店隐私表单必须如实披露。具体说明见[隐私说明](隐私说明.md)。

插件不包含遥测、统计、广告、追踪、崩溃自动上报、在线字体、第三方图标代理或图标 CDN、远程内容 iframe 或公告 API。浏览器原生同步是用户主动开启的功能，接收方是浏览器厂商；Bing 是默认壁纸请求接收方，网站识别请求的接收方是用户授权的目标站点。浏览器自身的商店更新通信不属于插件页面或后台的请求。

反馈仅在用户主动发起时进行，不自动附带本地数据。有效项目地址和反馈渠道确认后再提供入口，不填写未经确认的联系方式或发布链接。发布材料公开权限用途、隐私行为和数据格式变更。

## 工程约束

首版工程目标为 Chrome 和 Edge 的 Manifest V3 扩展，页面和依赖随扩展包发布，无业务服务器。Firefox 等浏览器的发布与兼容验收另行安排。

扩展工程本轮采用 WXT 0.21.4，原因及与 Plasmo 的对比见[框架选型](框架选型.md)。框架迁移只负责扩展入口、开发和打包，不改变现有 React 产品界面、原生同步协议、搜索 API 或权限用途；普通网页预览与既有 Sites 脚手架继续保留。正式入口为包内 `newtab.html`，Manifest 唯一源为 `app/extension.manifest.json`；生产输出保持原路径。迁移结果以最终产物、静态检查及运行记录为准，不因框架支持多浏览器就宣称 Firefox 已兼容。

- 使用 `chrome_url_overrides.newtab` 指向包内页面替换新标签页，不用标签监听与重定向绕过 URL Overrides API；保持首屏轻量，不让首屏等待网络或完整图片解码。
- 配置以扩展本地存储为主，用户启用后将可移植配置同步到浏览器原生存储；图标采用本地二进制资源，Bing 图片采用设备缓存。容量不足时明确提示和保留原数据。
- 功能权限为 `storage` 和 `search`：前者用于本地及浏览器同步配置，后者用于默认搜索。Bing 图片功能使用 `https://www.bing.com/*` 必需主机权限。网站识别在 `optional_host_permissions` 声明 HTTP／HTTPS 可选范围，运行时只通过用户手势申请实际目标的来源权限；不请求所有来源的整体授权，不读取浏览历史、后台标签页或地理位置。用户可在浏览器扩展权限页面撤销已授予的站点访问。
- 书签仅通过用户选择HTML文件导入，不读取或修改浏览器书签库；工具栏收藏当前页等集成功能不进入本版。
- 自定义引擎、备份和恢复内容均作为数据处理，不执行其中的脚本。
- 图片、导入记录及解压资源均设置明确的体积、数量和解码尺寸上限；限制值在实现前确定并在界面说明，超限不损坏已有数据。
- 导入校验包含协议、字段、容器关系、重复标识、资源引用、ZIP 路径和解压总量。
- 开发时实测启动、拖拽和大量网址表现，记录设备、浏览器和数据规模，再确定发布性能门槛，不用主观“丝滑”代替测试结果。

工程参考：[Chrome 新标签页覆盖](https://developer.chrome.com/docs/extensions/develop/ui/override-chrome-pages)、[Chrome Search API](https://developer.chrome.com/docs/extensions/reference/api/search)、[扩展存储](https://developer.chrome.com/docs/extensions/reference/api/storage)、[权限声明](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)。上架规则和证据见[Chrome 上架与搜索规范](Chrome上架与搜索规范.md)。

## 推进顺序

1. 按已选方案3及最新精简要求实现空桌面、网格加号、已有网址、拖拽文件夹、搜索候选、添加编辑、样式设置、设置中的书签导入和ZIP恢复预览；默认搜索固定为浏览器默认，完善视觉参数。
2. 实现四个模块的本地使用闭环，同时确定容量限制、快照策略和数据格式。
3. 保持 Bing 每日背景和浏览器原生同步，完成取消分组的兼容迁移、拖拽文件夹及按网址识别；补齐异常恢复、多标签和键盘操作，再进行 Chrome、Edge 的真实扩展及多设备同步验收。
4. 完成权限、网络、数据安全和性能验证后准备商店发布材料。发布动作另行执行。

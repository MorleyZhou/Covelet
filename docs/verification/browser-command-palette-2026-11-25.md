# 命令面板浏览器入口验证（2026-11-25）

设计与权限说明见 [browser-command-palette.md](../browser-command-palette.md)。本轮没有发布、提交商店或修改 0.6.0 版本号；沿用工作区已有改动，不把之前任务的结果算成本轮验收。

## 验证方式

- 单元测试使用项目现有 Node 测试入口，覆盖会话保存、规范化去重、CAS、容量拒绝、恢复预览、三批恢复、取消和失败重试。
- 存储边界测试使用现有加密存储实现，核对会话 URL 不以明文进入 IndexedDB 后端，且上传、接收和替换同步快照均不能带入或移除本机会话。
- 浏览器验收使用隔离 Chrome 配置和实际 unpacked 扩展，通过原生 CDP 驱动生产界面；不使用 Playwright。脚本交互与人工逐项签收分开记录。
- 不读取用户现用配置的历史或书签；测试标签、历史和书签均由隔离配置生成。

## 权限与数据范围

`tabs`、`history`、`bookmarks` 仅声明为可选权限。必需权限及主机权限保持原有范围；授权按钮直接由用户操作触发。浏览器搜索结果只在面板中短暂存在，不写入存储；用户主动保存的链接会话使用现有 `localData` 加密主副本，明确排除云同步、普通导出和现有完整备份。

隐私窗口、内部页面、扩展页面、不支持的 URL 协议和含用户名或密码的 URL 不进入会话。保存窗口保留全部原标签；恢复每次最多新增 10 个后台标签，跨普通窗口去重。

## 人工复验步骤

1. 在隔离 Chrome 配置加载 `app/dist/extension`，打开 30 个不同 HTTP(S) 页面，其中两个固定；另保留 Covelet 新标签页。
2. 打开命令面板，选择“打开的标签页”。首次点击“授权此来源”，按标题和 URL 查询，用上下键、回车切换一个标签，再用独立的“关闭标签页”按钮关闭测试标签。
3. 分别选择“浏览历史”和“浏览器书签”，确认各自需要单独授权，且查询只展示相应来源的结果；拒绝授权不影响“内容与操作”。
4. 选择“本机会话”，点“保存当前窗口”，输入名称，预览后确认保存。核对 30 个有效链接、原标签仍在，Covelet 内部页面被排除。
5. 打开恢复预览后先取消，核对没有新增标签。关闭这 30 个测试标签后重新预览，每次确认仅新增 10 个后台标签，三批共恢复 30 个；核对 URL 集合、固定状态和当前焦点。
6. 再恢复同一会话，应跳过已打开的链接。尝试仅选择一部分链接，更新预览后才能确认恢复。
7. 重命名，重启浏览器，核对会话名称和链接仍在；删除须确认，已打开的标签不随之关闭。
8. 使用系统中文输入法组合文字，在组合过程中按回车和 Esc，确认不会执行结果或关闭面板。组合结束后上下键、回车和 Esc 正常工作。此步需要真实输入法人工复验，不能由 DOM 组合事件代替。

## 真云图片与故障路径

两份空白、独立的 bundled Chromium 配置加载实际扩展。通过生产恢复 UI
导入两张可解码的合成 PNG，每张大于 **256 KiB**，需要多个加密分片；通过
便笺 UI 创建正文。使用生产「导出完整备份」下载持久化内容，对图片重新计算
SHA-256，并比较两边的站点、便笺正文及文档内容。

验证离线修改仍保留本机内容，出现可操作错误；联网后重试，两边内容一致。
随后让真实 GitHub 接受一个分片写入，确认 **2xx** 后在客户端丢弃响应。
错误后本机图片和便笺不变、待上传内容仍在。完全关闭浏览器后重新打开，
凭据为空；显式解锁并同步后，实际 GET 的原密文 SHA 与首次写入一致，该
对象写入次数仍为 **1**，两边图片字节与便笺内容一致。再同步不新增写入。

这是**实际云存储读写与受控客户端网络中断**，不是自然网络故障统计。
测试临时副本只预授予精确测试 origin；生产 manifest 不增加授权。
原生 Chrome/Edge 权限弹窗、OS 输入法候选窗及两台物理机器仍未在本轮验证。
整体入口继续显示「自备存储同步（Beta）」。

新增十条确定性故障测试还覆盖四个 HTTP 适配器的第二图片分片读取失败
（离线、超时、404、篡改）及迟到写入响应。失败整批不 apply、不上传，
本机 note 与 Blob 字节不变；pending 重启复用密文，中途锁定需重新解锁。
这些合成测试不冒充其他服务的本轮真云结果。

## 复验与产物

从 `app/` 执行：

```powershell
npm test
npm run build:unpacked
npm run check:extension
npx playwright install chromium
npm run test:e2e
$env:COVELET_QA_CONFIG = (Resolve-Path ../output/playwright/covelet/live-config.local.json).Path
npx playwright test --config tests/playwright-live.config.mjs
```

日志、浏览器报告、合成截图与图片 SHA 证据位于被 Git 忽略的
`output/playwright/covelet/`。真云不记录凭据、请求正文、trace、截图或自动
失败 ARIA 快照；失败诊断仅含阶段、方法/状态计数及应用过滤后的错误。
本轮检查曾发现：R2 补测失败的本机快照仍含凭据字段，已在提交前脱敏，
没有上传。原来的环境开关只覆盖普通快照；现也将带表单快照的断言异常
替换为无 cause/matcherResult 的脱敏普通错误，并通过假凭据失败回归验证。
GitHub 合成 QA 分支与正常测试的本机配置目录会清理；没有删除用户原同步目录。

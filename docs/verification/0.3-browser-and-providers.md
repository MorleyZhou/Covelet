## Prepare remaining live services

Edit the ignored `output/playwright/covelet/live-config.local.json` on this
machine; never paste it into chat, a PR or an attachment. It contains disabled
templates for GitLab, R2 and OSS. Fill the dedicated resource and credential
fields, then set the desired provider's `enabled` to `true`. An optional
`sessionToken` field supports temporary R2/OSS credentials. GitLab project may
be an ID or full namespace path; Git branch must already exist.

- GitLab: private initialized test project/branch and dedicated API token.
- R2: private dedicated bucket, account S3 API endpoint and bucket-scoped object
  read/write credentials.
- OSS: private dedicated bucket whose versioning has **never** been enabled,
  bucket endpoint/region and object read/write, listing and GetBucketVersioning
  permissions. Keep the bucket's versioning policy unchanged during sync.

Run in PowerShell from `app/`:

```powershell
$env:COVELET_QA_CONFIG = (Resolve-Path ../output/playwright/covelet/live-config.local.json).Path
npx playwright test --config tests/playwright-live.config.mjs
```

Disabled providers are reported as skipped/blocked, never passed. The suite
leaves encrypted synthetic objects under its unique QA prefix for R2/OSS/GitLab;
remove only that exact run prefix after inspection. Do not use production data.

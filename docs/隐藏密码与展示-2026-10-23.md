# 隐藏密码与导航展示

隐藏功能使用本机密码解锁。首次开启时设置并确认 8–256 个字符的密码；以后开启可直接隐藏，关闭则需验证。首页开关、隐藏导航、隐藏组件、被遮蔽的编辑窗口和工具栏弹窗共用验证逻辑。取消、Escape、错误密码或写入失败均保持当前隐藏状态；刷新、新标签页以及重新启动测试浏览器后保持隐藏。2026-10-23 的后续修正将隐藏范围限定到已标记内容，具体见文末；产品不再设置独立的“展示模式”。

隐藏网站和文件夹沿用普通导航的纵向结构：匿名锁图标居中，统一文案在下方，保留原网格位置，不展示名称、域名或数量。组件保留原占位和已挂载的运行／编辑树，显示对应尺寸的锁定表面。点击占位进入密码输入。文件夹子项、私密别名和便笺继续从展示及本地搜索中排除。

密码设置后，可在“设置 → 搜索 → 内容别名与隐私标记 → 修改隐藏密码”中修改，须验证当前密码。没有免密重置并显示内容的入口。旧版已隐藏但尚无密码的安装先设置密码，设置成功仍保持隐藏，然后通过密码解锁。

## 存储与边界

- `covelet.privacy.lock.v1` 独立保存随机 16 字节盐、PBKDF2-SHA256 210,000 次派生的验证值，以及失败次数／重试时间，不保存明文密码。派生盐具有独立的隐私锁用途前缀。
- 设置、验证、密码修改与隐藏状态写入共用内容偏好的跨页面事务锁；首次设置的验证值与隐藏开关在一次原生存储调用中写入。两个页面不能互相覆盖首次设置的密码。
- 连续五次验证失败后，等待 30 秒再尝试；失败记录保存在本机，重新打开弹窗不会清零。成功验证清除失败记录。
- 实际隐藏状态 API 要求解锁凭据。隐藏时可以正常编辑公开内容偏好，但不能通过偏好编辑或备份恢复移除受保护内容的私密标记；恢复不替换本机密码或隐藏开关。
- 密码验证值不进入导航同步、工具加密同步、桌面分享、完整备份或恢复点。备份仍可能包含用户主动导出的私密内容。
- 这是本机界面的可见性控制，内容存储本身未因此加密；不承诺对浏览器配置文件、开发者工具或直接修改扩展存储提供加密保护。密码无法找回。

## 追加修正：隐藏时的拖拽

用户反馈开启隐藏后无法拖拽。原因是原实现同时移除了所有条目的拖拽事件，并关闭拖拽预览与跨屏落点。现恢复普通导航、匿名网址／文件夹／组件以及公开文件夹内条目的直接拖动；隐藏模式仍保留密码验证和私密标记。

匿名网址和文件夹的拖拽预览只绘制锁图标；隐藏组件的冻结预览移除整个隐藏内容子树，原运行／编辑树继续挂载。公开文件夹的预览仍过滤私密子项。隐藏条目可调整位置与跨屏移动；隐藏时不允许通过匿名条目合并或移入文件夹，以避免显示文件夹名称或改变继承的私密范围。拖动结束后抑制紧随的点击，不打开网址或密码窗口。其他页面切换隐藏状态时取消手势，并立即拒绝展示此前状态的预览。

`node --test src/lib/desktop-layout.test.js src/lib/content-preferences.test.js`：12 项相关回归通过。独立解压版扩展中验证普通网址、隐藏网址、隐藏文件夹、大于单格的隐藏便笺组件、迷你隐藏时钟组件移动，公开文件夹预览与普通分组，匿名分组保护、文件夹内公开和匿名条目排序、移回桌面、悬停跨屏后在目标网格落下、刷新持久化、拖后密码验证，以及跨标签页切换隐藏时取消拖动。未启动本地服务。证据在 `output/playwright/privacy-drag-20261023/`，解压目录已更新；未更改冻结发布包或商店状态。

## 追加修正：仅锁定已标记内容（2026-10-23）

隐藏是内容级别的开关，不是限制整个桌面的“展示模式”。开启后，只有已标记的网站、文件夹及其子项、组件、便笺和稍后读记录不可打开或编辑；对应内容继续从公开预览、搜索结果和回收站列表中过滤。匿名占位保留原位置与尺寸，并可继续调整位置。取消隐藏仍须验证本机密码，不因恢复公开功能而绕过验证。

公开网站、文件夹和组件保持正常操作；添加、设置、导入导出、桌面方案、布局编辑、撤销重做、恢复与版本历史、工具栏快捷添加、公共便笺与稍后读、回收站和已配置的同步均可照常使用。隐藏开关不会停止既有的组件运行或同步任务，也不会改变浏览器权限与用户的同步开关。主动导出的完整备份仍可能包含已隐藏的内容，不能把隐藏理解为备份脱敏或数据加密。

其他标签页开启隐藏时，只遮蔽当前正在编辑的已标记内容，公开编辑窗口和未保存的公开草稿继续可用。受保护编辑器及其草稿保留在当前页面内存中，解锁后可继续；关闭或切换涉及未保存修改时仍需确认。稍后读的隐藏草稿可经明确的放弃确认退出，以继续添加或编辑公开链接。草稿不会因隐藏而自动上传或保存到持久存储，关闭页面不承诺恢复尚未保存的草稿。

回收站只隐藏对应的已标记便笺与稍后读条目。隐藏期间确认“清空回收站”只删除当时可见的条目，保留被隐藏的条目；操作仍校验工具数据修订，避免覆盖其他页面的修改。公开内容的确认、错误提示和选择控件不会因为隐藏其他内容而失效。

# Covelet 0.4.4 开发批次验收

本批实现动态清单和链接列表整理，分支为 `feature/0.4.4`，从上一批已合入的 `main` 提交 `c8e5c4f` 开始。包版本继续保持 0.4.0，不发布或提审。 [分支计划](../0.5.0%20功能范围.md)

## 功能结果

- 动态清单保存查询文字、内容类型、标签交集、桌面或文件夹范围、精确域名和阅读状态。重新打开时计算当前内容，新收藏自动匹配。列表中的「全部」保存为网站与文件夹范围，不扩大为其他内容。
- 清单可新建、修改、改名、独立隐藏和删除。删除清单保留内容。失效的标签或位置引用保留在条件中，返回零结果并提示修正；不会自动删除条件后扩大范围。
- 桌面范围绑定稳定 ID。未有 ID 的桌面只在用户确认保存时分配，取消不修改导航；保存身份与清单在同一事务完成。
- 链接列表支持名称或备注检索、类型、标签、域名及位置筛选，本地排序和每页 50 项。结果不受搜索建议的 100 条上限限制。文件夹子项按所属文件夹的实际桌面定位。
- 网站可多选处理标签，移动或复制到桌面或文件夹。批量标签保留备注及未涉及标签，移动保留源文件夹，复制建立独立元信息，私密继承不会丢失。
- 排序只改变展示；纯元信息操作不推进导航修订号或挤占历史快照。批量操作在导航和偏好锁内校验存在性、隐私及版本后原子提交。

清单采用单一内容类型和单一位置范围，各条件取交集。最多 50 条清单，名称 80 字符、查询 2000 字符、最多 20 个标签，计入现有 1 MiB 元信息库限制。清单独立版本号保护同条目并发，不能通过刷新全局偏好版本覆盖另一页的新修改。

## 备份与兼容

完整备份和同步保留清单。追加恢复映射标签及桌面 ID，已有同 ID 清单保留本机内容。即使导入桌面的链接全部因重复而未追加，也不会把来源清单错误绑定到本机同 ID 桌面。工具 JSON 仍只迁移便笺与稍后读，排除并拒绝清单字段，保留接收设备已有清单。

使用上一开发批次 0.4.2 的真实模块及合成远端，验证普通同步和重试。共享基线遇到新字段时拒绝，独立偏好或并发修改停在冲突，均保全两端且远端写入为零。该检查没有使用真实云账户，也没有执行显式整云覆盖；同步设备应统一升级后再处理冲突。

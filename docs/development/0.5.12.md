# Covelet 0.5.12 开发批次

分支 `feature/0.5.12` 从已推送的 `main` 提交 `5e06f82` 开始，实现 06 桌面独立外观及 11 Markdown 资料库导出。包版本在这一最终候选批次统一更新为 **0.6.0**；不创建 PR、运行 Actions、打标签、发布或提审。[完整范围](../0.6.0%20功能范围.md)

## 实现

- 设置中选择全局或具体逻辑桌面的外观。桌面背景、遮罩、模糊分别覆盖或继承，明确保存；未保存修改在换范围、设置分类或关闭时确认放弃。保存按原身份与版本校验，不通过浅合并整组桌面元数据覆盖其他修改。
- 实际背景、遮罩、模糊、颜色适配与署名使用当前逻辑桌面的有效值；响应式子页保持相同身份和外观。全局或任一桌面使用随机背景时维持同一设备照片租约，切换桌面只复用现有图片，来源和轮换周期不进入局部配置。
- 局部配置进入导航、本机加密数据、完整备份、恢复点和同步；旧模型安全拒绝新字段。既有桌面方案只有数据 API，新增明确选择的公开相对外观字段和严格验证，不新增分享界面。[配置与兼容说明](../桌面独立外观.md)
- 命令面板和备份设置中增加 Markdown 资料库导出。网站、稍后读、便笺分别进入类型目录，包含索引、标题、URL、备注、标签及适用状态和日期；导航桌面/文件夹原路径保存为属性和索引文字，便笺保持平面结构。
- YAML 安全序列化；文件名处理 Windows 保留名、UTF-8 长度、大小写和规范化碰撞，相对链接另行编码。`covelet_tags` 保存全部标签原名，已确认符合规则的名称同时写入原生 `tags`，其他名称明确提示仅作为属性保留。
- 预览与导出使用导航→偏好→工具一致快照，检查版本及规范内容，始终排除直接或继承标记隐藏的记录，即使已解锁。标记变化在绘制前关闭旧预览；普通并发变化保留选择并要求重新预览。
- 复杂便笺、图片等无法完整表达的条目有明确提示，默认仍被选中并阻止导出，须用户明确取消选择或使用完整备份。文件上限 512 KiB、总解压上限 80 MiB、ZIP 上限 30 MiB，最多 2,701 文件；不下载附件或原网页。

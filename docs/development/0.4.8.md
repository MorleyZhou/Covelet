# Covelet 0.4.8 开发批次验收

分支 `feature/0.4.8` 从 `main` 的 `c42fac1` 开始，实现网页选文便笺和 Markdown 便笺交换。包版本继续保持 0.4.0，采用本地自测、直接合并和推送流程，不创建 PR 或运行 Actions，不发布或提审。 [分支计划](../0.5.0%20功能范围.md)

## 功能与边界

工具栏增加独立的便笺目标。明确选择该目标或点击读取后，只读取主框架选中文字、页面标题和 HTTP(S) 来源。选文中的 HTML 和 Markdown 都按普通文字保存，来源的完整网址作为可搜索的文字链接。没有选文、受限页面、框架选区或读取失败时可手工填写。切换、重新读取和取消保护未保存草稿，不因预览建立标签或保存记录。

选文复用已有 `activeTab` 和 `scripting`，没有新增权限、内容脚本、网页全文归档或后台采集。主框架导航、同网址重载及取消会拒绝迟到的捕获结果。标签只允许从当前可见的已有标签选择；锁定后不可见的选择会移除，偏好版本冲突不通过刷新版本后直接覆盖。

Markdown 支持标题、段落、列表、任务、引用、代码、链接和常用文字格式。导入最多 50 个 UTF-8 文件，每个 512 KiB、总计 5 MiB，另受现有便笺和工具容量限制。首个一级标题作为便笺标题并移出正文，没有一级标题时使用文件名；导出将独立标题放回一级标题。图片转成文字或链接并预览数量，不加载图片；相对路径保留为普通文字。HTML、表格及不支持的复杂块明确拒绝，不截断或部分导入。

导入先预览，再用固定版本整批新增独立 ID，不按文件名覆盖旧便笺。任一文件错误、容量不足、并发冲突或存储失败均不部分写入。预览对象不可变且仅在当前页面有效；取消零业务写入。

现有 Folio 0.2.1 的无损转换器还不能原样导出普通段落内开头、结尾、连续或仅含空白的换行，以及连续硬换行；代码块换行不受此限制。此类内容会整批明确拒绝，可使用完整备份。没有为绕过校验改变保存的正文或格式。

单篇导出 `.md`，多篇导出平铺 ZIP，文件名处理重名及不安全字符。先校验整批可序列化再生成文件；复杂 Folio 块或已有图片应使用完整备份。公开 Markdown 导出始终排除标记隐藏的便笺，即使当前已解锁；提交时再次核对隐私、全局版本与选择时固定的记录版本。

捕获界面及原生权限证据在本机 `output/playwright/covelet/0.4.8-note-capture/{chrome,msedge}/`，最终换行补验在同目录 `{chrome-linebreak,msedge-linebreak}/`，无页面异常或意外网络请求。Chrome 使用有界面原生 popup 验证真实鼠标取消、Escape 和手动激活标签页键盘操作；Edge 使用无界面原生 action/other target，确认框点击由 DOM 事件辅助。Edge 的 Escape 会直接关闭浏览器原生弹窗，因此没有把该项记作扩展确认框键盘验收。浏览器关闭弹窗会丢弃未保存草稿，不产生自动保存。

直接打开 `popup.html` 或测试包预授站点权限只证明保存表单，本批没有把它们作为 `activeTab` 授权证据。 [官方 activeTab 说明](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)

Markdown 五组实际文件操作、截图和下载结果在 `output/markdown-qa/{chrome,msedge}/`，两通道没有页面错误、图片下载或意外网络请求。编辑器仅忽略已证实的缺失默认属性补齐及成对生成的标题身份；任何已有 JSON 值、正文、标记或结构变化继续触发修改，不统一忽略首个事件。

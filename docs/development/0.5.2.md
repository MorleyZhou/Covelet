# Covelet 0.5.2 开发批次

分支 `feature/0.5.2` 从 `main` 的 `aeab3a8` 开始，实现 0.6.0 范围中的 01 命令面板和 02 结构化本机搜索。包版本保持 0.5.1；不创建 PR、运行 Actions、发布或提审。[完整范围](../0.6.0%20功能范围.md)

## 实现

- 命令面板提供操作与内容两组结果，支持 Ctrl/⌘+K（非文字编辑、组合输入或未完成弹窗）、可发现的按钮、方向键、回车、Escape 和焦点返回；常用设置、标签、备份、回收及同步入口复用原功能。
- 本机查询支持 `tag:`、`-tag:`、`type:`、`is:` 和 `domain:`，带空格标签使用双引号。条件可见、可单独移除或清除，保存清单时使用同一验证后的筛选结构。
- 无效语法、失效/隐藏标签不产生宽泛结果，不触发网页搜索或执行命令；清除无效条件会清空查询。已配置搜索引擎关键词仍优先保留其原始网页搜索语义，例如 `gh type:foo`。
- 排除标签字段仅在非空时持久化，普通旧清单保持原形；恢复/合并同步时重映射排除标签，缺失引用隔离，不误绑定本地相同 ID。固定的正式 0.5.1 验证器拒绝新字段，不静默删除后写回。
- 增加七种翻译，与简体中文源文共同覆盖八种界面语言；权限、外部依赖、服务来源和版本均未增加。

# Covelet 0.4.2 开发批次验收

本批实现链接备注和跨内容标签，从正式 0.4.0 之后的 `main` 提交 `fda3ad5` 开发，分支为 `feature/0.4.2`。`0.4.2` 是内部开发批次号，包版本保持 0.4.0。通过本地验收和 PR CI 后合入 `main`，继续下一批，整批到 0.5.0 后再统一准备正式包。当前不发布、不提审。 [完整分支计划](../0.5.0%20功能范围.md)

## 功能结果

- 网站和稍后读可以填写备注。新标签页与稍后读搜索能用备注找回原记录，并显示摘要。
- 网站、便笺和稍后读共用标签字典。筛选可同时选择多个标签，采用同时包含的关系，入口使用紧凑弹出层。全局标签支持改名和删除关联。
- 网站编辑、工具栏保存、便笺和稍后读保存，在同一个加密事务中提交内容及其元信息。导航复制和阅读项加入桌面会继承备注、标签及私密标记，之后各记录独立编辑。
- 继续支持完整备份、恢复前副本和可选全数据加密同步。工具自带 JSON 在需要携带备注、标签或隐私偏好时使用 v4，保留旧文件读取及只添加新 ID 的导入语义。

新增资料保存在已有的 `covelet.content.preferences.v1` 记录中，其可选 `library` 有独立格式校验。限制为最多 200 个标签、每条 20 个标签、3000 条元信息记录、备注 1000 字符、标签名称 60 字符，整库最多 1 MiB。超限在写入前拒绝。全数据同步采用分片，已验证约 700 KB 元信息通过往返。

保存同时检查整体偏好修订号和同条目原始元信息。即使编辑过程中创建标签推进了修订号，也不能掩盖另一标签页对同一内容的更新。锁定后从标签建议、搜索、列表、工具栏和复制入口排除私密内容及其独占标签，包含文件夹继承的隐藏规则。

## 旧版本与同步

使用真实 0.4.0 与新版本模块、独立本机加密存储和合成远端，验证三类场景及各自重试，共六次。旧端共享已同步基线且未修改时拒绝新格式；旧端具有独立偏好或并发修改时进入冲突。六次均保全本机业务和远端现有字节，远端写入为零，冲突中仍保留完整新资料。旧版导入工具 JSON v4 明确拒绝。

同步设备应统一升级后再处理冲突。旧版显式选择「以本地为准」会执行整份云端替换，不属于上述普通同步和重试的保全结论。本轮没有调用这一破坏性操作，也没有使用真实云账户验证认证服务。

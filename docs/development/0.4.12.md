# Covelet 0.4.12 开发批次与 0.5.0 候选验收

分支 `feature/0.4.12` 从 `main` 的 `e411602` 开始，完成搜索引擎关键词和密码加密完整备份。六批十二项功能完成后，将 package、lockfile 和 manifest 统一更新为 0.5.0，未按中间批次发布。按用户最后指令，本批只运行本地验证，直接合并及推送，不创建 PR、运行 Actions、打 tag、发布 Release 或提交商店。 [分支计划](../0.5.0%20功能范围.md)

## 功能结果

现有额外搜索引擎可设置唯一关键词，字母开头，1–20 位 ASCII 字母、数字、下划线或连字符，保存为小写。空值删除字段，旧数据不补空字段。仅「关键词＋ASCII 空格＋非空内容」识别为引擎搜索，保留查询内部文字和空格，显示目标引擎；不会改变默认引擎。显式候选、网址直达、完整桌面名定位及歧义、中文输入法优先规则保持。无效或重复关键词在保存和图标获取前拒绝。

完整备份增加独立密码导出和解锁预览，继续支持原普通 JSON 和导航 ZIP。密码不修剪或规范化，不写入设备设置、同步、日志或备份。加密备份在内存中完整认证解密，再校验 UTF-8、JSON 和所有数据域；只有用户随后确认恢复才写业务记录和恢复前副本。错密码、损坏、无效 profile、超限、无效 UTF-8 及取消均不写业务数据。原生密码派生不能中途终止，取消会丢弃迟到结果，阻止下载、预览或恢复；旧任务也不会覆盖新任务的忙碌状态。

导出及预览改用只读工具快照，不因读取清理过期工具回收记录。加密沿用完整备份的数据范围，包含图片及前五批新数据，继续排除设备密钥、会话凭据等原有设备资料。 [文件格式与参数](password-backup-v1.md)

原生性能只测浏览器密码派生和加解密，不等于完整 UI 耗时：600000 次 PBKDF2 在本机 Chrome 约 61–66 ms、Edge 约 62–67 ms；50 MiB AES 加密约 78 / 101 ms，解密约 65–67 ms。未为本机速度降低固定成本。

所有资料均为隔离配置中的合成资料，普通渲染与离线恢复没有 HTTP 请求或页面异常。没有操作日常浏览器资料、真实云账号或商店。

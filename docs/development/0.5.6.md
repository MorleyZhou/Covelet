# Covelet 0.5.6 开发批次

分支 `feature/0.5.6` 从已推送的 `main` 提交 `e964719` 开始，实现 04 指定便笺固定到桌面及 05 动态清单桌面组件。包版本保持 0.5.1；不创建 PR、运行 Actions、发布或提审。[完整范围](../0.6.0%20功能范围.md)

## 实现

- 从已保存且无未保存修改的便笺，以及动态清单列表，选择“固定到桌面”；默认当前逻辑桌面，可选择桌面与四种尺寸。同一目标可创建多个独立实例，通用便笺组件继续保留。
- 卡片仅保存稳定目标引用，显示原记录的实时标题、摘要或查询结果，点击直接打开。移除组件保留目标；目标删除显示失效，不回退为其他便笺或全部内容。未绑定的清单组件打开独立选择器。
- 直接隐私标记与清单条件隐藏均约束卡片、计数、字幕、菜单、键盘和拖拽；选择器在另一标签页锁定后遮蔽并保留选择。固定动作在导航→偏好→工具锁内核对目标及版本，单次提交导航和必要隐私标记。
- 公开桌面方案移除个人目标 ID、名称及正文，拒绝绑定引用输入，也不复用本机已绑定卡片。完整备份保留关联；导航单独恢复、追加同 ID 碰撞或未恢复的目标保持隔离失效，实际恢复的目标才允许重连。
- 恢复导航、隐私偏好和工具数据使用一次底层事务及共同通知，避免新卡片短暂读取本机同 ID 的旧私密内容；仅恢复内容及失败回滚也保持相同保护。
- 修正共享弹窗初始焦点跳过禁用/隐藏控件，以及子弹窗关闭后可返回保留的父级启动按钮；新打开的不相关弹窗仍保有焦点。
- 隐私重新锁定或隐藏范围变化时，在绘制前清空临时桌面搜索并关闭命令面板，避免无效查询仍显示先前输入的私密标签名称。

- 完整单元测试 **808 项通过**，日志 `output/0.5.6-unit-rerun.log`；先前运行读到修正前的可选空字段测试夹具，失败日志保留，没有为测试改变产品语义。
- 定向检查包括 64 项模型/引用回归、43 项恢复与模板检查、101 项存储/工具/完整同步回归，以及 13 项固定控制器与引用测试。这些集合有重叠，不相加作为新测试数量。
- 新增六个实际扩展场景覆盖跨桌面多实例、实时编辑和删除恢复、未绑定选择器、动态成员、隐私及异步锁定、同 ID 导航/完整恢复和八语 390px 布局。
- 恢复期间使用 DOM 观察断言没有短暂出现本机碰撞目标的标题；初始焦点、取消返回及命令面板转入新弹窗的焦点均有实际浏览器断言。
- 生产解压构建与扩展静态检查通过。六个新增实际扩展场景分别在 bundled Chromium、Chrome 157、Edge 157 **6/6 通过**（合计 18 个），报告在 `output/playwright/covelet/0.6-batches/0.5.6{,-chrome,-edge}/`。隐私输入清理及命令面板追加复验在三个通道各 **3/3 通过**；报告在该批次 `privacy-recheck/{chromium,chrome,edge}/`。

本批使用隔离配置及合成资料；原生浏览器通过测试副本/开发者加载入口运行，没有操作用户日常浏览器资料。备份/同步协议测试及受控 HTTPS 响应不等于真实云账号验收。资料与图片经生产备份入口进入浏览器测试，不通过测试脚本直接写业务存储。

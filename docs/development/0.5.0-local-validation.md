# Covelet 0.5.0 发布前本地验收记录

本文归档发布前各批开发、候选包和手动试用的历史记录。下文“未发布”“未提审”及旧候选校验和均是当时状态；本次正式版本见 [0.5.0 发布说明](../releases/0.5.0.md)。

2026 年 11 月 11 日完成十二项功能开发与本地验收，版本统一为 0.5.0。当前为候选包，未打发布 tag、发布 Release、上传或提交 Chrome / Edge 商店。后续发布与提审等待用户指令。

## 新功能

- 链接备注和跨内容标签：网站、便笺与稍后读共用标签，支持组合筛选。
- 动态清单和链接列表：保存筛选条件，集中按位置查找和整理。
- 稍后读再看日期和批量处理：本地日期到期筛选，批量已读、未读、归档及删除。
- 网页选文便笺和 Markdown 交换：保留普通文字与出处，单篇或多篇文件导入导出。
- 网站与文件夹回收站和重复审阅：先预览合并及删除，恢复保留位置、元信息和图片。
- 搜索引擎关键词和密码完整备份：例如 `gh react`，以及独立密码的离线跨浏览器恢复。

## 2026-11-11 本地试用界面修正

根据解压扩展的试用反馈，在 `feature/0.5.0-ui-polish` 修正六处界面：顶部按钮固定为正方形圆形控件（普通窗口 44px、矮窗口 36px）；首次使用直接进入空白桌面；子弹窗遮罩盖住父窗口并增加边框和阴影；快捷保存默认只展示名称、网址和位置，备注、标签及图标设置按需展开；文件夹批量打开入口移至标题栏右侧；批量选择改成左对齐的紧凑列表，保持底部操作可见，并避免背景通知遮挡。

布局参考 [Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets) 与 [Modality](https://developer.apple.com/design/human-interface-guidelines/modality)。新增两条文案覆盖八种语言。

本次本地验证包括 38 项实际扩展 E2E、30 项选文/元信息/批量打开逻辑检查，以及 Chrome 156 / Edge 157 的原生快捷弹窗、空白首屏、圆形按钮、文件夹标题栏、9 条完整展示、15 条局部滚动和双层弹窗焦点、Tab、Escape 检查。快捷弹窗实际为 360×510 CSS px，默认网站、稍后读及便笺无需滚动；展开额外字段后仅正文滚动，保存始终可见。

手动测试继续加载 `output/worktrees/main/app/dist/extension`，版本保持 0.5.0。上文已有 ZIP 和 SHA-256 对应修正前的冻结候选包，不包含这次界面修正；本次更新解压目录，未重打 ZIP、发布或提审。

## 使用边界

Markdown 对不支持的复杂块、已有图片及部分段首、段尾或连续换行明确拒绝无损导出，可用完整备份保留原样。网页框架选区和浏览器受限页提供手工填写路径，关闭浏览器原生弹窗会丢弃未保存草稿。

密码不保存，丢失无法恢复加密文件；可移植文件不包含设备解锁密钥或会话凭据。旧客户端对新字段安全停下，但不承诺混合版本自由互通；共享同步位置的设备应统一升级再解决冲突。兼容检查使用固定旧真实模块与合成远端，没有新增真实云账号验收。商店自动更新、审核和上线不由这些本地验证证明。

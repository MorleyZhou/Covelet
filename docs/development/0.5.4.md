# Covelet 0.5.4 开发批次

分支 `feature/0.5.4` 从已推送的 `main` 提交 `c25f838` 开始，实现 03 搜索定位和 07 选文追加。包版本保持 0.5.1；不创建 PR、运行 Actions、发布或提审。[完整范围](../0.6.0%20功能范围.md)

## 实现与边界

- 全局搜索及命令面板打开便笺时，只将真正匹配正文的普通检索词传入临时定位会话；标题、别名独占命中显示正文无匹配。提供上一处、下一处与关闭，编辑、切换记录、隐藏及关闭后清理。
- 使用 DOM Range 与 CSS Highlight 展示匹配，不改正文、选择区、修订、撤销历史或同步数据。偏移映射覆盖 Unicode NFKC、组合字符、大小写及 UTF-16 边界，匹配数量有上限。
- Folio 延迟挂载后才安装观察和首次定位；滚动按弹窗内所有裁切祖先的可见交集计算，避免命中在内层可见却被外层裁住。定位不滚动背景桌面。
- 选文保存支持新建或追加到现有可见便笺，选择前可搜索，追加内容与出处可预览。既有标题、富文本节点、置顶、标签及隐私保留。
- 追加在现有锁及原子写入边界内检查便笺和偏好版本；取消、记录变化/隐藏/删除、容量或存储失败保留摘录，不产生部分写入。打开选择器只读，不触发回收站清理。
- 新增十三个词条的七种译文，与简体中文源文覆盖八种界面语言。权限及外部依赖保持原样。

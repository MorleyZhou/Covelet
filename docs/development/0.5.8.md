# Covelet 0.5.8 开发批次

分支 `feature/0.5.8` 从已推送的 `main` 提交 `d1c54e9` 开始，实现 08 稍后读批量标签/日期及 09 动态清单组合条件。包版本保持 0.5.1；不创建 PR、运行 Actions、发布或提审。[完整范围](../0.6.0%20功能范围.md)

## 实现

- 稍后读在现有批量选择中增加添加/移除所选标签、统一设置/清除再看日期；仅改变明确选择的字段。选择时保留记录版本和元信息基线，其他页面修改后要求重新选择。
- 标签批量修改按导航→偏好→工具锁顺序重新检查记录、标签可见性与容量，将工具记录和元信息一次提交。无变化不写入；失败不部分应用。原有状态、删除、分页和回收站行为保留。
- 动态清单增加包含全部/任一所选标签、排除标签，以及“今天”“未来七天”。未来七天覆盖本机今天至第六天，使用日历日期运算处理夏令时、跨月及年份边界。
- 只在任一模式保存可选 `tagMode: any`；旧数据默认全部模式。正向与排除条件的所有引用仍必须有效、可见；任一模式不会忽略失效或隐藏条件而扩大匹配。
- 桌面搜索延续清单的标签模式与日期条件；桌面清单组件实时刷新。锁定状态下可见标签字典变化也会清理临时搜索，避免最后一个公开关联移除后仍残留原标签名。

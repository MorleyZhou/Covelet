## 实现

- 在现有导入窗口增加明确的 Raindrop HTML 与 OneTab 文本来源，可选本地文件或粘贴。普通书签 HTML、Markdown 链接和网址粘贴保持原有流程。
- Raindrop 只读取惰性 Netscape 结构、`TAGS` 和 `DESCRIPTION` 属性；不抓取页面、不读取图片，也不把可能属于高亮的 `DD` 当作备注。没有客户端版本标记的文件不推断版本。
- OneTab 兼容经验证的 2.25 纯文本序列化结构：首个 ` | ` 分开 URL 与标题，后续分隔符保留在标题，空行分组；预览允许修改组名。兼容目标不等于识别所选文件的实际导出版本。
- 重复项默认保留本地。每个规范化网址单独选择目标副本、来源行，以及合并标签/追加备注；不覆盖名称、地址、位置或正文。不同的本地副本不会自动合一。
- 来源字段原样预览；支持字段超限时阻止提交，可减少选择、调整决策或明确关闭标签与备注导入。没有静默截断或逐条先写标签。
- 提交只接收来源与用户决策，在导航→偏好锁内重新计算，检查两类版本及目标绑定，一次提交导航和偏好。取消、隐藏、容量或并发失败不部分写入。改变标签/备注的导入不提供只能撤回导航的旧撤销按钮。
- 增强导入在隐藏开启时使用固定解锁门槛，不根据是否匹配到隐藏网址决定提示。异步锁定保留预览；解锁或外部资料更新后，用户可明确重新预览再导入。

## 来源与支持范围

OneTab 2.25 官方 Firefox 包经 SHA-256 校验并只读检查序列化代码；自有合成资料通过纯序列化分支生成测试样本，没有复制再分发第三方代码。Raindrop 使用公开导出结构作事实校验，测试仓库只保存自有合成字段和布局样本，不复制无再分发授权的公开收藏资料。具体来源、日期、哈希和样本说明随测试夹具记录；忽略的下载原件在 `output/0.6-samples/`。

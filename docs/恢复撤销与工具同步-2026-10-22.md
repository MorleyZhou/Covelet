# 完整恢复、布局撤销与工具同步

日期：2026-10-22。

本轮按用户授权完成完整备份与恢复中心、当前布局编辑会话的撤销／重做、工具回收站，以及便笺和稍后读的自选存储加密同步。功能延续免费新标签页方向，不增加 Covelet 账号、业务服务器或浏览器权限。本文件记录当前源码行为；冻结发布包、商店和托管版本不随本轮改变。

## 完整备份与恢复中心

入口为设置 → 数据 → 备份与恢复中心。导出的 `Covelet-complete-backup.json` 使用独立的 `covelet-complete-backup` 版本 1 格式，包含七类数据：

| 类别 | 内容 |
| --- | --- |
| 导航 | 网站、文件夹、外观、布局和额外搜索引擎；内部嵌入旧导航 ZIP，连同其引用的本地图标资源 |
| 便笺 | 标题、正文、富文本文档和置顶状态 |
| 稍后读 | 完整网址、标题和阅读状态 |
| 标签快照 | 用户主动保存的标签列表及其原有顺序、固定状态 |
| 工具回收站 | 尚在保留期内的删除记录 |
| 本机桌面方案 | 命名方案及其声明式内容 |
| 别名与隐私标记 | 本机内容别名、私密条目标记；恢复时保留当前设备的隐私展示开关 |

文件限制为 50 MiB。导航部分继续使用已有 ZIP 的大小、解压体积、字段和图片校验；只有被导航引用的本地图片资源进入备份。远程图标地址并不等于已备份其图片文件，Bing 图片缓存、派生图像和分析缓存不进入完整备份。凭据、密码、同步目标、工具同步跟踪状态、时钟运行状态也不包含在内。完整文件包含私人内容，应由用户自行妥善保管，不用于公开分享桌面方案。

恢复前显示时间、类别和数量，允许勾选类别。旧导航 ZIP 和旧工具 JSON 仍可在同一入口预览恢复；旧格式只提供其实际包含的类别。完整 JSON 缺少必需数据区或数据区无效时拒绝恢复，不把损坏文件解释为空类别。

- **追加**为默认方式：相同 ID 保留本机版本，阅读项按完整 URL 去重。新导航放到新屏幕，已有外观不变；新增条目按各容器连续排序。已有别名优先，私密标记合并。
- **替换所选类别**：所选类别按备份内容替换，合法的空类别也会清空本机该类别；未选类别保持原样。开始前需要确认选择和方式。
- **并发保护**：预览捕获各数据区的修订号；写入时在该区原有锁内再次检查。其他页面或同步已经改变数据时，要求重新预览，不静默覆盖。

首次写入前先持久保存恢复前副本；存储空间不足时不开始恢复。最多保留两份恢复前副本，可分别预览或导出。从某份恢复点恢复时保留该来源副本，避免恢复再次中断后丢失原始救援数据。

某区写入失败时，对已经完成的区按其刚写入的修订号尝试回退。若期间出现更新，不覆盖较新的内容，而是保留恢复点并提示人工恢复。存在未处理的恢复中或需恢复状态时，普通备份导入被阻止，需先处理恢复点。恢复本身是一笔新的本机修改；已经开启的同步可能继续传播恢复结果，不能将本机回退视为撤销已经发生的远端接收。

旧导航 ZIP、浏览器原生配置同步和原有自选存储配置同步仍只处理原有导航配置范围，不包含本机别名、隐私标记和命名方案。它们现在可由完整 JSON 迁移，不表示被加入上述配置同步。

## 布局撤销与重做

编辑布局时保留最近 50 步事务历史，移动、合并文件夹、删除条目和增删屏幕等通过布局草稿完成的操作可以逐步撤销／重做。恢复时同时还原合理的选中项目和有效屏幕；不会通过布局历史改写工具正文或组件运行状态。

工具栏提供撤销和重做按钮。快捷键为 Ctrl／Cmd+Z、Ctrl／Cmd+Shift+Z，以及 Windows 的 Ctrl+Y。输入框、Folio、弹窗、弹出层和输入法保留自己的键盘行为。选择条目或切换屏幕不单独增加历史；无实际变化不清空重做分支，撤销后进行新布局操作则清空该分支。

历史只属于当前编辑会话：完成保存或取消都会清空，刷新、重启或跨设备不保留。保存仍只提交一次草稿，并检查进入编辑时的导航修订号；外部更新发生后，撤销、重做和保存均不能覆盖新版本，用户仍可退出编辑。

## 工具回收站

设置 → 数据及工具数据入口提供工具回收站。删除便笺、稍后读或手动标签快照时先保存原记录；支持恢复、确认后永久删除和确认后清空。

保留期为 30 天，最多 200 条回收站记录。活动工具内容和回收站合计限制为 4 MiB，并保留原有便笺、阅读项及快照条数限制。到期记录通过带锁的本机修改清理；空间或条数不足会拒绝删除操作，不通过静默淘汰尚未到期记录腾空间。

恢复保留记录 ID，并检测现有同 ID 内容或重复阅读网址，不静默覆盖较新记录。恢复和永久清理使用工具数据修订号保护；旧工具数据读取后兼容升级为版本 3。完整 JSON 和新工具 JSON 都包含回收站，工具内容同步不传递回收站列表。

## 便笺与稍后读的加密同步

复用现有 R2、OSS、GitHub、GitLab 或 HTTPS WebDAV 自选存储连接，在连接解锁后单独开启便笺与阅读同步，默认关闭。使用 Web Crypto 的 AES-GCM 加密，远端文件位于配置同步前缀下独立的 `tools-v1` 目录，工具正文不进入浏览器原生同步或导航配置对象。

同步内容仅为便笺和稍后读。标签快照、回收站、时钟运行状态、桌面方案、别名与隐私标记、临时缓存、凭据和密码不进入工具同步。连接信息及会话解锁沿用原有流程，不由 Covelet 服务器中转。

每台设备保留独立副本和因果信息，删除记录通过墓碑传播，防止旧设备把已经得知删除的内容重新上传。并发修改保留冲突版本，界面提供处理入口；恢复冲突内容产生新的修改。不会以整库覆盖抹去另一设备的修改，网络、授权、口令或容量错误也不阻止本机离线阅读和编辑。

工具同步继续遵守已有云对象明文 512 KiB 上限；单个设备副本还需给封装元数据留空间。多个设备副本的聚合限制为 4 MiB。因果信息、删除墓碑和冲突也占用容量，因此可同步正文少于这些标称大小；超限时停止同步并保留本机内容，不用裁剪正文伪造成功。

界面显示待同步数量、最近同步时间、冲突数和具体错误。本机完成上传与合并不代表另一设备已经接收，另一设备仍需自行同步。当前未使用真实云账号执行往返或多设备网络验收，不据此宣称所有服务商已验证可用。

## 验证记录

本轮已经运行有意义的定向数据测试，覆盖完整备份往返、兼容格式、追加排序、缺失类别拒绝、失败回退、修订冲突、恢复点保护、布局历史边界、回收站和工具同步的删除／冲突／离线行为。测试使用隔离数据与模拟存储，不使用用户私人数据或真实远端账号。

最终 `npm test` 为 **273 项通过，0 失败**，包含现有视觉／同步／GitHub WASM 校验。新增专项包括恢复中心 11 项、布局历史 8 项、工具回收站 8 项、工具同步 12 项；合并回归包含已有加密和服务商传输测试。前序遗留的四行桌面、旧视觉开关及文字图标同步断言已按既有需求更新，保留布局边界、迁移、图片资源和并发覆盖。

`npm run build:unpacked` 已刷新 `app/dist/extension`；`npm run check:extension` 通过（40 文件、2 HTML、9 JS、3 CSS）。打包校验修正了旧版号／默认英文标题预期、补入已有图标缓存与工具 WASM 桥的检查，并排除依赖对象同名 fetch 方法造成的误报。默认工具栏标题现由本地消息资源生成，未增加权限。

通过 Playwright 在独立 Chromium 配置中实际加载上述未打包扩展，页面使用 `chrome-extension://…/newtab.html` 与 `popup.html`，没有启动或使用本地网页服务，也没有读取用户的浏览器配置。测试使用合成便笺、阅读项、方案和快照：

- 实际导出完整 JSON，再通过文件选择预览并替换恢复；核对 `chrome.storage.local` 中的正文、完整 URL、方案和私密标记以及恢复点。
- 两个扩展页面间修改数据后，旧恢复预览拒绝写入，后改的正文保留。
- 便笺从界面删除进入回收站，再恢复同一 ID 和正文；打开扩展 `popup.html` 删除手动快照，确认同样进入本机回收站。
- 布局编辑中增屏、按钮撤销／重做、Ctrl+Z／Ctrl+Shift+Z以及完成保存；核对本机保存的屏幕数量。
- 工具同步独立开关默认关闭，开启写入本机偏好；连接未解锁时上传按钮禁用。
- 1000×700 窗口内恢复操作可滚动到达，没有横向溢出。视觉检查修正了通用表单样式导致的恢复条目竖排问题。
- 扩展回归修正了图标展示元素不必要的 CORS 属性，确认 Google 等原图重新显示；有界图标分析请求仍遵守 CORS，失败时保留原图展示，不绕过浏览器限制。

测试记录和截图位于 `output/playwright/extension-qa/`，其中 `unit-tests.log` 保存最终自动化结果。开发演示模式禁用完整恢复、导出和回收站入口，避免操作真实预览数据。

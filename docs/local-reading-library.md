# 本地阅读器与 RSS 收件箱

实现基线：已发布的 0.6.0，保留稍后读的 500 条上限、状态、标签、再看日期和原有同步协议。

## 存储与网络边界

稍后读链接仍在 `covelet.tools.v1` 中；正文、抽取标题、高亮及阅读样式保存在独立的 `covelet.reading-library.v1`。订阅与收件箱保存在 `covelet.rss.inbox.v1`。两者都通过现有 `localData` 写入设备密钥 AES-GCM 加密的 IndexedDB，并明确列入 `sync-data-rules.js` 的设备专属排除项。因此正文、高亮和订阅不会进入云端全量快照，也不会改变原有 0.6.0 链接记录格式。

现有完整备份格式保持兼容；这两个设备专属集合不纳入完整备份。用户可以明确导出公开阅读记录的 Markdown，包含本机正文、高亮和备注；Markdown/ZIP 仍是未加密交换文件。隐藏记录和私密文件夹继承内容在导出预览、序列化、文件名、警告与数量计算之前排除。搜索继续采用现有隐藏模式边界：隐藏状态下先剔除隐藏记录，再做正文匹配、摘要和计数。

新增链接成功写入后异步尝试一次正文抽取；权限拒绝、网络失败、无法识别正文均保留链接及原标题，不延迟或撤销链接保存。只在用户保存新链接、更换地址或明确打开/重试该文章时进行抓取，不在普通渲染、搜索、导出、后台扫描中抓取。精确来源权限只从用户操作申请；请求使用省略凭据、无 Referer、拒绝重定向、超时与大小上限，不执行网页 JavaScript，不使用远程解析服务。

抽取使用本机结构分析。送入 DOM 解析器之前先移除资源标签、全部网页属性、脚本、样式、嵌入内容；图片仅保留校验后的 HTTP(S) 地址到结构化占位数据。最终渲染是 React 文本节点，禁止 `dangerouslySetInnerHTML`。不声称能处理登录文章、付费墙或仅客户端动态生成的正文；这类文章可用原链接阅读。

## 正文与高亮

文章按标题、段落、列表项、引用和图片占位保存。文本块以两个换行拼接为规范正文；高亮使用 UTF-16 起止偏移和原选区文字双重校验，不依赖页面 DOM 路径。高亮备注与版本号一起保存在同一本机记录中。正文变化且已有高亮时拒绝覆盖，保护旧锚点；同一正文的重试保留高亮。

文章抓取在锁外进行，提交时在现有加密存储原子更新中重新校验稍后读 ID、URL、记录版本及隐藏状态。被删除、更换 URL、锁定或其他页面更新的内容不能被迟到的网络响应覆盖。高亮修改使用版本检查。

阅读样式包括字号、行距、系统/浅色/深色。图片默认没有远程 `src`，仅在用户点击单张图片且授予其精确来源权限后获取；使用有界栅格图片字节创建本机 Blob URL，并在卸载时回收。图片访问仍会向该图片来源发起用户主动的网络请求；没有预取、远程代理、自动跟踪像素或外部字体。

正文上限 256 KiB UTF-8，单次 HTML 上限 2 MiB；最多 500 篇本机文章、每篇 100 个高亮，总集合上限 32 MiB。达到上限拒绝新的本机缓存/高亮写入，保留原有内容，不自动淘汰带注释的文章。链接保存仍然成功，阅读视图可明确重试并显示存储错误。阅读器的“移除本机正文”经确认删除这一篇正文和批注，保留链接；即使链接已改址，旧缓存也能显式清除。列表的“清理已移除文章的正文”只清除已不在稍后读和回收站的孤立缓存，并校验集合版本；隐藏状态下不开放该数量和操作。

## 全文匹配与导出

搜索在内存中将当前可见稍后读链接与 URL 相同的本机文章连接，匹配标题、URL、说明、正文、高亮选区及备注。复用结构化搜索的 `tag:`、`type:reading`、`is:`、`domain:` 条件和现有清单，不建立持久倒排索引。缓存中的孤立 ID 或 URL 过期的文章不进入搜索或导出。

Markdown 资料库导出在原有导航/隐私/工具锁内读取正文集合，并在生成及应用预览后比较同一集合，正文或高亮变化使旧预览失效。图片只导出说明，不生成会在 Markdown 阅读器里自动联网的远程图片语法。高亮选区和备注转义为文本，避免 HTML、链接或 frontmatter 注入。

## RSS 生命周期

订阅默认关闭，用户手动添加 RSS/Atom HTTP(S) 地址后启用。精确来源授权后，本机扩展 service worker 按订阅周期通过浏览器 alarm 拉取；浏览器关闭时不会运行，重新启动后恢复计划。后台没有申请新权限的能力。仅请求用户添加的订阅 URL，不抓取其文章或图片，不扫描失效链接。

收件箱仅保存纯文本标题、摘要、链接及日期，不存 `content:encoded` 正文或可执行 HTML。支持有界 RSS 2.0 与 Atom，拒绝 DTD、外部实体与无效 XML。解析或请求失败保留上一次有效条目，在收件箱显示错误并继续可用。最多 20 个订阅、每源 100 条、总共 500 条；收件箱按接收顺序滚动保留，移除源会删除其收件箱条目，已经保存的稍后读独立保留。打开条目后才抽取正文。

无账号、服务器、遥测、广告、云端 AI 或 RSS 云端代理。同步密码和设备密钥体系不变。

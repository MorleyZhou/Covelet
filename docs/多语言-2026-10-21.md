# Covelet 多语言

本轮为 2026-10-21 开发源码改动。按用户要求，仅修改功能及生成包内翻译资源，未运行测试、静态检查、应用构建或浏览器验收；不修改冻结的 v0.1.0 发布包和商店提交。

## 语言与默认行为

内置英文 `en`、简体中文 `zh-CN`、繁体中文 `zh-TW`、日语 `ja`、韩语 `ko`、德语 `de`、法语 `fr`、俄语 `ru`。

默认选择“跟随浏览器”。扩展优先读取 `chrome.i18n.getUILanguage()`；网页预览使用 `navigator.languages[0]`，再使用 `navigator.language`。按浏览器当前语言匹配，不跳到语言列表后方的其他语言；不支持的语言回退英文。例如 `de-AT` 使用德语，`es-ES` 使用英文。繁体匹配 `zh-Hant`、台湾、香港、澳门标记；其他中文标记使用简体。

设置 → 外观 → 语言，可以改选指定语言或重新跟随浏览器。语言切换更新界面、文档语言、页面标题、日期与数字；已打开的同浏览器页面通过存储变更通知更新。Chrome 原生的安装简介等消息由浏览器的扩展国际化机制选择，工具栏标题也跟随本机语言偏好。

## 覆盖与内容边界

- 主界面的搜索、右键菜单、文件夹操作、布局编辑、屏幕管理和提示。
- 设置、背景颜色编辑器、浏览器同步、书签和备份入口。
- 扩展分类、配置、时钟与时区工具、GitHub 贡献、便笺、稍后读、标签快照、云端版本和恢复。
- 浏览器工具栏快速添加弹窗、倒计时通知及 Chrome 包内简介消息。

网站、文件夹和搜索引擎的自定义名称，便笺正文、阅读条目和快照名称不做翻译。仅识别未改名的内置组件名称和原始 Bing 搜索项，用当前语言呈现，不改写保存记录。Bing 返回的图片说明、站点返回的名称以及浏览器或存储服务自己的提示仍属于外部内容。

主要界面文案及常见操作提示提供全部语言；底层协议、格式校验等详细诊断允许逐条回退英文。简体中文使用原始中文消息。翻译不参与数据标识、同步因果时钟、签名、加密、日期协议格式或 URL 生成。

语言偏好使用独立本机键 `covelet.language.v1`，网页开发演示使用 `covelet.language.demo.v1`。扩展保存在 `chrome.storage.local`，网页预览保存在 `localStorage`；不加入导航 JSON、浏览器同步、自定义云同步、ZIP 或个人工具导出。语言资源全部随安装包提供，不新增网络请求、权限、在线翻译或数据上传。

## 维护

运行时入口是 `app/src/i18n/index.js`；React 使用 `useLanguage()` 订阅本机语言。使用 `tr('稳定的源消息', [参数])`，完整句子使用占位符，避免逐词拼接。不要对用户输入或数据记录直接调用翻译；组件名称使用 `builtinName`，原始内置搜索项使用 `providerName`。模块级选项通过 getter 在读取时翻译，避免缓存启动时的语言。

翻译源在 `app/src/i18n/phrases.txt`，每行依次为源消息、英文、繁中、日语、韩语、德语、法语、俄语，以 `|` 分隔。`errors.en.txt` 提供底层诊断的英文回退。Folio 菜单的八种语言在 `folio.phrases.txt`，上游英文回退在 `folio.en.txt`；仅翻译编辑器界面，不翻译文档节点。不要在参数或翻译中嵌入 HTML 或可执行表达式。

`npm run generate:i18n` 只生成 `src/i18n/catalog.json` 和 `public/_locales/*/messages.json`，不会执行应用或构建；生成不是通过验收的证据。新增消息时补充翻译源再生成。`scripts/localize-source.mjs --extract / --write` 为本次存量源码迁移工具，不作为运行时依赖，也不需要在日常构建前执行。

Chrome 清单采用 `default_locale: en` 与 `__MSG_*__` 消息引用。语言目录采用 Chrome 的下划线命名 `zh_CN` / `zh_TW`，应用运行时使用 BCP 47 连字符标记。[Chrome 扩展国际化文档](https://developer.chrome.com/docs/extensions/reference/api/i18n)说明原生消息与清单规则。

- 上架前核实 Bing 图片的展示／缓存授权、接口边界及署名；提交材料准确披露 Bing 必需主机、站点识别的可选来源范围和逐站授权、默认背景网络行为及可选浏览器厂商同步。接口可访问不代表长期可用或已获许可。

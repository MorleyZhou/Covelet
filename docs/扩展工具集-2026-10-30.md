# Covelet 扩展工具集开发记录

日期：2026-10-30。范围：本地 Chrome／Edge MV3 扩展开发，共新增 17 个内置扩展入口，包括汇率计算。单词卡片属于语言学习模块；JSON、正则和文本对比属于同一个在线工具模块。

这是实现与验证记录，不代表商店已上传、审核通过或发布。现有 `releases/`、冻结 ZIP 和商店资料不作为本次开发输出修改。

## 扩展目录与实现范围

扩展中心仅管理组件的添加、移除和导航尺寸；工具通过导航打开各自独立弹窗。移除桌面组件保留模块内容；配置和内容继续使用 Covelet 的存储、恢复与同步边界。

## 数据、附件、同步与备份

- 模块数据使用 `preferences` 命名空间下的 `covelet.app.v1.<id>`。本机持久化通过现有 `localData`，使用设备本地、不可导出的 AES-256-GCM 密钥和独立随机 IV；没有新增明文 `localStorage` 或浏览器原生 `storage.sync`。
- AI 连接的 endpoint、provider、model 和 API Key 独立存入设备本地 `covelet.ai.connection.v1`，仍通过本机加密存储保存。**这些连接配置不随同步或备份搬到另一设备**，也不从导入的聊天内容覆盖本机连接；在新设备上需要单独配置模型服务。会话与消息内容继续使用 `covelet.app.v1.ai-chat` 的内容存储和恢复流程。
- 每个模块使用版本化 envelope，读、写、同步导入和备份导入均先校验已知领域结构。写入读取最新数据；有草稿基准版本的操作检查 CAS／记录 revision，冲突保留原内容并要求重新打开。
- 行程凭证、收据、图片／PDF／媒体结果中的 Blob 都在相同加密存储边界内，参与已接入的完整加密同步与恢复。生成中的临时输入不因打开工具就自动保存；明确处理／保存后的内容才进入持久化。
- 完整备份升级为 v2，在原导航、便笺、稍后读、快照、回收站、方案和隐私标记之外加入 `apps`，携带已保存模块内容和附件。继续读取旧 v1 及原有支持格式。恢复有预览、覆盖／追加选择、恢复点和版本冲突保护。
- **普通完整备份是用户主动导出的 JSON 文件，不等同于设备的 AES 密文，也不应宣称备份自动受到设备密钥保护。** 附件使用有界编码保存；导出文件可能包含对话、账本和凭证等私人内容。
- AI 连接配置整体排除在同步和备份之外。普通备份另会移除股市／赛事 Key、物流 Key；恢复时保留当前设备已有的对应 Key，不用备份中的空字段覆盖本机凭据。恢复到新设备后，用户需要重新配置相关 Key。
- 用户自选存储的完整加密同步仍沿用现有独立加密信封与密钥流程；设备解锁、同步控制元数据与本地设备密钥的排除规则保持原有边界。模块接入本身不证明真实远端或跨设备交付已经通过验收。

## 扩展运行与交互边界

- 所有可执行 JS、worker、解析器和依赖随扩展打包。重型格式化／PDF 模块按需加载；没有 iframe 小组件、远程脚本、远程 WASM 或代码下载市场。
- AI 内容按文本／Markdown 显示，跳过原始 HTML；外部链接和内容经过对应边界处理。代码片段和在线格式化的输入不会作为 JavaScript 执行。
- 新组件沿用桌面尺寸、拖拽、隐藏和开启工具的流程；隐私隐藏只限制被标记内容，不冻结其他公开功能。任务通知对被隐藏的任务组件使用不含任务名称的通用文本。
- 草稿在关闭／返回／跨模块跳转时有放弃确认；忙碌操作有关闭保护，错误有可操作反馈。普通保存不添加重复成功提示。
- 不承诺浏览器关闭后的提醒、监控、实时行情或模型推理；桌面客户端和常驻后台服务不在此范围中。

## 2026-10-30 布局重构与最终验证

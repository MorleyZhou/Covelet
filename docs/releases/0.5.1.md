# Covelet 0.5.1

2026 年 11 月 12 日。修复同步冲突处理，并增加随机壁纸的图片选择。

## 同步修复

- “以本地为准”用整份本地可同步数据替换云端；“以云端为准”用整份云端可同步数据替换本地。
- 修复其他设备重建同步数据后，旧设备的离线修改或中断上传阻止明确覆盖选择的问题。
- 后台同步中断后可改选另一端；覆盖成功但响应丢失后，选择云端会读取最新云端内容。
- GitHub 权限、限流、服务错误及同步目录含其他文件的情况分别提示，避免误报为数据格式错误。并发校验与非同步文件保护继续生效。

设备密钥、连接凭据与本机隐藏状态继续保存在本机。新安装能正常读取云端内容，不代表现有设备的写入权限或覆盖目录检查一定通过；本次没有读取用户的云端响应，尚未确认截图中的具体触发原因。

## 随机壁纸

- 保留已展示图片的轮换进度，一轮用完再开始下一轮，刷新或重开页面后继续减少重复。
- Bing 合并两页官方近期归档，按实际图片标识去重；可用图片仍受 Bing 归档范围限制。
- Wikimedia Commons 改为从官方接口分页获取符合尺寸、格式与许可条件的横图，不再只轮换四张。当前搜索限定 CC0，并保留作者及文件页链接。
- 下载、解码或保存失败时保留旧壁纸及轮换进度。

使用 Commons 时需按需授权 `https://commons.wikimedia.org` 获取图片及许可信息，以及 `https://upload.wikimedia.org` 下载图片。安装时的权限范围未扩大。

## 验证与发布

764 项单元测试、WASM 校验、生产构建及扩展静态检查通过。实际解压扩展另通过 6 项同步和 2 项壁纸回归；这些浏览器测试使用隔离配置及合成网络响应，不代表真实账号或原生权限弹窗验收。

公开 Commons 真实请求已验证元数据读取和 JPEG 下载；该检查仅检查图片头，未进行浏览器图片解码。尚未使用用户的真实云端数据复验。详细证据见[本地验收记录](https://github.com/MorleyZhou/Covelet/blob/v0.5.1/docs/development/0.5.1-local-validation.md)。

GitHub Release 提供安装包与 SHA-256 校验文件。Chrome / Edge 商店的审核和上线时间以各商店记录为准，提交不表示已经通过审核。

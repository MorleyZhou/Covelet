# Covelet 0.3.0

0.3.0 调整首页的时间显示与搜索布局，补充同步和恢复保护，并修复日常导航问题。

- **首页更简洁**：新安装从空导航开始；时间和日期显示在搜索框上方，极简模式可隐藏。旧时钟组件退役，保留旧数据与备份兼容。
- **同步更清楚**：测试连接与保存配置分开，未验证状态明确显示；冲突时可查看影响范围，选择保留本机版本或采用云端版本，按整组内容处理。补充图片一致性、重启恢复、断网重试与重复同步的回归覆盖。
- **备份恢复更稳妥**：完整备份可恢复导航、便笺与图片；取消、损坏文件或预览后内容发生变化时保留当前数据。修复新文件无效时仍能执行旧预览的问题。导出文件未加密，可能包含隐藏内容，请妥善保管。
- **日常导航修复**：调整搜索布局，修复键盘焦点与导航操作中发现的问题。

自备存储同步整体仍为 **Beta**，阿里云 OSS 另保留渠道 **Beta** 标记。

## 验证边界

531 项单元测试、21 项真实扩展 UI 自动化通过；GitHub 真云同步已在两个独立浏览器配置之间验证，不等同于两台实体设备验收。

用户选择跳过人工验收，未验证项目不记为通过。后续真云回归仅使用 GitHub；OSS 本轮未测试，其他渠道不沿用 GitHub 的验收结论。

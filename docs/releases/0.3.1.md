# Covelet 0.3.1

- 首页按可用高度调整导航。时间默认跟随系统时区，农历和星座可在「设置 → 时间与日期」分别关闭。
- 「扩展 → 自备存储同步」支持只用同步密码解锁。同步在后台运行，中断后可接着处理。发生冲突时可选择整份本机或云端版本。
- GitHub 同步选择「以本地为准」时，会先回读并验证新快照，再替换当前同步目录并清理旧文件。其他设备需更新 Covelet 后继续同步。
- 「设置 → 备份与恢复」可直接导出备份或选文件确认恢复。回收站单列，「关于」汇集版本更新与隐私信息。
- 「随机壁纸」支持 Bing 和 Wikimedia Commons，可设置 5 分钟至 1 个月的更换间隔。
- 文件夹中的站点可通过右键菜单移回桌面，书签可从桌面空白处的右键菜单导入。

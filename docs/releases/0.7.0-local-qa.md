# Covelet 0.7.0 发布验收

日期：2026-11-25（Asia/Shanghai）。从 `main` 的已发布 0.6.0 后工作区准备 0.7.0，包含此前四个独立提交的记录级同步合并、同步密码轮换、定时加密备份与便笺历史，以及本轮完成的本地阅读器、Firefox 适配和浏览器命令面板。

## 正式候选检查

| 检查 | 结果 |
| --- | --- |
| `npm test` | **1,187 通过，0 失败、0 跳过**。包含会话保存/恢复/去重、正文抽取回退、高亮导出、全文匹配、RSS 解析失败、密码轮换、备份轮转、便笺恢复及双浏览器发行包版本/校验边界。 |
| `npm run build:extension` | Chrome 0.7.0 正式 ZIP、WASM 和扩展静态检查通过，56 个文件。 |
| `npm run build:firefox` | Firefox 0.7.0 独立 ZIP、WASM 和扩展静态检查通过，56 个文件。 |
| 版本/包边界 | package、lockfile 两处、源 manifest 和两个包内 manifest 均为 0.7.0；ZIP 路径无目录穿越。 |
| 权限 | Chrome 必需权限仍为 storage/search/favicon/activeTab/scripting/alarms；Firefox 移除不支持的 favicon。两个目标仅新增可选 tabs/history/bookmarks，必需主机范围仍为 Bing，可选 HTTP(S) 来源按需授权。 |
| 0.7.0 Chrome 运行时 | 实际 Chrome 157.0.8103.79、隔离配置、生产命令面板，9 项原生 CDP 检查通过；30 标签保存后原标签保留，取消不创建，三次明确确认各创建 10 个后台标签，URL 集合和固定状态正确，重复恢复不新增，改名重启后持久化，确认删除不关闭标签。 |
| 未授权入口 | 原始 manifest 下选择三个浏览器来源仍保持未授权，均显示直接授权按钮，不自动申请权限。未授权 Chrome 隐藏 history/bookmarks API 的情况已回归。 |
| 多语言 | 新版 What’s New 有简中及七种译文；网页八语静态文案生成检查通过。 |

本机采用已安装 Node 26.13.0 / npm CLI 执行同名 package scripts，绕过无法离线解析版本的 mise npm shim，未联网安装或修改依赖。正式发布工作流按 tag 检出、Node 22 和 lockfile 构建，GitHub 发行附件的 SHA-256 以该次工作流生成的 `SHA256SUMS.txt` 为准。

本机候选、日志与脱敏回执保存在 `output/releases/v0.7.0/`，不将 ZIP、配置文件或凭据提交进 git。原生浏览器证据复用 `output/playwright/covelet/browser-command/`；体验用配置与测试配置分离，测试临时目录已清理。

## 功能验收来源与限制

以下功能验收在 2026-11-24 至 25 日完成，当时工作区仍使用 0.6.0 版本标识；版本升级后重新执行上表完整测试、两种正式打包和 Chrome 会话流程。文档保留原日期与当时版本，不改写为重复执行记录。

- [记录级同步和真实 Chrome / Edge / R2 双端](../verification/record-level-sync-merge-2026-11-24.md)、[R2 浏览器验收](../verification/record-merge-browser-r2-2026-11-24.md)。
- [密码轮换](../verification/password-rotation-2026-11-24.md)：真实 R2 及产品界面，新旧密码边界按权威世代验证，旧归档或已下载副本不在密码撤销范围内。
- [定时加密备份](../verification/scheduled-local-backups-2026-11-24.md)：真实加密、Worker 与三份轮转；自动化使用真实 OPFS 目录句柄，不冒充外部系统目录手动选择和持久授权验收。Firefox 暂无外部目录定时备份，浏览器关闭时不承诺准点写入。
- [便笺历史](../verification/note-history-2026-11-24.md)：恢复前保存当前版，原子持久化及备份兼容。
- [本机阅读器](../verification/local-reader-2026-11-25.md)：20 篇真实文章保存、阅读、高亮、搜索和 Markdown 导出流程；使用原生浏览器自动交互。
- [Firefox 核心与 R2](../verification/firefox-2026-11-25.md)：原生 Marionette 核心流程和真实 R2 验证；Firefox Playwright 扩展导航不支持，未宣称其通过。本轮没有另做 Firefox 命令面板会话运行时验收。
- [浏览器命令面板](../verification/browser-command-palette-2026-11-25.md)：会话加密与同步排除、异步取消、预览、三批恢复、中文组合事件保护。

WebDAV 真实服务按维护者要求暂缓。上述原生自动化并非人工逐项签收；真实系统中文输入法候选窗、macOS、原生读屏和外部目录持久授权仍未验收。

Firefox 分发包未签名、未提交 AMO，不是商店安装包；暂按开发调试方式临时加载。GitHub Release 与 Chrome / Edge / Firefox 商店审核及上线各自独立，不沿用旧版回执作为本次送审证据。

# Covelet 0.6.0

2026 年 11 月 14 日。更快找到资料，把项目内容固定到桌面，并方便地迁入和导出。

## 查找与继续使用

- 新增全局命令面板：在新标签页点击放大镜或按 Ctrl/⌘+K，查找内容、切换桌面，以及打开设置、新建、导入和导出。
- 本机搜索支持 `tag:`、`-tag:`、`type:`、`is:`、`domain:` 条件，可移除条件并保存为动态清单。
- 从搜索结果打开便笺时，定位并临时高亮正文命中，支持上一处、下一处；查找不修改正文。
- 将指定便笺或动态清单固定到桌面，内容修改后更新卡片；移除组件保留原资料。
- 网页选文可追加到已有便笺，保留旧正文，并附上来源标题和网址。

## 整理与外观

- 稍后读支持批量添加或移除标签、设置或清除再看日期，只修改选中项和指定字段。
- 动态清单支持包含全部标签、包含任一标签、排除标签，以及今天或未来七天的再看日期条件。
- 每个逻辑桌面可单独设置背景、遮罩和模糊，也可逐项继承全局；切换、重排及恢复后保留对应外观。

## 资料迁入与导出

- 新增 Raindrop HTML 和 OneTab 文本文件迁移，提供分组、条目及支持的标签和备注预览。
- 导入遇到重复网址时，可明确选择目标和来源，合并标签并追加备注；默认保留本地信息。
- 新增 Markdown 资料库 ZIP，按类型导出网站、稍后读和便笺，包含索引、相对链接及可表达的标签、备注、URL、阅读状态和日期。
- 大批来源和重复项采用分页审阅，翻页保留选择；导出文件名处理特殊字符、大小写及 Unicode 重名。

## 数据与兼容

本版不新增安装权限、账号、遥测或后台扫描。新增便笺／清单引用、桌面外观和筛选数据沿用本机加密存储、完整备份、恢复及自备存储同步；命中高亮等临时状态不进入同步。云同步仍保留整份本地或云端的冲突选择。

Markdown ZIP 是未加密的交换文件，始终排除标记隐藏的内容；原样恢复请使用完整备份。Raindrop 首版支持已验证 HTML 的标签和描述，OneTab 支持 `URL | 标题` 及空行分组，不提供在线账号迁移。Markdown 交换不承诺完整 Obsidian Vault、插件、附件或复杂块无损迁移。新增数据可能被旧版安全拒绝，升级后不建议降级覆盖资料。

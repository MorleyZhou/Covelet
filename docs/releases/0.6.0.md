## 性能与网络

近上限资料为 1,900 网站、500 稍后读、200 便笺及 50 桌面，固定后 1,901 导航条目，导出 2,601 文件。采集实际输入/点击至可见结果的墙钟时间，包含自动化传输与断言，不以纯函数耗时代替界面响应；并行通道有 CPU 竞争，不作设备无关的性能保证。普通全量测试仍保留追踪快照；另有关闭 DOM 快照的独立 CPU/长任务诊断，避免混淆产品和测试开销。

独立诊断将巨量文本框填入与预览生成分开：1,900 行模拟填入约 4.9 秒，CPU 采样主要位于 Chromium 原生编辑/布局；之后实际生成预览约 **531 ms**，实际 OneTab 文件选择器到预览约 **399 ms**（最大长任务分别 280/171 ms）。因此不能把合并的粘贴操作时间全归为产品解析或渲染成本，也不宣称普遍延迟保证。资料库预览约 2.0 秒，生成并解析 2,601 文件 ZIP 约 1.0 秒。具体原始记录 `output/0.6.0-performance-final/`；早期带快照与原生填入混合开销的记录仍保留供比较。

来源预览每页显示 100 行，重复项合并控件每页 20 组，全部 1,900 条来源、选择和提交计划保持完整。全选与文件夹选择继续作用于全部筛选结果；翻页、单项取消、从第二页全组取消及恢复全选都有实际界面断言。23 组跨页合并仅改变两个明确选定目标，其他 21 个及全部导航保持不变。分页既限制一次挂载的控件数量，也让大批逐组审阅有明确页码和范围。

完整项目路径验证迁入标签与备注、按正文检索并定位、指定便笺固定、真实合成 HTTPS 网页选文追加、导出后保留结构和出处。普通迁移/查找/固定/导出没有 HTTP 请求；网页捕获只联系明确的合成来源。随机壁纸检查区分显式首次加载和切屏零增量请求。

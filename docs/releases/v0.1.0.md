# Covelet v0.1.0 发布说明

状态：生产候选已验证，Chrome已提交并显示待审核；交易者身份验证和Edge进度统一见[发布状态](../store/发布状态.md)，本说明不表示已上架。[固定发行包及校验文件](../../releases/v0.1.0/README.md)已保存。发布者Morley，支持邮箱support@mudong17.com；[隐私政策](https://sites.google.com/view/covelet-privacy)已公开并验证可匿名访问。

首版专注网站导航、搜索、外观和布局：

- 新配置从空桌面开始，网格加号添加网站；拖拽叠放创建文件夹、移入／移出和排序，文件夹顶部直接改名，右键编辑或删除。
- 默认搜索遵循浏览器设置；主动选择额外引擎时显示Logo，无图时回退名称。自定义引擎图标逐来源授权获取，失败不影响保存或搜索。
- 网站图标自动使用实际图片或文字，可调整背景色。支持主题、每行数量、图标大小与间距，以及可隐藏的本机时间日期。
- 支持Bing每日背景与本地回退；设置→数据保留书签HTML导入、ZIP备份恢复、快照和默认关闭的浏览器原生配置同步。
- 对外名称统一为Covelet，新增原创C形海湾Logo和扩展／商店图像；内部`owntab`存储键、备份格式等继续兼容，不因改名清空数据。

没有Covelet账号、广告或开发者遥测。Bing、用户授权的目标站、搜索提供商和主动开启后的浏览器同步服务仍有已披露的数据流，详见公开隐私政策。

最新74项核心测试、4项Sites测试和13文件静态gate通过；精确生产文件在独立网页来源的导航、搜索提交、设置、书签、备份／快照、刷新和两标签冲突已实测，详见[最新验证轮](../验证记录.md#covelet-v010)。真实扩展API／host授权、多设备云端、触屏／屏幕阅读器、200%及最新390窗口未执行。商店进度见[发布状态](../store/发布状态.md)，权利边界见[提交材料](../store/商店提交材料.md)；不宣称全部UI或商店审核已通过。

# Covelet v0.2.0

发布日期准备：2026-10-22。Chrome 上传、审核与公开发布状态以商店回执为准。

完整 ZIP：[covelet-0.2.0.zip](../../releases/v0.2.0/covelet-0.2.0.zip)，3,618,387 字节、39 个文件。SHA-256：`6183f843a9acc710549a201e3314dfa804f8e7537a6ad9d2742add680442931d`。五张宣传截图见[素材目录](../store/assets/v0.2.0/README.md)。Google Sites 公开政策已更新至本版日期，Chrome 提交另行记录。

- 新增时钟、世界时钟、时区对照、倒计时与计时；新增便笺和稍后读。
- GitHub 贡献组件采用安静的方格视图；扩展中心按用途分类。
- 自定义存储同步支持加密配置、版本浏览、差异查看及选择性恢复。
- 支持八种界面语言，默认跟随浏览器，不支持的语言回退到英文。
- 自由布局、多屏、默认多选、批量文件夹合并、拖拽移出文件夹和确认删除。
- 支持真实高清及明暗图标、位置感知的视觉适配和平滑配色；修复长时间后台恢复及图标闪烁。
- 工具栏快速添加网站/稍后读；标签快照树支持手动保存与选择恢复。
- 第一方控件统一使用本地 shadcn/ui 来源组件；搜索结果浮层不挤压桌面。

隐私：没有 Covelet 账号、广告或开发者遥测。工具正文和标签快照默认仅保存在本机；配置同步由用户主动开启。新增可选权限、网络数据流及公开政策更新见 [v0.2.0 隐私政策](../store/v0.2.0/privacy-policy.txt)。订阅/支付尚未接入，不将 $6/年收费或订阅解锁描述为本版已实现功能。

打包使用 `node scripts/build-extension.mjs --skip-checks`。按用户要求未运行测试、WASM/扩展检查或功能验收；本次浏览器操作用于宣传截图及商店发布，不代表全部功能验收。正常构建校验流程保持可用，只有显式 `--skip-checks` 跳过检查。

宣传截图使用隔离的 Chrome 演示会话与独立本地数据，包含真实来源图标、原创颜色渐变、作者编写的便笺和 GitHub 公开日历，不使用用户的实际便笺、标签页、同步秘密或未核实宣传许可的 Bing 摄影作品。旧版 v0.1.0 发布文件保持不变。

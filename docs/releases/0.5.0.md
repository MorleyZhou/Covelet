# Covelet 0.5.0

2026 年 11 月 11 日。收藏、便笺和稍后读的整理与找回更方便，快捷保存和编辑弹窗也更紧凑。

## 新功能

- 链接备注和跨内容标签：网站、便笺与稍后读共用标签，支持组合筛选。
- 动态清单和链接列表：保存筛选条件，按位置集中查找、移动和整理链接。
- 稍后读再看日期和批量处理：筛选到期内容，批量标记已读、未读、归档和删除。
- 网页选文便笺和 Markdown 导入导出：保存普通文字与出处，支持单篇或多篇文件交换。
- 网站与文件夹回收站和重复审阅：删除前预览，恢复时保留位置、备注、标签和图片。
- 搜索引擎关键词和密码完整备份：用 `gh react` 等关键词直接搜索，完整备份可用独立密码加密并跨浏览器离线恢复。

## 界面改进

- 首次使用直接进入空白桌面，顶部按钮保持圆形。
- 快捷弹窗默认一屏保存，备注、标签与图标设置按需展开。
- 文件夹批量打开入口移至标题栏，选择列表更紧凑，底部操作保持可见。
- 双层弹窗有明确遮罩和层级；便笺放大还原后保存按钮保持可见。
- 修复块操作、表格和选区控件随滚轮越出编辑区；保留菜单、拖拽和键盘操作。
- 精简便笺说明和重复数据管理入口，将导入、导出移到“新便笺”左侧。

## 升级与验证

未新增权限、外部依赖、账号或采集。共享同一同步位置的设备请统一升级到 0.5.0；旧客户端遇到不支持的资料格式会停止处理。

通过 732 项单元测试、实际解压扩展回归、WASM 和打包静态检查。Chrome、Edge 验证覆盖新功能、八语布局、升级和旧备份恢复，以及最新界面修复。详细本地验收记录见 [开发记录](https://github.com/MorleyZhou/Covelet/blob/v0.5.0/docs/development/0.5.0-local-validation.md)。

Markdown 的复杂块、已有图片及部分空行可能无法无损导出，完整备份可保留原样。备份密码不保存，丢失后无法恢复加密文件。

# Covelet 0.3 候选发布说明

这是 0.3 的发布准备记录。扩展包和 manifest 版本仍为 **0.2.2**，尚未发布 0.3。

## 候选变更

- **首页**：新安装默认空导航；现有数据中，仅移除完全未编辑的六个初始网站，保留用户添加、编辑或移动过的内容。时间与日期移到搜索框上方，极简模式隐藏，并记住选择。调整搜索布局，修复实际发现的键盘焦点与导航操作问题。
- **时钟退役**：移除时钟扩展入口，停止旧时钟调度并清理遗留提醒；保留旧记录，兼容备份与同步。
- **同步**：区分测试连接、保存配置与首次同步；未通过测试的配置明确标记未验证。冲突时展示影响范围，选择保留本机版本或采用云端版本，同组内容整体替换。补充图片字节一致性、重启恢复、断网重试、写入成功但响应丢失、重复同步的回归覆盖。
- **备份与恢复**：验证完整备份恢复导航、便笺与图片；取消、损坏文件和预览后发生的新修改均保留当前数据。修复选择无效备份后仍可执行旧预览的问题。完整备份未加密，可能包含隐藏内容。

同步名称继续使用 **“自备存储同步（Beta）”**；**阿里云 OSS 单独保留 Beta 标记，本轮不测试 OSS**。后续真云回归仅使用 GitHub；这不代表其他渠道已通过同等验收。

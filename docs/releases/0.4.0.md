# Covelet 0.4.0

- 在桌面右键选择「编辑布局 → 屏幕管理」，给桌面命名或调整顺序，完成后保存。搜索完整且唯一的桌面名称，按 Enter 跳转。「设置 → 布局」可指定本机新标签页打开的桌面。
- 打开文件夹后选择「批量打开网站」，可勾选最多 10 个站点。搜索可筛当前桌面、网站、文件夹、便笺和稍后读，并显示导航项的位置。可在浏览器的扩展快捷键设置中绑定「打开 Covelet 搜索」。
- 从工具栏收藏当前网页时可选桌面或文件夹。稍后读也可添加到桌面。编辑布局时可批量移动或复制选中的网站，取消布局编辑或撤销操作可恢复原位置。
- 首次打开可添加常用网站、导入书签或从空白开始。桌面右键菜单支持导入书签 HTML、粘贴网址和选择 Markdown 链接文件。也可按桌面或文件夹导出书签 HTML，标记为隐藏的内容始终从导出文件排除。

使用自备存储同步的设备应更新到 0.4.0 后再同步含命名桌面的数据。新版本可继续恢复旧备份。 [功能范围与验收条件](../0.4.0%20功能范围.md) · [备份及同步用法](../0.3使用说明.md)

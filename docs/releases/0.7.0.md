# Covelet 0.7.0

2026 年 11 月 25 日。同步按记录合并，稍后读成为本机阅读器，命令面板可访问浏览器标签、历史和书签。

## 同步与数据恢复

- 同步冲突先按记录预览，区分双方修改、单边修改和删除，支持逐条选择后应用，并保留合并前副本供撤销。继续使用自备存储的加密不可变索引、内容块、CAS 和原子本机提交。
- 可更换同步密码。切换前完整校验保留的云端快照，失败保留原数据；成功后重新用新密码解锁。新密码用于当前权威同步世代，不能撤销旧归档、云端版本历史或已下载副本。
- 支持每日或每周生成本机 `.covelet` 加密备份，最多保留最近三份，并显示失败状态。需要浏览器支持可持续写入的目录能力、有效授权及可运行的扩展页面；浏览器关闭期间不承诺准点备份，Firefox 暂不支持外部目录定时备份。
- 便笺可预览、对比和恢复历史，恢复前先保存当前正文。每篇最多 20 版，同时受单篇及全局字节上限约束。完整备份升级为 v2，仍可读入 0.6.0 旧备份。
- 搜索引擎选择现在会记住，刷新后不必重新选择；该偏好和语言偏好仍仅在本机保存。

## 本地阅读器

- 保存稍后读时在本机抽取标题和正文；抽取失败仍保存链接。阅读视图支持字体、行距与深浅色，正文图片需点击才加载。
- 正文可高亮并添加批注；正文和高亮可参与本机全文及结构化搜索，公开阅读内容的 Markdown 导出包含高亮。
- 新增 RSS / Atom 收件箱，直接向用户添加的来源定时拉取标题、摘要和链接，正文按用户操作再抽取。没有云端解析服务或 RSS 代理。

## 浏览器命令面板

- 新增打开标签页、浏览历史和浏览器书签来源。可按标题和 URL 搜索、切换标签，并用独立按钮关闭选中标签。
- 可命名保存当前窗口的链接会话，原标签保持打开。会话可重命名、删除和选择部分链接恢复；恢复前必须预览并确认，每批最多创建 10 个后台标签，已打开链接跳过。
- 上下键选择、回车执行和 Esc 关闭；中文输入法组合期间不触发提交或关闭。

## Firefox 与隐私

- 提供独立 Firefox MV3 开发预览包，与 Chrome 共享源码，最低 Firefox 140。Firefox 包尚未签名、未提交 AMO；请按开发调试方式临时加载。
- `tabs`、`history`、`bookmarks` 为新增**可选权限**，只有点击对应授权按钮才申请。既有必需权限与主机权限范围保持不变；不休眠标签、不云同步浏览器会话，不新增账号、服务器或遥测。
- 阅读正文、高亮、RSS 和浏览器会话均使用本机加密 IndexedDB，排除云同步和现有完整备份。普通 JSON / ZIP / Markdown 文件仍未加密；Markdown 资料库和书签交换导出继续排除隐藏内容，完整备份可能包含隐藏内容并显示提示。独立密码 `.covelet` 加密备份默认包含其支持的隐藏内容，但不含访问凭据、隐藏密码和设备密钥。备份密码不保存，丢失无法恢复。

## 验证与分发

发布前单元测试、Chrome / Firefox 构建与扩展检查，以及本机浏览器流程结果见[发布验收记录](https://github.com/MorleyZhou/Covelet/blob/v0.7.0/docs/releases/0.7.0-local-qa.md)。真实同步服务验收使用 R2；WebDAV 本轮按维护者要求暂缓。30 标签会话和 20 篇阅读流程使用真实 Chrome 原生自动交互验证，不等同人工逐项签收；系统输入法候选窗、外部目录持久授权及 Firefox 命令面板会话运行时尚未人工验收。

GitHub Release 提供 Chrome ZIP、Firefox 开发预览 ZIP 与 SHA-256 校验文件。GitHub 发布、商店送审与商店上线是独立状态，以各自回执为准。

# Covelet 隐私说明 / Privacy policy

更新日期为 2026-11-06。本文适用于 **0.3.1**。公开政策与商店状态分别见[托管隐私政策](https://sites.google.com/view/covelet-privacy)和[发布状态](store/发布状态.md)。

发布者：Morley。支持／隐私联系：support@morley.work。

Covelet 提供新标签页导航、搜索、布局与外观、便笺、手动稍后读、GitHub 贡献组件和可选自备存储同步。没有 Covelet 账号、广告、遥测、自动日志上传或 Covelet 数据服务器。不提供扩展工具包、窗口标签快照或浏览器阅读清单导入，不请求对应权限，不被动收集浏览历史。

导航、网址、便笺、稍后读、图片、外观、隐私标记和组件记录保存在当前浏览器的加密 IndexedDB 中。设备 AES-GCM 密钥不可导出，但同源应用可使用它；这不能替代设备锁屏或防止已获浏览器配置访问能力者读取内容。隐藏密码控制本机显示，与设备加密密钥及同步密码不同。旧版功能记录可能保留在本机数据、备份或同步副本中，不会恢复已移除的功能入口。

浏览器原生配置同步已停用，不使用 storage.sync 发送新数据；旧浏览器云端副本不会因此自动删除。「自备存储同步」默认关闭，用户配置并解锁后，以同步密码加密内容和图片，直接发送至其选择的 R2、OSS、GitHub、GitLab 或 HTTPS WebDAV。服务商接收加密内容、目标路径、请求时间和网络元数据，并按其规则处理。设备密钥、隐藏密码和当前隐藏状态不随内容同步。连接凭据用于向所选服务认证，使用同步密码加密后保存在本机，不进入备份或同步内容。同步密码及解密后的凭据只在 chrome.storage.session 中使用，锁定或重启后用同步密码解锁。自动同步需要单独开启。其他设备、并发版本、恢复点和备份可能保留旧内容，删除本机内容不代表删除所有副本。

启用「随机壁纸」后，扩展访问所选来源。Bing 使用 https://www.bing.com，Wikimedia Commons 使用按需授权的 https://upload.wikimedia.org。图片来源接收 IP 等连接信息，请求省略 Cookie 和 referrer，图片缓存在本机。关闭随机壁纸或改用颜色背景可停止请求。搜索由浏览器默认搜索 API 或用户选定搜索引擎处理，查询由对应服务接收，Covelet 不收集查询。

网站信息和图片获取在用户添加／编辑、点击获取或确认导入／修复时进行。仅按需申请实际网站／图片来源的访问权限，不扫描浏览历史；普通导航显示、刷新和文件夹浏览使用本机图片缓存。被请求的站点接收所需地址及连接元数据。工具栏由用户点击触发 activeTab，只读取被调用页面的地址、标题和图标声明，保存前可修改或取消。不会读取整个窗口的标签集合。用户在便笺中插入远程图片时，显示图片可能连接图片来源。

GitHub 贡献组件在用户授权 github.com 并配置账号后，读取该账号的公开贡献日历。组件在加载、恢复可见和定期刷新时检查本机缓存，需要更新时连接 GitHub，也可手动刷新。不读取私有仓库或登录令牌。GitHub 接收用户名及连接元数据。首页时间和日期使用设备时间，所选时区、农历和星座均在当前浏览器中计算。时区和显示偏好保存在本机。此功能不请求定位或网络校时。独立时钟和倒计时组件已移除，当前版本不发送通知。

权限与用途：

| 类型 | 权限／来源 | 用途 |
| --- | --- | --- |
| 必需 | storage | 迁移旧数据并保存会话连接信息；内容与设置使用加密 IndexedDB，不启用浏览器原生同步 |
| 必需 | search | 按浏览器默认设置执行搜索，不修改默认搜索提供者 |
| 必需 | favicon | 显式添加／导入时读取浏览器已有图标 |
| 必需 | activeTab、scripting | 用户点击工具栏后读取当前页面元数据；不持续注入或遍历其他标签 |
| 必需 | alarms | 接续后台同步和清理旧版时钟提醒 |
| 固定主机 | https://www.bing.com/* | 随机壁纸的 Bing 来源 |
| 可选主机范围 | http://*/*、https://*/* | 仅为实际选择的网站、图片、GitHub 或存储服务逐来源申请；不在安装时授予全部网站权限 |

不请求浏览历史、浏览器书签库、地理位置或通知权限。书签 HTML 导入只解析用户选取的本机文件。完整备份、导航 ZIP、便笺／稍后读导出和恢复点有不同范围；导出文件未加密，可能包含私人网址、图片和正文，包括标为私密或当前隐藏的内容，请勿公开分享。恢复前会校验内容并要求确认，保留恢复前副本；旧标签集合只作为历史数据保留或导出，不提供打开标签或单独恢复入口。

用户可编辑／删除内容、禁用同步、选择背景、撤销网站访问权限并导出备份。卸载前请保存所需内容。反馈仅由用户主动发送，不自动附带日志、网址、图片或备份。不出售数据，不用于广告、画像、无关分析或信用决定；数据使用限于已披露功能，并遵守 Chrome Web Store User Data Policy（包括 Limited Use）。公开政策网址为 https://sites.google.com/view/covelet-privacy；本地修改不等于该托管页面已经更新。Google Sites 的页面访问由 Google 独立处理。

## English

Updated November 5, 2026 for the current source and package version, 0.3.0. This is the current repository privacy policy; no store submission has been made in this round. The hosted policy has not been checked or updated in this round and should be reviewed before a store submission. This document does not establish the current hosted policy or store status. Publisher: Morley. Contact: support@morley.work.

Covelet provides new-tab navigation, search, appearance, notes, manual Read Later, public GitHub contributions and optional storage sync. No Covelet account, advertising, telemetry, automatic log upload or Covelet data server is included. Tool packs, window tab capture/restore and browser Reading List import are not provided. No corresponding permissions or passive browsing-history collection are included.

Content, images and settings are stored in encrypted IndexedDB in the current browser. The non-extractable device key can still be used by same-origin application code; encryption is not a substitute for device security. The hiding password controls local display and is separate from device encryption and the sync password. Records from retired features may remain in local data, backups or synced copies without restoring those features.

Browser-native sync is disabled; this does not automatically delete old browser-cloud copies. Bring-your-own storage sync is off by default. After configuration and unlock, it encrypts content and images with the user's sync password and connects directly to user-selected R2, OSS, GitHub, GitLab or HTTPS WebDAV. Providers receive ciphertext, paths, request times and network metadata. Device keys, hiding passwords and the current hiding state are excluded from synced content. Connection credentials authenticate requests to the selected service and are not included in backups or synced content. Connection credentials are encrypted with the sync password and saved on this device. The password and decrypted credentials are held in chrome.storage.session. After locking sync or restarting the browser, enter the sync password to unlock the connection. Automatic sync requires a separate opt-in.

Random Wallpaper contacts the selected source when enabled. Bing uses www.bing.com, and Wikimedia Commons uses an optional grant for upload.wikimedia.org. The selected host receives connection metadata. Requests omit cookies and referrers, and images are cached locally. Turn off Random Wallpaper or switch to a color background to stop requests. Searches go to the browser's default or explicitly selected search provider, which receives the query; Covelet does not collect it. Website/icon acquisition and confirmed import/repair may contact the selected origins after origin-specific grants; ordinary navigation icon rendering uses local cached bytes. Clicking the toolbar provides temporary activeTab access to that page's URL, title and icon declarations through a packaged script. Fields can be edited and saving can be canceled. No window-wide tab collection is performed. Loading user-inserted remote note images may contact their hosts.

After authorization and account configuration, GitHub widgets read that account's public contribution calendar. They check the local cache when loaded, when becoming visible and during periodic refresh, and contact GitHub when an update is needed. Manual refresh is also available. No private repositories or login tokens are read. GitHub receives the username and connection metadata. The home page uses the device clock and computes the selected time zone, lunar date and zodiac sign in the browser. Time zone and display preferences stay on this device. The feature makes no location or network time requests. Standalone clock and countdown widgets have been removed; the current version does not send notifications.

Required permissions are storage, search, favicon, activeTab, scripting and alarms, with the fixed Bing host. Storage supports migration and session credentials; content and settings use encrypted IndexedDB. Search follows the browser's default search settings. Favicon reads existing browser icons during explicit add/import. ActiveTab and scripting read the invoked page's information after a toolbar click. The alarms permission resumes background sync and clears legacy clock reminders. There are no optional named permissions. The optional HTTP(S) host ranges support exact-origin grants for selected websites/images, Wikimedia Commons, GitHub and storage providers; they do not grant blanket access at installation. No history, bookmark-library, geolocation or notification permission is requested.

User-selected bookmark HTML is parsed locally. Complete backups, navigation ZIPs, notes/Read Later exports and recovery points have different scopes. Exported files are not encrypted and can contain private URLs, text and images, including content marked private or currently hidden; do not share them publicly. Restoration validates the content, requires confirmation and keeps a copy from before restoration. Legacy tab records can be retained or exported but cannot open tabs or be restored separately. Other devices, conflicts, recovery points and backups may retain older copies. Local deletion is not deletion everywhere. Users can edit/delete content, disable sync, change backgrounds, revoke website access and export data before uninstalling. Feedback is voluntary with no automatic attachments. Data is not sold or used for advertising, profiling, unrelated analytics or credit decisions. Use is limited to disclosed features and follows the Chrome Web Store User Data Policy, including Limited Use. The hosted policy URL is https://sites.google.com/view/covelet-privacy; editing this file does not update that page. Google Sites processes policy-page visits separately.

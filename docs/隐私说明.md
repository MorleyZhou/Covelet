# Covelet 隐私说明

更新日期：2026 年 10 月 21 日。适用范围：当前开发源码，尚未发布。本文包含高清图标、工具栏快捷添加、图标地址同步和时钟提醒的数据行为；旧图片仍兼容。本轮仅生成必要的包内 WASM 资源，按用户要求未运行测试、检查、应用构建或浏览器验收，见[开发改动](开发改动-2026-10-21.md)。本文不表示商店审核、真实扩展 API 或多设备同步已经验收；公开 Google Sites 隐私页仍对应原提交版。

Covelet 的网站导航、搜索、外观、布局及增强免费提供。当前开发版无需 Covelet 账号，没有广告、推广链接、统计追踪服务或 Covelet 业务服务器，扩展订阅和账号仍未接入。开发者不接收网址列表、搜索词、图片、设备标识和使用行为。默认背景会请求 Bing；图标显示可能请求目标网站或其图片地址，元数据读取遵守来源授权；可选同步会把配置交给浏览器厂商或用户选择的存储，详情如下。

## 本次新增工具与历史恢复

世界时钟、时区对照仅使用浏览器 `Intl` 数据库，不联网查询时间或位置。城市／桌面时区作为组件配置参加已开启的配置同步，对照页临时日期不保存。

便笺正文与置顶、稍后读标题／网址／状态、标签快照名称与标签网址／标题／固定状态仅保存在独立本机记录，不进入导航 ZIP、原生配置同步或自定义存储配置同步。“工具数据”可主动导出完整 JSON，导入时去重合并，不替换已有记录；移除桌面组件保留内容，删除记录需要确认。正文预览不插入原始 HTML、不加载图片、不自动抓取文章。

用户点击“保存当前窗口”时才申请可选 `tabs`，读取该窗口普通 HTTP(S) 标签的上述字段，排除隐身和浏览器内部标签，不读取正文、不监听浏览变化、不申请 `history`。完整 URL 可能包含私人查询参数／片段，应妥善保管导出文件。选择并确认后在新普通窗口打开，保留现有标签。点击“从浏览器阅读清单导入”才申请可选 `readingList`，单次读取并合并，不修改或删除浏览器清单。工具栏添加表单可选择导航／稍后读，继续使用已有 activeTab，只读取被点击后的当前页，取消不保存。[Chrome Tabs](https://developer.chrome.com/docs/extensions/reference/api/tabs)、[Reading List](https://developer.chrome.com/docs/extensions/reference/api/readingList)

版本历史仅列举已配置且解锁的存储，用户选择修订后再读取、校验与解密。新修订的创建时间和完整可移植配置处于认证加密内；旧修订只比较实际记录过的项目。确认恢复时校验当前修订和摘要，并保留恢复前配置快照；不回退设备因果时钟或恢复工具正文。旧构建不能读取新修订，所有设备需更新。正文统计／匹配、差异和网址去重使用包内 WASM，本机处理，不向 Covelet 发送内容。见[实现与数据边界](扩展升级与本机工具-2026-10-21.md)。

公开 Google Sites 和原商店声明仍对应冻结提交，本次只更新本地隐私说明，未上线新权限或新版本。

## 在设备上处理和保存的内容

为了提供功能，Covelet 在本机处理并保存以下数据：

- 用户添加或从Covelet ZIP恢复的网址、名称、图标、文件夹及桌面排列顺序；旧数据的分组在兼容处理后合并为单一桌面。
- 自定义搜索引擎的名称、URL 模板及排序；临时选中的非默认引擎不保存成下次新标签的默认项。
- 背景模式、主题、外观、行列位置、组件配置、图标 HTTP(S) 地址与背景色。不再提供新增图标上传或用户壁纸上传，既存合法本地图标仍可兼容处理。
- Bing 每日图片信息和该设备的图片缓存；缓存服务于显示和离线回退，不用于识别或分析用户。
- 为恢复功能保留的本地快照、同步所需的本地状态及用户主动导入、导出的备份。

配置以扩展本地存储为主副本。网站图标可按所存地址加载，也可读取既有本机图片和浏览器缓存；Bing 图片使用设备内缓存。取消新增图标上传不删除旧图片，兼容 ZIP 备份仍可恢复被引用的合法图标。旧壁纸选择迁移为 Bing 模式，新备份不包含壁纸，旧备份校验后不再导入壁纸资源。插件不读取浏览历史或书签库，设置中的书签导入只在本机解析用户选择的 HTML 文件。六个可编辑删除的默认网址为 Google、YouTube、GitHub、X、ChatGPT、Grok，不含推广参数，使用随安装包提供的官网高清图标；不会自动打开这些网站或发送导航列表。已有配置及已删除网址不会重新初始化。

时钟由用户从扩展目录添加，使用设备时间和时区，不请求网络授时、地理位置或系统日历。样式、尺寸和桌面位置属于可移植配置；计时、倒计时和通知开关仅存本机，不进入浏览器／自定义存储同步或 ZIP。独立闹钟功能已移除，旧本机记录经兼容校验后移除闹钟字段、取消旧计划，不再发送闹钟通知；其他计时数据保留。显式移除时钟组件会清除其本机运行记录和倒计时提醒；删除屏幕只撤下组件展示，保留原记录、运行数据及有效倒计时计划，可在扩展中重新使用。通知权限按用户操作申请；浏览器运行时通过 alarms 调度倒计时，可能延迟且不会唤醒休眠设备。开发网页仅在页面打开时提供页面提醒。

时钟桌面仅展示时间，点击后在本机弹窗操作时钟、倒计时或计时；开关弹窗不新增权限或外部请求。关闭弹窗不停止既有计时／倒计时提醒。迷你 1×1 仅是配置与展示尺寸，不新增数据收集。

布局编辑的选中项和未保存草稿只存在于当前页面内存，不上传或同步。拖入垃圾桶后需要确认，确认仅修改草稿；Enter／完成保存后才写入配置，并清理本轮明确删除的时钟本机记录和提醒。Esc／取消丢弃草稿，不执行清理。屏幕列表、位置和组件撤下状态按已有同步开关处理；删除屏幕保留网站和文件夹，将导航追加到末尾，组件记录与本机数据不因此删除。拖拽中的图标／组件副本只用于当前画面反馈，不导出截图或发送至服务端。此项未新增权限或外部请求。

“视觉增强”默认开启，可在设置中关闭，已有明确关闭的选择继续保留。在本机处理已加载的壁纸／包内及本地图标，调整界面色调、图标留白和背景；图标图片本身不变色。按各标题的实际字形、当地明暗及线条选择文字颜色和必要的轻微描边／阴影；组件背景及内部文字、表针、贡献色阶也按组件下方壁纸取色。Bing 分析复用当前缓存和最多两份 2048px 本地细节缩略图，不额外请求图片，不截取其他页面、不上传图片、不调用识别服务。缩略像素、字形权重、色板、文字／图标／组件配色及计算结果只用于当前设备，不进入 ZIP 或同步；统一开关作为普通外观偏好保存，并按用户已开启的同步处理。关闭后恢复原有显示规则，不改写主题、手动遮罩、手动图标底色或原始图标。

本地处理仍是用户数据处理，并非“完全不处理数据”。Covelet 对相关数据的使用限于上述新标签页功能、保存、同步和恢复所需用途，遵守 [Chrome Web Store 用户数据政策](https://developer.chrome.com/docs/webstore/program-policies/limited-use)，包括 Limited Use 要求；不出售数据，不用于广告、画像或独立于产品功能的分析。

## 可选浏览器原生同步

同步默认关闭。用户可在数据设置中主动开启，由 `chrome.storage.sync` 向浏览器的同步存储提交可移植配置。此功能需要用户在 Chrome 或 Edge 中登录相应浏览器账号并开启适用的同步设置；Covelet 不创建账号、不接收凭据，也不能替用户开启浏览器账号同步。不承诺 Chrome 与 Edge 账号之间互通。

可同步内容包括网址、名称、文件夹、桌面行列位置、网站图标 HTTP(S) 地址与显示方式、图标背景色、搜索引擎及可移植的外观和组件配置。图标地址也可能包含个人信息，与网址列表一样会交给浏览器厂商的同步服务，并受其政策和用户设置管理。旧分组按兼容规则合并，不恢复产品分组。Covelet 不在原生同步之上另行提供端到端加密，不将“开发者不接收”表述为“没有任何第三方处理”。

搜索词及搜索历史、图标图片文件和本地资源 ID、Bing 图片和缓存、旧壁纸、本地快照、备份文件、时钟运行／闹钟状态及本机同步开关不进入同步。其他设备按同步的图标地址加载，地址失效时回退，不依赖原设备的图片文件。

同步受浏览器容量和写入频率配额限制，可能延迟或失败；本地完整数据应保留，失败状态不得显示为已成功送达另一台设备。写入 `storage.sync` 成功只表示浏览器 API 已接受写入，不能证明其他设备已收到。关闭 Covelet 同步后，本机不再主动读取或写入同步配置；浏览器仍可能传输此前已提交的数据，这不等于已经删除浏览器厂商保留的云端副本，也不等于停止浏览器其他功能的同步。云端及其他设备数据需要通过相应浏览器的数据控制机制管理。

## 开发版可选的自定义存储同步

本节是本地开发版的新能力，尚未更新到公开 Google Sites 隐私页及原 v0.1.0 商店提交。用户可在设置 → 增强选择自己的 R2、阿里云 OSS、GitHub、GitLab 或 HTTPS WebDAV；这与浏览器原生同步独立，自动同步默认关闭。无需 Covelet 账号，无 Covelet 数据中转服务器。功能扩展入口当前为空，不提供 ToDo，也不下载远程可执行模块。

只有主动配置并授权目标来源后，扩展才把加密的导航、文件夹、搜索引擎、外观和布局配置直接读写到所选服务。每次请求核对会话和具体来源权限，不带 Cookie／页面来源，不跟随重定向。服务商可获知 IP、时间、密文大小、随机设备标识和递增版本等元数据，并按自己的政策处理。Git 托管服务会产生仓库提交，数据删除还需考虑仓库历史和服务商保留策略。

真实图标、Bing 壁纸、派生图像、密钥、同步密码、连接地址及本机同步开关不随配置同步。用户已有的本机图像保留；其他设备缺图时以文字回退。数据使用 Web Crypto 的 PBKDF2-SHA256（210,000 次）及 AES-256-GCM 认证加密；固定随包 WASM 负责摘要、请求签名及同步状态计算，不载入远程或用户代码。

访问密钥、API 令牌、WebDAV 应用密码和同步密码只保存在浏览器的 `chrome.storage.session`，不写入导航、本地持久配置、备份或原生同步；浏览器重启后重新输入。网页预览只在内存保留秘密，不能发起真实云端同步。非秘密目标信息和合并元数据存本机。插件没有同步密码找回或对已有云端记录改密的流程。

自动同步只在 Covelet 页面打开且会话解锁时工作；点击锁定停止新的请求，但已发出请求可能完成。关闭或卸载扩展不会自动删除用户云存储中的数据；插件不调用远端删除。不同云服务可能收费、限制访问或终止免费额度。建议使用受限专用凭据、专用目录和独立 ZIP 备份。详细渠道、接入和限制见[自定义存储同步](自定义存储同步.md)。发布更新前应把本节准确同步到公开隐私页和商店披露。

## 搜索和访问网站

每次打开新标签页时，网络搜索默认交给浏览器当前默认搜索提供商。Covelet 使用 `chrome.search.query`，不修改浏览器默认搜索设置，不读取或猜测默认引擎品牌。

用户可以显式选择其他引擎，再提交搜索；此时浏览器直接访问所选引擎。输入过程不请求在线联想、不保存搜索历史；只有用户主动提交后，搜索词才交给对应提供商。用户打开已保存网站或输入网址时，浏览器直接访问目标网站，不经过 Covelet 跳转服务器，不额外添加推广参数。

搜索提供商和目标网站会按各自政策处理用户主动发送的信息，并可能获知访问时的 IP 地址等连接信息。它们的行为不由 Covelet 控制。

## 搜索引擎图标

必应、Google、DuckDuckGo的展示Logo随安装包保存，不因打开搜索菜单而向它们发请求；这只标识用户明确选择的额外引擎。默认搜索始终显示放大镜，不读取浏览器默认引擎品牌。

新增或保存修改的自定义引擎时，插件先读取本机缓存及浏览器原生 favicon 资源，不再为图标主动申请具体站点权限。原生查询只包含来源根地址和图标尺寸，不传搜索词、模板路径、查询参数或片段；浏览器默认占位图不会保存为真实网站图标。若该来源已有用户明确授权，可补充读取来源根首页与同源图标，请求不带 Cookie／来源页或第三方代理。获取失败仍可保存并正常搜索。

搜索引擎图标缓存独立保存在当前设备，最多32个来源；内存缓存用于本地存储不可用时的当前会话。图像不进入浏览器同步、完整ZIP备份或导航资源，只同步／备份引擎名称和模板。已有、导入、恢复或同步引擎不会自动批量联网取图；打开页面和菜单只读取缓存。

## 新增网站的名称和图标识别

六个默认站点的高清图片来自各服务官方公开资源，随安装包提供并记录来源；显示这些资源本身不请求官网。用户输入新网址时，可尝试该来源的标准 Apple touch 图标地址，并读取浏览器原生 `/_favicon/` 缓存；不逐站弹出页面读取授权，也不经第三方 favicon 服务。常规图标地址仅是回退，不保证该站提供高清资源。没有可用图片时使用名称文字。

名称先根据域名填写，用户可直接修改。主动点击“读取网站名称”或“获取高清图标”时，可按需申请该具体来源权限；已有授权可自动补全。高清识别读取页面声明的 touch 图标和 Web Manifest 图片，manifest 只在当前 activeTab 来源或已有来源授权下读取，不为其关联域名自动请求新权限。拒绝授权或补全失败保留有效图标；权限可在浏览器中撤销且不随配置同步。

主页识别只请求输入网址所属来源的根首页，不发送导航路径、查询参数或片段；主页／manifest 的 fetch 省略 Cookie 和 Referer，并拒绝重定向。图标可直接从网站声明的 CDN 或用户填写的 HTTP(S) 地址加载，只用作图片、不执行脚本；图片设置不发送 Referer，但其他 Cookie／缓存／网络层行为由浏览器决定，不能承诺全部图片均无凭据。接收网站可获得其资源请求、连接 IP、时间和必要网络信息；显式 HTTP 地址没有 HTTPS 传输保护。不会将整个导航列表发送给任一图标提供方。

HTML 只提取名称和图标声明，不执行远程脚本。根首页最多读取前 512KiB，manifest 最多 64KiB；高清候选最多检查五个，图片最长等待四秒并检查解码后尺寸，直接图像加载的下载与解码由浏览器处理，不能沿用本机转换路径的 1MiB 下载上限。已有授权的同源图像转换仍限每张 1MiB，并校验、重编码。既存导航、导入和恢复不触发批量元数据识别；正常显示已保存图标时会按地址加载图片。原生 favicon 的安装／更新权限提示由浏览器管理。

用户在其他网页点击工具栏按钮后，Covelet 用 activeTab 读取该页的标题、网址与图标声明，并用包内 scripting 函数读取 document.head 中的图标／manifest 链接。它不读取正文、其他标签页内容或浏览历史，也不执行远程脚本。信息先停留在表单，保存才写入导航，取消不写入。已存在的网址可以在表单中编辑；与其他页面并发修改时避免覆盖。

## Bing 每日背景和网络行为

新安装默认选择 Bing 每日背景。插件请求 `https://www.bing.com/HPImageArchive.aspx` 获取每日图片信息，再请求同一主机 `/th` 图片地址，按返回的来源信息展示图片说明和来源链接。实际请求不携带用户的网址列表、搜索词、图标、备份、Covelet 遥测或用户设置；获取背景使用省略凭据和不发送来源页的请求策略。Bing 仍可获得连接所需的 IP 地址、请求时间、请求路径和浏览器网络层提供的信息；这不构成匿名连接保证。Bing 按微软的服务及隐私政策处理请求。

各设备独立按日刷新图片信息，在独立 IndexedDB 缓存单张背景资源供重复打开及离线显示。刷新失败冷却 15 分钟后重试，优先显示旧缓存，再使用包内离线背景；可见性变化及定时检查遵守缓存和冷却规则。Bing 缓存不经过 Covelet 服务器，不进入同步或备份。关闭 Bing 模式后停止后续背景请求；用户可改选“颜色”中的单色或渐变，内置图片不作为可选壁纸。

该公开接口不是已确认拥有第三方稳定性承诺的正式 API。图片授权、署名、缓存和再展示条件仍需在发布前核实；接口可访问或返回 `wp` 字段不能替代许可依据。

| --- | --- |
| 新安装默认背景、Bing 模式按日刷新或主动刷新 | 向 `www.bing.com` 请求图片信息及图片；设备本地缓存 |
| 新增网站与显示导航图标 | 可请求当前网站的 touch 图标及保存的图标地址，或读取本机／浏览器缓存；主页／manifest 读取遵守具体来源授权 |
| 工具栏快捷添加 | 点击后读取当前页标题、网址与图标声明；保存才持久化，可按声明加载图标 |
| 新增自定义搜索引擎 | 先读本机／浏览器图标缓存，已有明确授权才补充同源读取 |
| 颜色背景、未开启同步的手动配置和搜索输入 | 不因该配置动作本身发送外部请求；已有的背景／图标按显示规则加载 |
| 时钟与提醒 | 使用设备时间与本机浏览器提醒，不请求外部授时服务 |
| 修改网站或文件夹图标背景色 | 在本机编辑颜色配置；若原生同步已开启，颜色随普通配置同步，不因此抓取图标 |
| ZIP备份导出和恢复 | 文件处理在本机；恢复后的配置按用户已开启的同步及背景模式正常工作，不批量抓取网址 |
| 开启浏览器同步或更新可同步配置 | 经浏览器原生同步服务传递配置，Covelet 无服务器参与 |
| 用户提交搜索或打开网址、来源链接 | 浏览器直接访问用户选择的目标 |

插件不使用在线字体、第三方 favicon 代理、远程脚本、内容 iframe、公告接口、自动崩溃上报或遥测服务。网站官方 CDN 或用户指定的图标服务器可能收到其图片请求，不能将此称为“没有任何网络请求”。浏览器的扩展商店更新通信由浏览器负责，不属于 Covelet 页面或后台的数据上传功能。

## 权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 本地保存配置；按用户开关使用浏览器原生同步；自定义存储的访问凭据仅用 storage.session 保留 |
| `search` | 将默认网页搜索交给浏览器默认搜索提供商 |
| `favicon` | 通过浏览器原生接口读取用户输入来源的已有图标，不枚举历史，不需要逐站内容授权；安装／更新可能显示相应权限提示 |
| `activeTab`、`scripting` | 用户点击工具栏后读取当前页标题、网址、图标声明；包内函数只读 head 中的图标链接，不常驻读取其他页面 |
| `alarms` | 调度本机倒计时及闹钟，不联网；浏览器可能延迟提醒 |
| 可选 `notifications` | 用户开启提醒时申请，用于系统通知；不向服务端上传通知内容 |
| `https://www.bing.com/*` 主机访问 | 获取每日背景信息和图片；请求地址在代码中限定为图片信息和图片路径 |
| HTTP／HTTPS 可选主机访问 | 站点识别只按需授权实际来源并读取根首页及同源图标；自定义存储同步只按需授权用户选择的 HTTPS 来源，GitHub 组件按需授权 github.com，不申请整体全部站点授权 |

新标签页通过 `chrome_url_overrides.newtab` 指向包内页面。安装时不取得全部网站的内容读取能力，可选来源范围也不表示所有来源已获授权。插件不申请 history、tabs、地理位置或书签库权限；activeTab 仅由用户点击授予当前来源的临时访问。Bing 权限用于壁纸，可选来源用于站点识别、用户自选存储同步或 GitHub 组件，均不执行远程代码。图片请求与网站内容读取权限不同，按上述图标规则披露。

## GitHub 贡献组件（2026-10-20 开发迭代）

扩展 → 开发工具中的 GitHub 贡献组件由用户主动添加。正式扩展在“使用”或主动刷新授权操作中申请 `https://github.com/*` 访问，仅请求所填用户名对应的公开贡献日历。不要求登录 GitHub 或提供访问令牌，不携带 Cookie／Referer，不跟随重定向；GitHub 可看到该用户名、连接 IP、时间及必要请求头。日历可能包含用户在 GitHub 主动公开的私有贡献数量，不读取私有仓库内容。

用户名、尺寸、时间范围和组件位置作为桌面配置，随用户启用的同步或导出备份传播。日期、次数及等级最多缓存八个账号，仅在本机，不同步或打包进 ZIP；不保存 GitHub 页面 HTML、脚本、图片。切换时间范围只计算已有缓存，不增加请求；移除组件停止后续刷新，已有缓存可能暂时保留。

计算内核 `github-core.wasm` 随包发布，不下载远程代码。开发预览中的本地 GitHub 日历代理不进入正式安装包。此项尚未更新到 Google Sites 的原发布版隐私页；商店发布前需同步更新公开说明，不能把本地修改描述为已经公开发布。[详细边界](扩展与组件.md)

## 数据控制和反馈

用户可编辑、删除相关内容，关闭同步、改用本地背景，并主动导出备份到自己选择的位置。备份保存配置和被引用的自定义网站图标，不保存 Bing 缓存或用户壁纸。恢复快照和同步冲突记录可能暂时保留旧内容；本地删除与浏览器同步数据删除是不同操作。彻底清理时需要同时考虑本地快照、浏览器同步副本、其他设备及已导出的备份。

卸载扩展或清除浏览器配置可能移除本地数据，卸载前应导出需要保留的内容。自己导出的备份文件不会随卸载自动删除；卸载也不应被描述为已经删除浏览器厂商的云端副本。

反馈只在用户主动发起时提供。插件不自动上传日志、截图、网址或备份；用户自行选择是否分享，并应先检查其中的信息。发布者 Morley，支持邮箱 support@mudong17.com；公开隐私页为 https://sites.google.com/view/covelet-privacy，当前公开页仍对应原提交版。

功能、权限或数据行为变化时，需要同步更新本文和商店隐私声明，并按适用规范告知用户。发布前的核查清单见[Chrome 上架与搜索规范](Chrome上架与搜索规范.md)。

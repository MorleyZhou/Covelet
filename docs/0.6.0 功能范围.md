# Covelet 0.6.0 功能范围

确定日期：2026 年 11 月 14 日。产品基线为已发布的 `v0.5.1`，对应提交 `3af8e44100a50e6de7efd92ac482e30ae3f26c34`。本文整合两轮功能分析，确定 12 项交付范围、首版边界和开发批次。用户已授权六批依次开发，每批本地自测通过后合并并推送 main，不创建 PR、不运行 Actions；全部完成后完整回归，暂不发布或提审。

## 版本目标

**更快找到资料，打开桌面继续工作，方便把资料带进来、带出去。**

用户把已有收藏迁入 Covelet，保留备注和标签；通过搜索条件找到项目资料，把项目便笺和动态清单固定到桌面；浏览时继续把选文追加到同一篇便笺，最后可以导出为其他工具可读的 Markdown 资料库。

延续无 Covelet 账号、无广告、无遥测及本机加密主副本的定位。新增组件由用户主动添加，不增加首页默认常驻区域。本批新增的搜索、筛选、组件展示、文件解析及导出均在本机完成，不新增远端服务、命名权限或必需主机权限。现有显式图片获取、壁纸、用户配置的同步等行为继续遵循各自规则，不能把整款产品描述成完全不联网。

## 确定的 12 项功能

按用户能独立完成的新动作计数。共同数据模型、翻译、性能优化、无障碍和测试属于交付工作，不另计功能。

| 编号 | 功能 | 用户能完成的新动作 | 首版验收 |
| --- | --- | --- | --- |
| 01 | 全局命令面板 | 用一个入口查找内容、切换桌面、打开清单或设置，以及执行新建、导入、导出等已有动作。 | Covelet 页面提供 `Ctrl/⌘+K` 和可发现的入口；内容与操作分区，支持键盘选择、返回和关闭。浏览器外部唤起沿用现有扩展快捷键配置。删除、覆盖、同步冲突继续走既有确认。 |
| 02 | 结构化本机搜索 | 输入 `tag:"项目 A" type:reading is:unread` 等条件找到资料，并保存为动态清单。 | 首版支持 `tag:`、`-tag:`、`type:`、`is:`、`domain:`；解析结果展示为可读条件，可修改和清除。与筛选界面共用条件模型，保留普通文字、网址直达、引擎关键词及桌面名跳转。 |
| 03 | 从全局搜索定位便笺命中 | 找到便笺后，直接看到命中的段落，再跳到上一处或下一处。 | 只传递实际正文检索词，打开指定便笺并临时高亮、定位；不修改正文、文档格式或修订。标题、标签或备注命中但正文无命中时，正常打开并如实提示。 |
| 04 | 指定便笺固定到桌面 | 将一篇项目便笺固定展示，点击直接继续编辑这一篇。 | 使用稳定记录引用，支持现有组件尺寸；编辑后更新展示。移除组件保留便笺，删除便笺显示引用失效，隐藏状态不泄露标题、摘要或数量。保留通用便笺组件。 |
| 05 | 动态清单固定到桌面 | 桌面直接展示“项目资料”“开发未读”等清单，新内容自动进入。 | 用户选择已有清单；按尺寸展示数量或有限条目，可直接打开记录。实时使用原内容及筛选规则，删除组件保留清单；清单删除、失效或隐藏时保持正确的状态与隐私。 |
| 06 | 每个桌面独立外观 | 为工作、学习、生活桌面分别选择背景、遮罩或模糊，也可继承全局。 | 首版仅覆盖纯色、渐变、已有内置背景、当前随机壁纸及遮罩/模糊；绑定逻辑桌面身份。随机来源和轮换周期保持本设备统一，不恢复上传壁纸。切换、重排和恢复后正确，已有桌面默认继承全局。主题、网格列数和工具配置仍沿用原规则。 |
| 07 | 网页选文追加到已有便笺 | 同一主题的多次摘录进入同一篇便笺，每次保留出处。 | 保存前可选新建或追加，搜索选择可见便笺并预览。仅在末尾追加选文及来源块，保留旧正文；取消、超限、存储失败或并发修改不丢草稿，不覆盖新版本。 |
| 08 | 稍后读批量改标签与再看日期 | 将选中的多篇资料统一安排到周末，或增删项目标签。 | 支持统一设置/清除日期和增添/移除标签，预览数量及结果；只修改选中项和指定字段，保留其他标签、备注及阅读状态，沿用原子提交与并发检查。 |
| 09 | 动态清单增强条件 | 保存“开发或设计”“项目 A 但排除已完成”“未来七天再看”等清单。 | 标签支持全部包含、任意包含和排除；再看日期增加有限的相对日期范围。与结构化搜索共用模型，明确解释组合关系；失效或当前不可见的引用不自动扩大到全部内容。 |
| 10 | Raindrop 与 OneTab 文件迁移 | 将已有收藏的标题、链接、来源分组及支持的标签、备注带入 Covelet。 | Raindrop 首版限定 Netscape HTML 增强解析；OneTab 首版限定带标题的文本链接。读取用户选择的本地文件或粘贴内容，经字段与分组预览后导入。实现前用可再分发的真实导出样本冻结支持版本、字段和分组映射，不承诺未验证格式或远端账号迁移。 |
| 11 | Markdown 资料库导出 | 把选定的网站、稍后读和便笺导出为 Obsidian 等工具可阅读的文件与索引。 | 生成 Markdown ZIP，含可读索引、标签、备注、URL、适用的阅读状态和日期。使用安全文件名及标准 Markdown 链接，可按类型组织目录。支持字段使用 YAML front matter 表达；不承诺完整 Obsidian Vault、插件、双向链接或复杂块无损迁移。 |
| 12 | 导入重复项元信息合并 | 迁入的链接已存在时，仍可查看并保留来源独有的标签和备注。 | 默认继续保留本地；逐组比较本地与来源记录，用户明确选择后并入支持的信息。多个本地副本需明确选择目标，不擅自合并位置或覆盖正文；超限、隐藏、并发和取消均不产生部分写入。 |

01、02、03、09 构成查找路径；04—08 让找到的资料回到日常桌面和摘录流程；10—12 解决资料迁入迁出。指定便笺、动态清单组件由用户自行添加，首页默认布局保持简洁。

## 共享设计与功能边界

### 搜索与清单

结构化查询、可视化筛选和动态清单共用一种经过版本校验的条件结构。重复的正向标签条件默认表示同时包含；“任意包含”由明确的组合控件表达，排除标签另列。首版不提供任意嵌套布尔表达式。相对日期只适用于稍后读的再看日期，先提供今天及未来七天（今天至第六天，含首尾），以当前设备本地日期计算。

`is:` 首版仅支持稍后读的 `unread`、`read`、`archived`；使用该条件时，类型范围明确限定到稍后读。纯文本仍检索已有的名称、正文、备注、网址、标签及别名，保留近似中文拼音首字母匹配；带运算符和不带运算符都覆盖回归。识别为运算符但参数无效时显示可修正的错误；不存在、失效或隐藏的标签不退化为无条件查询。

普通网址和引擎关键词不被 `type:` 等解析误伤。编辑器和输入框内已有的文字编辑快捷键继续有效，中文输入法组合期间不触发打开或提交。页面快捷键与全浏览器扩展快捷键区分说明，不能承诺系统级键位一定可用。

全局搜索到便笺的定位词只在当前页面会话内使用，不进入便笺数据、同步或完整备份。在可见正文匹配，退出搜索或关闭后清除临时高亮。异步打开遇到已删、已隐藏或正在修改的记录时，保留当前草稿并重新确认目标。

本版不承诺新增持久倒排索引。先在当前约束范围内测量冷、热搜索及输入响应，再选择缓存或索引方案。派生索引如有需要，应可重建、不携带隐藏内容进入可见结果，也不作为可移植业务数据上传。

### 引用型桌面组件与外观

固定便笺和清单存稳定引用，不复制一份正文或结果。移除组件、删除目标、恢复目标、移动桌面及同一目标多处展示分别定义；目标恢复或身份重映射时，引用不能误指向另一条记录。组件隐藏与目标隐藏共同约束标题、摘要、结果、计数和搜索建议。完整备份保留这些引用；用于分享的桌面方案不携带个人便笺/清单 ID、名称或正文，只保留通用组件或待选择目标的占位，导入后由用户重新选择。

独立外观按逻辑桌面 ID 保存覆盖值，新增或旧桌面默认继承全局；响应式布局产生的临时分页不获得新的外观身份。首版只使用当前有效背景类型，不重新开放历史 `image` 上传壁纸。随机壁纸来源与轮换周期沿用设备设置，各个选择随机背景的桌面共享设备当前照片；不新增逐桌面图片池、来源或轮换历史。已缓存的 Bing / Commons 照片及署名遵循现有资源规则，切桌面和普通渲染只读取本地，不触发图片下载。新增外观覆盖值进入完整备份、同步及桌面方案中允许公开分享的部分，来源与周期保留现有设备排除规则。无法显示某张图时使用确定的本地回退，不因切屏重置随机壁纸轮换进度。

### 迁入、合并与导出

Raindrop 官方提供 HTML、CSV、TXT 等导出，本版仅选择其中的 HTML 路径。名称、URL 与文件夹结构复用现有流程；标签与描述仅在文件含有、样本确认且用户预览后映射。没有携带的元信息保持未知，不从网站补抓；高亮、上传文件和网页副本不属于本版兼容承诺。[Raindrop 官方导出说明](https://help.raindrop.io/export)

OneTab 首版处理支持样本中的 `URL | 标题` 行与空行分组，保留条目顺序。分隔符只按约定位置解析，不能截断 URL 或标题；缺失组名先显示可修改的导入组名。格式目标与“当前 OneTab 所有版本均能生成这种文件”是两回事：官方当前帮助没有完整文本格式规范，开发需验证样本并列出支持范围。仅迁移用户提供的链接文件，不捕获浏览器窗口标签集合。[OneTab 官方帮助](https://www.one-tab.com/help)

导入时的元信息合并区别于 0.5 的库内重复审阅：前者处理尚未入库的来源记录，后者处理已保存副本。规范化网址保持协议、查询参数和片段语义，不擅自移除跟踪参数、改成 HTTPS 或跟随重定向。名称和布局默认保留本地，标签可明确取并集，备注展示前后内容并由用户决定保留或追加。跨桌面相同网址可能是有意副本；有多个本地目标时，用户选定后才能应用。私密副本不得经分组、数量或预览泄露，冲突时提示重新处理，不能借此放宽导入去重或并发规则。预览同时记录导航、内容偏好和目标元信息版本，提交时共同重验，不能只检查导航 revision；新导航、新标签和备注合并在同一原子提交中全部成功或全部失败。

Markdown 资料库导出区别于现有“便笺 Markdown 导出”：它涵盖导航和稍后读，并保留其可表达的元信息与可读索引。目录先按内容类型组织；导航可表达桌面/文件夹路径，便笺没有文件夹模型，不虚构原本不存在的笔记层级。索引和相对路径在重名、特殊字符及大小写不同的文件系统上可用。YAML front matter 使用安全序列化，标题、标签和备注中的冒号、引号、井号、换行及 `---` 不能改变字段结构；Markdown 外链、相对路径和文件名另行正确转义，并覆盖括号、井号和中文路径的实际打开验证。

Obsidian 使用 Markdown，属性采用文件顶部的 YAML；这支持可阅读的文件交换，不等于完整 Vault 兼容。[Obsidian Markdown 导入](https://obsidian.md/help/import/markdown) · [Obsidian 属性格式](https://obsidian.md/help/Editing%2Band%2Bformatting/Properties)

Covelet 标签允许空格等文字，Obsidian 原生标签有字符及非纯数字约束。导出以 `covelet_tags` 列表保留全部原名，并在索引中提供可读标签；原生 `tags` 列表只包含无需改名就符合目标规则的标签。其余标签在预览中说明仅作为属性保留，不替换字符或静默合并名称。[Obsidian 标签格式](https://obsidian.md/help/tags)

所有普通交换导出排除标记隐藏的内容，即使当前已解锁；索引、标签、文件名和数量遵循同一规则。资料库导出从导航、便笺/阅读及偏好取得一致快照，并在生成可下载结果前重验相关版本和隐私状态；导出期间的标签、隐藏或正文修改不得产生混合版本文件与索引，冲突时保留选择并提示重新生成。文件读取和解析本身不加载远程图片、执行 HTML 或访问来源网站。导入确认阶段如沿用现有显式图标准备流程，必须逐来源授权、可取消，并与纯文件解析区分。导出不下载附件。

沿用现有容量边界，遇到超限或不支持的复杂便笺结构时，预览列出问题，让用户取消或明确排除后分批导出，不能静默截断或丢字段后宣称成功。原样恢复仍由完整备份承担；Markdown ZIP 是未加密交换文件，不能称为加密备份。新增的导入/导出适配器必须有字段保留与损失说明，不重复把 Firefox HTML 和普通 Markdown 标成新功能。

## 发布验收要求

1. **可移植数据与混合版本。** 新的组件引用、外观、筛选和导入元信息同时覆盖加密本机存储、完整备份、恢复前副本及自备存储同步；搜索临时高亮等派生状态不进入同步。验证正式 0.5.1 原地升级、旧备份、不同设备密钥下的离线恢复，以及旧客户端安全拒绝未知字段，避免缩水回写。保持现有整组冲突选择语义，不引入记录级云同步合并。
2. **失败和并发。** 覆盖取消、记录删除/隐藏、两标签页编辑、同步导入、存储失败、容量超限、身份冲突和未知格式。比较失败前后数据，证明未发生部分写入或覆盖新编辑。
3. **实际 Chrome 与 Edge 扩展。** 在隔离配置加载真实解压包，检查键盘、中文输入法、焦点返回、读屏名称与结果状态、触屏点击/滚动、200% 缩放、深浅色、高对比及八语窄窗口。保留网站/文件夹、布局编辑、现有快捷键、导入导出和隐藏内容回归；无本地应用服务器替代验收。Windows 实测与未执行的 macOS `⌘` 路径分别记录。
4. **资料互通。** 对有版本/来源说明且可再分发的 Raindrop、OneTab 样本验收；使用普通 Markdown 和 Obsidian 实际打开导出目录，验证索引、标签、URL、备注、支持的便笺结构及重名文件。Firefox 书签 HTML 是既有兼容性回归，不是 Firefox 浏览器适配完成。
5. **性能与网络。** 使用接近当前条目上限的合成资料记录搜索、面板打开、组件更新、导入预览及导出耗时，发现阻塞再针对性优化。普通渲染、切屏、解析文件和本机检索的网络行为分别检查；现有显式联网操作单列。运行受影响测试、现有回归、WASM 和包检查，结果按实际通过/未验证记录。
6. **同步证据。** 本版新数据至少覆盖合成双设备同步、整组冲突、删除恢复和备份往返；有可用的维护者专用端点时，按既有维护范围使用 GitHub 做真实双配置验证。没有真实凭据或端点时明确记录缺口，不使用私人资料、不扩大服务商验收范围，也不把合成响应描述成真云通过。
7. **使用价值。** 用一组实际项目资料验证“迁入保留信息 → 搜索找到段落 → 固定桌面继续使用 → 追加摘录 → 导出仍可读”。自愿试用反馈用于调整入口；没有采集时不能声称已证明活跃度或留存增长。

## 延后项目与理由

| 项目 | 处理决定 |
| --- | --- |
| 单篇便笺历史、便笺模板、网页与摘录关联 | 留作 0.7 优先候选。本版先完成打开、定位、追加和迁移路径；历史还需冻结容量、裁剪与同步规则，不能用已有回收站代替。 |
| 同步密码更换 | 留作 0.7 的独立安全流程：验证旧密码及完整数据，处理待上传/冲突，向新空目录写入并回读验证，成功后切换本机目标。不能声称旧目录和其他设备旧副本已撤销或删除。当前保存连接密码不等于重加密远端。[当前缺口说明](自定义存储同步.md) |
| 定时本地加密备份 | 先验证目录授权、权限持久性、浏览器生命周期、密码保管和备份保留；不能承诺页面或浏览器关闭时仍定时写入。文件系统 API 的选择器依赖用户操作，不能直接当作后台服务。[Chrome 文件系统访问说明](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access) |
| 记录级云同步合并 | 独立设计基线、删除墓碑、图片引用和三方冲突处理。“导入重复项元信息合并”不改变云同步协议，不能相互替代。 |
| 完整网页离线归档、回访高亮、便笺双向链接 | 涉及正文提取/安全显示、网页锚点或文档关系，不纳入此次普通搜索与文件交换。 |
| 侧边栏、网页右键捕获、原生标签组 | 先验证收益与额外权限、不同浏览器行为，本版不扩命名权限。 |
| 失效链接联网扫描 | 默认手动、逐来源授权的方向保留；须区分真实失效、需要登录、反爬和网络异常，不能只凭 HEAD 失败判定或自动改 URL。 |
| WebAuthn 隐私解锁 | 需独立验证扩展来源、平台凭据与本机隐藏密码的关系及回退路径，不等同于数据加密密钥管理。 |
| 最近使用/频率排序、单字母热键、Vim 导航 | 可能改变固定布局和已有键位；本版先把新流程的键盘及无障碍验收完成。 |
| 固定随机壁纸、自动壁纸明暗调整、倒计时/专注计时 | 固定照片和自动调节壁纸明暗是后续外观候选；现有文字/组件对比适配及手动遮罩保留。计时器涉及重启此前移除的产品方向，本版不恢复。 |
| Pocket 专用迁移 | Pocket 已关闭，官方说明导出和 API 均于 2025 年 11 月 12 日关闭；不承诺在线搬迁。已有本地旧导出文件可按匹配格式使用，专用适配需有样本与明确需求。[Mozilla 官方说明](https://support.mozilla.org/en-US/kb/future-of-pocket) |
| 完整 Obsidian Vault 导入、Infinity / WeTab 专用迁移 | 普通 Markdown / HTML 继续使用已有入口；全库属性、附件、插件、复杂链接和厂商私有格式另行定义，不以文件能打开就宣称无损兼容。 |
| Firefox 浏览器上架与适配 | 属于新的浏览器交付矩阵，需要构建、API、权限、升级与审核验证；导入 Firefox 书签并不意味着能在 Firefox 运行。 |

0.6.0 不恢复窗口标签快照、浏览器阅读清单导入或旧工具包，继续遵循 [0.5.0 已明确的产品边界](0.5.0%20功能范围.md)。

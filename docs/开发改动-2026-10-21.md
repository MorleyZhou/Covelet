- 时钟与 GitHub 的全部尺寸及冻结拖拽预览接入“视觉增强”：按各自位置调用原 WASM 壁纸统计，生成带壁纸色调的半透明背景，并匹配内部文字、次要文字、表针及贡献色阶。明确浅色／深色主题保持其明暗方向，跟随系统选项可按当地亮度选择，并用窄平局区间减少切换；启用时使用轻微背景模糊，不加装饰外框／外发光。
- 局部分析预算为 64 个文字／操作区域、48 个图标和 48 个组件，单块仍最多 256×64，静态复用且只保留最新待处理画面。关闭增强、处理失败或退出目标后恢复原变量及主题底色；派生色不保存、备份或同步，无新增请求、权限或图标图片变色。

本轮只修改源码和说明，未运行测试、检查、构建或浏览器验收；复用已有 WASM，不改 Rust／ABI／二进制或重新生成资源。冻结发布包及线上材料未变。下方闹钟功能、保留旧闹钟计划的历史描述由本节覆盖。

- 时钟本机运行数据和闹钟仅在布局保存成功后按明确的删除操作清理；确认前、草稿取消或普通删除屏幕时均不清理。并发冲突继续阻止保存／删除操作。
- 视觉增强默认开启；新配置及完全没有视觉字段的旧配置采用该默认值，明确关闭的新开关／旧开关保留关闭。
- 图标参考 [Apple App Icons](https://developer.apple.com/design/human-interface-guidelines/app-icons) 的前景／底色分层和统一遮罩。原图保留：X 的透明圆形边缘以黑底补齐，Grok 的透明白色标志使用黑底，YouTube 用原图红色 `#ff0033` 填满透明留白；没有额外绘制 Logo 或替换成图标库字形。支持时使用连续圆角，旧浏览器保留圆角方形。
- 按用户最新澄清，自动配色只调整图标背景，图片不反转、不染色、不加变色滤镜。逐项取得壁纸色调作为轻微底色，并确保透明浅色标志用暗底、深色／彩色标志用浅底；文字回退及文件夹可按当地亮度适配，接近分界时保持原选择。完整底图及匹配边缘底色保留，避免重新出现嵌套圆形／白框。已有手动底色优先，背景色浮层的“自动”清除手动覆盖。不能安全读取像素的远程图片不加权限或再次请求。
- 工具栏快捷添加也默认保留自动背景，不再把预览回退色保存成手动覆盖；已有手动底色保留，点击“自动”可清除覆盖。
- 文字按实际字形下方像素加权，考虑字体、字距、对齐、省略号、设备像素比、分页裁切和细分位置；纯色／渐变直接在真实屏幕坐标取样，Bing 复用同次解码产生的最大边 2048px 细节缩略图，内存最多留两份。
- 单块采样最多 256×64，文字／操作区域和图标背景分别最多 64／48 块，在剔除屏外区域后计数，静态块复用缓存，只传局部像素到固定 Worker。Rust 增加 `analyze_caption`：比较整体覆盖、八段字形中最弱局部、严重低对比及周围线条，降低大块亮色掩盖暗线的影响；使用窄平局区间。复杂背景仅增加轻阴影，高风险细节再加 0.7px 反色文字描边，纯色可读背景无额外效果，不宣称照片逐像素达到 WCAG 要求。

已通过 `node scripts/build-wasm.mjs --generate` 生成 9,471 字节的包内视觉 WASM 及源码／二进制校验和；此模式只编译资源，不调用模块检查或验证。原始官网图片、冻结 v0.1.0 包和线上材料未改。按用户要求未运行测试、检查、整包构建或浏览器验收。下方同日早些记录中的 Shift、单色图像反转、1024px 细节、512px 全屏采样、旧默认关闭及原 WASM 未变的说明由本节覆盖。

## 后续：统一视觉增强与局部文字配色

- 设置 → 增强合并为一个“视觉增强”开关，统一控制壁纸界面配色、图片图标适配及导航文字明暗。新配置默认关闭；旧的两个开关任一开启即迁移为开启，已有明确的新开关值优先，不重置导航和手动外观。
- 网址、文件夹与组件标题逐项取文字下方区域的背景，亮部使用黑字、暗部使用白字，顶部按钮和分页同样按位置适配。拖动中的组件标题、窗口缩放、滚动、切屏及布局变化会更新取样。
- 纯色及当前颜色编辑器产生的渐变复用实际色标、方向和曲线；显示和颜色预览显式使用 sRGB 插值，保存的 CSS 与旧配置格式保持兼容。已识别的普通旧线性渐变可取样，其余旧渐变保留原显示并回退原文字样式。
- Bing 复用当前本地图片缓存的缩略像素，按 center/cover 的实际裁切、壁纸缩放、模糊、手动遮罩和同一层淡化渐变还原低分辨率背景。固定 Worker 调用现有包内 Rust 亮度及分位数算法，比较黑／白字的局部对比度，不依赖第三方模型或服务。
- 以 [WCAG 普通文字 4.5:1](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 为选色参考；复杂纹理区域仅补充小幅文字阴影。低分辨率与分位数取样不能证明照片上每个文字像素符合无障碍规范。
- 视口采样最大边 512px，最多处理 64 个可见区域；每块 WASM 输入最多 64×24。静态画面复用结果，拖拽中限频并只保留最新待处理画面，近似平局时保持上次文字明暗，避免闪烁。不再为统一白字自动压暗整张照片，手动遮罩仍保留。
- 只有统一开关进入本地、ZIP 和已开启的原生／自定义同步。色板、缩略像素、每项文字颜色均为本机派生结果；旧原生同步文档仍可读，明确关闭新开关不会被旧的开启值重新激活。没有新增外部图片请求、权限、上传或新的 WASM 二进制。

实现见 `app/src/lib/navigation-contrast.js`、`use-navigation-contrast.js`、`visual-worker.js` 与相关设置／同步迁移。按用户要求，本次未运行测试、检查、构建或浏览器验收；冻结发布包和在线材料未更新。

- 六个默认站点使用各服务官网提供的高清图片，分辨率为 Google 256、YouTube 144、GitHub 560、X 512、ChatGPT 180、Grok 512 像素。图片随包提供；来源记录见 `app/src/lib/default-icon-assets.json` 和 `app/public/assets/navigation-icons/SOURCES.txt`。
- 完整底图铺满统一圆角，透明标志保留适当留白；视觉增强遇到完整方形图案时保留原图显示，避免重复留白及低分辨率中间图放大。
- 新增网站时优先使用已知官网资源、网站标准 touch 图标和已有授权可读的站点图标；否则使用浏览器原生缓存和常规图标地址，全部失败才显示名称文字。仅检查当前正在添加的网站，不批量扫描导航或书签。

- 原生同步只传图标 HTTP(S) 地址、显示方式及背景色，不传图片文件或本地资源 ID；旧的本地图标仍兼容读取和 ZIP 迁移。另一台设备按地址加载，来源失效可回退。

Covelet，让新标签页成为自己的空间。

把常用网站、搜索和日常记录放在手边。没有广告、推广链接或 Covelet 账号，没有开发者遥测与使用统计。

自由整理
拖拽网站创建文件夹，在多屏桌面自由放置图标和组件。编辑布局时默认支持多选，可批量整理、跨屏移动和合并文件夹。文件夹直接在标题中重命名。右键编辑网站，或从浏览器工具栏将当前页添加到导航与稍后读。

清晰的图标与外观
优先获取真实高清图标及网站提供的明暗版本，无可用图片时回退文字。可调整图标底色、尺寸、间距和每行数量。视觉增强在设备本地分析背景，让文字、图标底色及组件保持清晰；原始品牌图案不会被自动染色。选择 Bing 每日壁纸，或设置自己的颜色、多色渐变和渐变曲线。

尊重浏览器的搜索
默认搜索使用浏览器当前提供商，不改变默认搜索设置。也可主动选择 Bing、Google、DuckDuckGo 或自定义模板。输入时仅搜索已保存导航，不请求在线联想。

按需添加的随包扩展
• 时钟：世界时钟、时区对照、倒计时与计时。
• 便笺：富文本记录、预览、搜索与置顶。
• 稍后读：按未读、已读和归档整理链接。
• GitHub 贡献：查看自己选择的公开贡献日历。
• 自定义存储同步：加密配置同步、版本浏览、差异查看及选择性恢复。
工具栏的标签快照支持手动保存当前窗口，并选择链接恢复到新窗口。

数据由自己掌握
导航和工具内容优先保存在本机。浏览器原生配置同步默认关闭；自定义存储同步只有在用户配置、解锁并授权后才连接所选服务。图标同步保存来源地址，不传图片文件。便笺、稍后读和标签快照不随导航配置同步，可单独导出工具数据。支持本地书签 HTML 导入及导航 ZIP 备份。

内置英文、简体中文、繁体中文、日语、韩语、德语、法语、俄语，默认跟随浏览器语言，不支持的语言回退到英文。

Bing、图标来源、GitHub 和用户选择的搜索/存储服务可能收到正常连接请求，详见隐私政策。所有执行代码和 WASM 随包提供，不加载远程执行模块。无需 Covelet 登录；此版本尚未接入订阅或支付。

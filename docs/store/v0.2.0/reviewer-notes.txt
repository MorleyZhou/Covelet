Covelet 0.2.0 is a customizable new-tab page for the user's saved sites, search and packaged desktop tools. No Covelet login, payment or subscription is required in this version. Default search uses chrome.search.query without changing the browser provider. All JS/WASM ships in the ZIP; remote resources are bounded website metadata/images, Bing wallpaper data, a user-chosen public GitHub contribution calendar, or encrypted user-configured storage records, never executable code.

Core review: open a new tab; add/edit a website; drag two sites together to make a folder; open the folder and drag a child to its desktop exit; right-click navigation > Edit Layout for selection, free placement, multi-screen moves and batch folder creation. Add tools using the Extensions button next to Settings. Clock/Notes/Read Later work without accounts. GitHub requires only a public username and its exact origin grant. Native configuration sync is opt-in in Settings > Data and depends on browser sync settings.

The toolbar popup offers Website Navigation, Read Later and Tab Snapshots. Adding the invoked page uses activeTab plus a packaged scripting function to read title/URL/head icon declarations, and stores only after Save. Snapshot capture requests optional tabs only on a manual action, reads only the selected window, excludes incognito and internal URLs, and keeps data locally. Confirmed restoration uses a new window. Optional readingList is requested only for an explicit import; the original browser list is not modified.

Required favicon reads the browser's existing icon cache. Required alarms schedules countdown completion; optional notifications is requested only when reminders are enabled. No dedicated alarm-clock feature, history, location or bookmark-library access is included. Exact optional origins support explicit website recognition, public GitHub data and user-configured storage; the declared http(s) host range is not granted at installation.

Notes, read-later records and snapshot contents remain device-local and are excluded from navigation/native/custom-storage configuration sync. Users can separately export/import tool JSON. Native sync carries icon source URLs instead of image files. Custom-storage configuration is opt-in and encrypted with PBKDF2-SHA256/AES-256-GCM; credentials/passwords use storage.session and require re-entry after browser restart. No developer server receives these records.

The updated bilingual privacy policy is https://sites.google.com/view/covelet-privacy (October 22, 2026; v0.2.0). No ads, affiliate redirects, analytics or telemetry are included. Five updated screenshots use isolated sample data, genuine site icons, an original color gradient and a public GitHub calendar; they do not contain the user's private records.

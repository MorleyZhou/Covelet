## 中英文商店文案

### 中文

**标题**：Covelet

**简短说明／Manifest description 草稿**：

> 简洁的新标签页：拖拽网站与文件夹、尊重浏览器默认搜索、自定义外观布局，可选浏览器同步。无需账号，没有广告。

**完整说明**：

Covelet 把新标签页留给你常用的网站和搜索。全新安装从空桌面开始，通过网格中的加号添加网站；没有预置推广站点，无需创建 Covelet 账号，也没有广告、联盟跳转或使用统计。

把一个网站图标拖到另一个图标中心可创建文件夹，拖入现有文件夹、拖出以及拖到边缘调整顺序。文件夹名称可以直接在顶部编辑。右键保留编辑和删除；网站图标获取失败时自动使用文字，支持修改图标背景色。

搜索默认使用浏览器自己的搜索提供商，不修改你的默认引擎。你也可以为本次搜索主动选择必应、Google、DuckDuckGo，或添加自己的搜索模板。有图标时显示标识，无图标时保留名称；不会在输入时请求搜索联想。

你可以调整主题、背景、图标大小、间距及每行数量，显示或隐藏本机时间日期。支持 Bing 每日背景、内置背景、纯色和渐变。Bing 图片由设备独立获取和缓存；接口不可用时会回退。

设置中的书签 HTML 导入在本机处理。ZIP 备份可保存和恢复配置及被引用的网站图标；浏览器原生配置同步默认关闭，主动开启后由浏览器厂商处理，需要相应浏览器账号和同步设置，不承诺 Chrome 与 Edge 账号互通。

Covelet 开发者不接收你的导航、搜索词或图片。默认 Bing 背景会连接 Bing；网站识别和自定义引擎图标获取会在逐站授权后直接访问目标来源。图标图片和 Bing 缓存不进入浏览器同步，自定义搜索引擎图标缓存也不进入 ZIP。完整数据流、权限及控制方式见隐私政策。

### English

**Title**: Covelet

**Short description / manifest draft**:

> A calm new tab with drag-and-drop folders, browser-default search, daily backgrounds and optional browser sync. No account or ads.

**Full description**:

Covelet gives your new tab a quiet home for your websites and search. A fresh installation starts with an empty desktop. Use the plus tile to add a website. There are no sponsored shortcuts, ads, affiliate redirects, usage analytics or Covelet accounts.

Drag one website onto another to create a folder. Drop websites into folders, drag them out, or use the edges to change their order. Edit an open folder's name directly in its title. Right-click to edit or delete an entry. Website icons use a validated image when available and a text fallback otherwise, with adjustable icon background colors.

Search follows your browser's current default provider without changing that setting. You may explicitly choose Bing, Google or DuckDuckGo for the current tab, or add a custom search template. Covelet does not request online suggestions while you type.

Adjust the theme, background, icon size, spacing and number of icons per row. Show or hide a simple local clock and date. Choose Bing daily backgrounds, a built-in background, a solid color or a gradient. Each device fetches and caches its own Bing image, with a fallback when the service is unavailable.

Import a bookmark HTML file locally from Settings. Export and restore a ZIP backup of your configuration and referenced website icons. Optional browser-native configuration sync is off by default and requires your browser account and applicable sync settings. Sync delivery can be delayed, and interoperability between Chrome and Edge accounts is not promised.

The Covelet developer does not receive your shortcuts, search queries or images. Bing receives background requests. Authorized website and custom search-icon recognition connects directly to the selected origin. Image bytes remain on the device; custom search-icon caches are also excluded from ZIP backups. Read the privacy policy for the full data flows, permissions and controls.

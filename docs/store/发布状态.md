# Covelet 发布状态

## 0.5.1 发布与送审（2026-11-12）

本轮修复同步冲突的整份本地／云端覆盖、中断任务改选及随机壁纸短循环。764 项单元测试、6 项同步及 2 项壁纸实际解压扩展回归通过；浏览器网络响应为合成数据，真实用户云端未复验。

- 源码与安装包版本：**0.5.1**，提交及合入 `main` 进行中。
- GitHub Release：[v0.5.1](https://github.com/MorleyZhou/Covelet/releases/tag/v0.5.1)，本轮发布进行中。
- Chrome Web Store / Edge Add-ons：准备通过[发布工作流](https://github.com/MorleyZhou/Covelet/actions/workflows/release-stores.yml)上传并提交审核；以各任务回执为准，不表示已经审核通过。
- 官网隐私政策：同步说明 Commons 元数据与图片的两个按需授权来源；公开部署进行中。

[正式发布说明](../releases/0.5.1.md) · [本地验收证据](../development/0.5.1-local-validation.md)。以下为各日期保留的历史记录，不代表当前发布状态。

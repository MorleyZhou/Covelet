Covelet 隐私政策

发布者：Morley · 版本0.1.0 · 更新日期：2026年10月19日 · English

Covelet是免费的浏览器新标签页扩展，提供网站导航、搜索、外观和布局。无需Covelet账号，没有广告、推广跳转、遥测、使用统计或自动崩溃上报，开发者没有接收插件数据的业务服务器。我们不会把“开发者不接收”描述为“不处理数据”或“绝不联网”：本机保存、Bing背景、用户授权的图标识别、搜索和可选浏览器同步的数据流如下。

1. 本机处理和保存

  • 用户添加、书签文件导入或ZIP恢复的网址、名称、文件夹、顺序、网站图标及图标背景色。
  • 自定义搜索引擎的名称、地址模板、顺序，以及主题、背景、图标尺寸、每行数量等外观布局设置。
  • 本地快照、同步运行状态、冲突恢复信息和主动导出／选择恢复的备份文件。
  • 设备内的网站图标资源、单张Bing背景缓存及独立的自定义搜索引擎图标缓存。

配置以浏览器扩展本地存储为主副本，图像使用设备内资源或缓存。新安装为空桌面，不预置推广网站；升级或空白演示不删除用户已保存的网址。没有新增壁纸或网站图标上传入口，既存合法本地图标和兼容备份仍保留。搜索词不保存为搜索历史；我们不请求浏览历史权限，也不读取整个浏览器书签库。网址可能由用户自行包含个人信息或令牌，保存和分享前请检查内容。

时钟仅用设备系统时间及本地时区，不请求授时、定位、天气或日历服务；只保存显示偏好，不同步当前时间、设备时区或查看行为。

2. 网站名称与图标识别

输入网站网址后，Covelet可从目标来源的根首页提取名称并获取同源图片。首次由用户点击识别入口申请该具体来源权限；已授权来源可自动识别。只处理根首页，不发送用户输入网址的路径、查询参数或片段，不发送Cookie、认证凭据或来源页，不经开发者服务器或第三方favicon代理。目标网站仍可能收到IP、请求时间和浏览器网络层信息；省略凭据不等于匿名连接。用户明确输入HTTP时，该请求不具有HTTPS传输保护。

远程HTML仅作有界文本解析，不执行脚本、不显示远程页面或加载其嵌入资源；不继续访问跨来源重定向或图标。首页请求限512KiB，每张候选图片限1MiB，单请求限5秒；受支持的图片经过校验、解码限制和重编码后保存在本机。图标不可用时自动使用名称文字。拒绝权限、超时或无图片仍可保存。不会扫描现有导航、导入书签、ZIP恢复或同步来的网址批量获取图标。权限可在浏览器扩展管理中撤销。

3. 搜索和搜索引擎图标

默认网页搜索使用chrome.search.query交给浏览器现有默认提供商，不读取其品牌、不修改浏览器搜索设置。用户主动选择其他引擎并提交时，浏览器直接访问所选提供商；输入时不请求在线联想，只有提交后才把查询交给相应提供商。打开网址和来源链接时同样直接访问目标，不经过Covelet跳转服务，不增加推广参数。目标网站和提供商按自己的政策处理连接和提交内容。

随包的必应、Google、DuckDuckGo展示Logo不因打开菜单而联网，不表示官方背书。用户新增或保存修改的自定义引擎时，插件可在用户手势中申请其具体来源的访问权限，再读取根首页和同源图标。请求不带搜索词、模板路径／参数／片段、Cookie或来源页，沿用上一节的图片与同源限制。拒绝或失败不影响保存和搜索。

自定义搜索引擎图标按来源缓存于当前设备，最多32个来源；本地持久缓存不可用时可只用于当前会话。打开页面或菜单仅查本地缓存，不自动请求或批量扫描已有、导入、恢复或同步的引擎。该缓存不进入导航资源、浏览器同步或完整ZIP备份。

4. Bing每日背景

新安装默认启用Bing每日背景。Covelet请求https://www.bing.com/HPImageArchive.aspx取得图片信息，再从同一主机的/th地址获取图片，并展示来源说明和链接。不附带用户导航、搜索词、图片、备份、遥测、Cookie或来源页。Bing仍会收到连接所需的IP、时间、路径和浏览器网络信息，并按微软隐私声明处理。

各设备独立按日获取并缓存单张背景，用于复用及离线回退；失败后冷却15分钟，优先旧缓存再回退内置背景。Bing图片不进入浏览器同步或ZIP备份。改用内置、纯色或渐变后停止后续Bing背景请求；已有缓存不会因此上传。公开接口可用性和图片供应可能改变。

5. 可选浏览器原生同步

同步默认关闭。主动开启后通过chrome.storage.sync把网址、名称、文件夹、顺序、搜索模板、图标背景色和可移植外观布局配置交给浏览器厂商。需要用户自己的浏览器账号及相应同步设置；Covelet不接收账号密码，不创建账号，不承诺Chrome与Edge账号互通，也不在应用层额外提供端到端加密。

搜索词、使用历史、图像二进制、本地资产引用、Bing缓存、自定义搜索图标缓存、本地快照、ZIP文件和本机同步开关不进入同步。其他设备对本地图标使用文字回退。同步受配额、延迟、失败和浏览器设置影响；API接受写入不代表另一设备已收到。关闭Covelet同步停止本机后续同步行为，不承诺删除浏览器厂商此前保存的副本或阻止浏览器继续处理已提交数据。

6. 书签文件、ZIP和恢复

设置→数据中的书签导入只解析用户主动选择的HTML文件，不读取或修改浏览器书签库，不执行脚本或加载嵌入资源，也不发送该文件。导入后的网址和单层文件夹按正常本地保存和已开启的配置同步处理。

ZIP备份在本机生成，包含配置及被引用的网站图标，不包含Bing背景缓存、旧用户壁纸或自定义搜索图标缓存；引擎名称和模板会随配置备份。恢复先校验格式、路径、关系和资源，再按用户确认替换。备份文件可能包含私人网址，请自行妥善保管；其不会因卸载扩展自动删除。

8. 保留、控制和联系

用户可编辑／删除条目、修改背景、关闭同步、撤销逐站权限并导出备份。快照、冲突记录、缓存、其他设备和已导出文件可能保留旧内容；删除本机条目不等于删除所有云端、快照或备份。清除扩展数据或卸载可能移除本地内容，先导出需要保留的数据；浏览器云端数据需通过相应浏览器的数据控制管理。没有开发者服务器副本可供远程代删。

反馈只由用户主动发送；插件不自动附送网址、日志、图片或备份。政策随实际功能变化更新。隐私或支持联系：support@mudong17.com。

English privacy policy

Updated October 19, 2026. Version 0.1.0. Publisher: Morley. Contact: support@mudong17.com.

Covelet is a free new-tab extension for website navigation, search, appearance and layout. It has no Covelet accounts, ads, affiliate redirects, analytics, telemetry or automatic crash uploads. The developer has no server receiving your shortcuts, queries or images. Local processing and the third-party connections described below still involve user data.

Local data

We store your shortcuts, names, folders, order, website icons, icon colors, search templates, appearance, layout, local snapshots and recovery/sync state on your device. Fresh installations start empty; updates do not clear existing shortcuts. Local time/date uses the device clock without location or time-service requests. Search queries are not stored as a history. We do not request browsing-history or bookmark-library access. Saved URLs can themselves contain personal information supplied by you.

Website and custom search icons

Website recognition requests permission for one selected origin. It reads only that origin's public root and same-origin raster icons, omitting cookies, credentials and referrers; the entered path, query and fragment are not sent. HTML is inertly parsed, not executed. Requests are bounded: 512KiB HTML, 1MiB per candidate image and 5 seconds per request, with image validation, decoding limits and re-encoding. Denial or failure leaves a text fallback and does not block saving. No existing, imported, restored or synced shortcuts are scanned in bulk. You can revoke access in your browser.

Built-in search-provider logos are packaged, so opening the menu does not fetch them. Saving a new or edited custom engine may request access to its origin and fetch a root-page/same-origin icon without sending a query or the template path. These images use a separate on-device cache for at most 32 origins, with a session-only fallback if persistent storage is unavailable. The cache is excluded from browser sync and ZIP backups. Page/menu rendering reads the cache without automatically fetching existing engines.

Search and backgrounds

Default searches use chrome.search.query and your existing browser provider without changing that setting. Explicitly selected engines receive queries only when submitted; no online suggestions are requested while typing. Opening a site goes directly to the selected destination without a Covelet redirect server or promotional parameters.

Bing daily background is enabled by default. Each device requests metadata from www.bing.com/HPImageArchive.aspx and an image from the same host's /th path, without cookies, referrers, shortcuts or search queries. One image is cached locally; failures have a 15-minute cooldown and use an older image or the built-in fallback. Switching to another background mode stops subsequent Bing background requests. The Bing cache is excluded from sync and ZIP backups. Image credits are displayed.

Bing, authorized origins, search providers and destinations may receive IP addresses, request times and other connection metadata and apply their own policies. Omitted credentials do not make a connection anonymous. An explicitly entered HTTP origin does not have HTTPS transport protection.

Optional sync and files

Browser-native sync is off by default. If enabled, the browser vendor processes portable shortcut/folder/search/appearance/layout configuration. It requires your browser account and sync settings; Covelet receives no account credentials, adds no separate application-layer end-to-end encryption and promises no Chrome-to-Edge account interoperability or delivery confirmation. Image bytes, local asset references, caches, snapshots, ZIP files, transient queries and device sync controls are excluded. Disabling Covelet sync does not delete the browser vendor's previously submitted copies.

Bookmark HTML import in Settings processes only the file you select, locally and without executing scripts or loading embedded resources. ZIP exports contain configuration and referenced website icons, not Bing images, old wallpaper or search-icon caches. Restore validates the archive before replacement. Imported/restored configuration follows your enabled sync and background settings. Backups can contain private URLs; exported files survive uninstalling the extension.

Controls and limited use

Permissions are limited to storage, browser-default search, Bing's background host and user-granted HTTP/HTTPS origins for recognition. All executable code is packaged. We do not sell user data or use it for advertising, profiling, unrelated analytics or credit decisions. Covelet's use of user data is limited to its disclosed new-tab features and complies with the Chrome Web Store User Data Policy, including Limited Use.

You can edit/delete entries, switch backgrounds, disable sync, revoke site permissions and keep a ZIP backup. Snapshots, conflict records, caches, exported files and other devices may retain older content. Removing local data or uninstalling does not prove that browser-vendor cloud copies were deleted; use your browser's data controls. Feedback is sent only at your initiative and is not automatically accompanied by logs or backups. Contact: support@mudong17.com.

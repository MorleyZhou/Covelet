# 局部配色与主题图标

## 配色规则

- 导航名称与图标、组件表面分开判断。名称仍按实际字形位置选择黑白，保留已有复杂壁纸下的细描边策略。
- 系统主题下，组件比较浅色与深色表面相对局部壁纸的对比度，避免暗处卡片继续用近黑色、亮处继续用近白色。沿用内置 WASM 给出的平均亮度与 10/50/90 分位数，使用小幅滞回和 95% 不透明表面；用户指定浅色或深色主题时保留该选择。
- 图标配色同时考虑图形和局部壁纸。在本机解码后的图像中，按透明度统计可见图形的 64 档亮度分布；先比较候选底色能看清的图形比例，再比较底色与壁纸的区分度。纯黑、纯白图形分别约束为浅底、深底，混合图形可选择可读的中性底。不能为追求壁纸对比而选出看不清图形的底色。
- 有真实深浅原图时先确定可读底色，再选择对应原图；只有单图时调整底色，保留图形原色。完整不透明应用图不改像素、不加外框。用户手动背景色优先。
- 底色、组件表面以 280ms 过渡，文字以 220ms 过渡。图标使用独立图片层，加载好新版本后淡入淡出；旧层保留自身的 SVG color-scheme，等待期间不闪空。快速切换时淘汰过期回调并限制图片层数，尊重系统“减少动态效果”。颜色／透明度过渡不触发重新采样，位移、尺寸变化仍按原规则处理。

## WASM 与浏览器分工

- `normalize_icon` 在同一份输入内存中完成缩放、透明度统计、单色判断、边缘底色识别和 64 档亮度分布。复用固定数组，不再在 JS 中逐像素扫描并维护颜色 Map。缩放后图像与小型统计记录一起返回。
- ABI 1 保留已有导出与 32 字统计记录，新增 `icon_presentation_ptr`、`icon_ink_ptr`；宿主读取前检查能力、指针范围、字段与数值范围。WASM 仍是随包提交的固定模块，使用 512 KiB 固定内存，不接受网络、DOM 或远程模块参数。
- 少量候选色决策继续在 Worker 的 JS 适配层中进行。网络获取、权限、网页声明、IndexedDB 和 DOM 使用浏览器 API；SVG／ICO 使用浏览器解码，动画使用 CSS。WASM 适合密集数值计算，不能直接替代浏览器接口，也不会让网络下载自动变快。
- 本轮没有做耗时测量，不能据此宣称具体倍数或端到端速度提升。该拆分减少了一次 JS 像素遍历和相关 Map 分配。

## 获取与数据

- 统一优先级为：高清双色原图 → 高清单图或 SVG → ICO → 浏览器缓存／文字图标。普通位图的高清门槛保留为短边至少 96px；SVG 按矢量内容生成最大边 256px 的本机显示图，ICO 不通过放大冒充高清。
- 网站首页、授权识别结果与当前页快捷添加保留图标声明的 `media`、`type`、`sizes`，并读取符合既有权限边界的 Manifest。仅使用网站公开声明的来源，不维护品牌适配名单，不猜测 dark/light 文件名，不抓取品牌素材下载页。仅收集名称时先返回首页元数据，避免旧 ICO 下载先于高清搜索。
- 先尝试明确声明的浅／深来源，两者都可用才启用切换；其次识别单个 SVG 自带的 `prefers-color-scheme` 样式。SVG 只作受限的静态 XML 检查，经浏览器被动 Image 解码；不把 SVG 节点插入页面，不执行脚本。拒绝脚本、foreignObject、外部引用、字体导入和超限内容。按照原图自身的 light/dark 样式生成两份 PNG，仅实际结果不同时才视为双色。
- 单次识别最多比较 7 个非 ICO 地址，另留 2 个 ICO 回退地址；共享地址共用结果，保留整体超时和来源检查。失败、拒绝访问或被 CORS 限制时保留浏览器／文字回退，不为每个图标弹出授权，也不使用第三方代理。
- 导航中的品牌图片已从安装资源移除，删除了旧的打包素材表和采集脚本。六个默认导航仅保留初始图标 URL；它们与用户添加的网站使用相同的显示、缓存和配色流程，不阻止后续动态发现。搜索引擎选择器的标志属于独立功能，本次保留。
- 新增或明确获取高清图标时读取元数据；已有导航不批量重新识别。可见图标按需缓存当前使用的图标地址，隐藏屏幕不会批量加载。独立 IndexedDB 缓存 `covelet.navigation-icons.v1` 最多 64 项、16 MiB、30 天，最多三个并发加载；失败短暂冷却，容量不足不阻止保存。位图最多 1 MiB，SVG 源文最多 128 KiB。自动请求无凭据、无来源页，使用已授予权限或站点自身允许的 CORS；明确点击高清获取时沿用指定来源的权限申请。
- 可选 `entry.iconVariants` 严格包含 `light`、`dark`，每项只有 HTTP(S) `url` 与 `fit`。对自适应 SVG，两项可指向同一个原始 SVG 地址。本机配置、备份、浏览器同步、自定义配置同步和版本差异仅保留原始地址；缓存图片、SVG 派生 PNG、Blob URL 和亮度分布不进入这些配置。既有合法本机图标及 ZIP 恢复继续兼容。
- 换网站来源、手工替换图标地址会清除旧配对；快捷添加修改其他字段时保留已有配对。取消表单不保存。
- 旧数据没有配对时照常读取；旧版本不认识新增字段，有配对数据的设备应先统一更新再同步。

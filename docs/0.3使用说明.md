# Covelet 0.3 候选使用说明

候选构建目录为 `app/dist/extension/`，包版本仍为 0.2.2。更新已加载的扩展后，重新打开新标签页。

## 首页与导航

- 新安装的桌面为空，点击右上角「添加网站」添加自己的网址。
- 时间、日期显示在搜索框上方。「设置 → 外观 → 极简模式」可隐藏它们。
- 搜索框可以搜索导航、便笺和稍后读，也可以输入网址。方向键选择本机结果，Enter 打开，Escape 收起。
- 将一个网站拖到另一个网站上可建立文件夹，再拖入其他网站。打开文件夹后，可拖回桌面。
- 点击文件夹名称可以改名，Enter 保存，Escape 撤销本次名称修改；再次 Escape 关闭文件夹。
- 右键进入「编辑布局」后可整理位置，保存后保留；取消会放弃本次布局调整。

旧时钟组件不再出现在桌面和扩展目录中，旧配置、计时数据及备份仍保留。

## 自备存储同步（Beta）

打开「设置 → 数据 → 自备存储同步（Beta）」：

1. 选择渠道。WebDAV 为推荐入口，OSS 保留 Beta 标识。
2. 填写连接信息，点击「测试连接」。通过表示当次登录和目录读取成功，不代表已验证写入。
3. 设置至少 12 个字符的同步密码，点击「保存并首次同步」。其他设备使用相同目录和同步密码。

访问令牌、WebDAV 应用密码用于登录存储服务；同步密码用于解密数据，无法找回。浏览器完全重启或手动锁定后，需要重新输入凭据和同步密码。

「保存配置」不执行连接测试、首次同步或开启自动同步。连接未验证时会明确显示。网络失败后本机内容保留，恢复连接后可点击「立即同步」重试；首次设置失败也可选择「仅在本机使用」。

发生冲突时，先保留本机内容。打开「查看并选择版本」，核对影响范围，再选择「保留本机版本」或「采用云端版本」。选择以界面列明的整组内容为单位，不会把两个版本的字段自动拼在一起。

## 备份与恢复

1. 打开「设置 → 数据 → 备份与恢复中心」，点击「导出完整备份」。
2. 恢复时点击「选择备份文件」，核对类别和数量。
3. 选择「添加新内容，保留已有内容」或「替换所选类别」，确认后点击「开始恢复」。替换模式下，备份中的空类别也会清空对应内容。

完整备份包含导航、文件夹、外观、便笺、稍后读、桌面方案、别名、隐私标记，以及引用的本地图片。登录凭据、同步连接和密码不进入完整备份。导出的 JSON/ZIP 文件未加密，包含私人内容，请妥善保管。

关闭预览不会恢复数据。损坏文件不能执行恢复；其他标签页已修改数据时，需要重新预览。恢复前会保留当前浏览器副本，可在恢复中心查看。

已开启同步时，恢复后的内容也可能同步到其他设备；操作前先核对恢复范围。

测试范围与未覆盖项目见[收口记录](verification/0.3-closeout.md)。

# Covelet 0.3.1 使用说明

本文适用于 **0.3.1**。解压版构建目录为 `app/dist/extension/`。更新已加载的扩展后，重新打开新标签页。发行包和商店状态见[发布状态](store/发布状态.md)。

## 首页与导航

- 新安装的桌面为空，点击右上角「添加网站」添加自己的网址。
- 时间、日期显示在搜索框上方。打开「设置 → 时间与日期」可更改时区，或关闭农历和星座。时区默认跟随系统。「设置 → 外观 → 极简模式」可隐藏整块时间和日期。
- 搜索框可以搜索导航、便笺和稍后读，也可以输入网址。方向键选择本机结果，Enter 打开，Escape 收起。
- 将一个网站拖到另一个网站上可建立文件夹，再拖入其他网站。打开文件夹后，右键点击网站，选择「移到桌面」。
- 点击文件夹名称可以改名，Enter 保存，Escape 撤销本次名称修改；再次 Escape 关闭文件夹。
- 右键进入「编辑布局」后可整理位置，保存后保留；取消会放弃本次布局调整。
- 右键点击桌面空白处，选择「导入网址与书签 HTML」。

旧时钟组件不再出现在桌面和扩展目录中，旧配置、计时数据及备份仍保留。

## 自备存储同步

打开「扩展 → 自备存储同步」。

1. 选择渠道。推荐使用 WebDAV。
2. 填写连接信息，点击「测试连接」。右下角显示测试结果。「连接通过，可读取目录」表示当次登录和目录读取成功。
3. 设置至少 12 个字符的同步密码，点击「保存并同步」。其他设备使用相同目录和同步密码。

访问令牌和 WebDAV 应用密码用于登录存储服务，使用同步密码加密后保存在本机。重启浏览器或手动锁定后，只需输入同步密码。旧配置若尚未保存加密凭据，需补填一次并完成同步。同步密码无法找回。

「仅保存」只保存连接。「目录读取」和同步结果分别显示。网络失败时，可用「重试」再次尝试。登录、权限或配置有误时，打开「修改配置」处理。首次设置时也可选择「仅在本机使用」。

「同步记录」保留当前连接最近 20 次同步的时间和结果。出现「有冲突」时，选择「以本地为准」会用本机整份同步内容替换云端当前内容。选择「以云端为准」会将本机整份同步内容替换为云端内容。之后的同步以选定的整份内容为基础。

在 GitHub 上选择「以本地为准」后，Covelet 会先上传并回读新快照，验证全部记录和图片，再切换分支上的同步文件。同步目录只留下本次恢复所需的索引、数据块和同步标记。仓库的 Git 提交历史仍保留。其他设备需更新 Covelet 后继续同步。

在「扩展 → 随机壁纸」选择 Bing 或 Wikimedia Commons，点击「设为背景」。可手动「换一张」，也可设置 5 分钟到 1 个月的自动更换间隔。默认 1 天，打开或返回 Covelet 时会检查是否到期。

同步在浏览器后台执行，可以离开 Covelet 标签页。浏览器关闭时会保留未完成的任务和已准备的加密数据。重新启动浏览器并用同步密码解锁后，任务会接续。

## 备份与恢复

1. 打开「设置 → 备份与恢复」，点击「导出备份」。
2. 恢复时点击「恢复备份」并选择备份文件。
3. 核对文件名后点击「确认恢复」。备份内容会替换当前数据。

完整备份包含导航、文件夹、外观、便笺、稍后读、别名、隐私标记，以及引用的本地图片。已有旧版桌面方案也会随完整备份保留。登录凭据、同步连接和密码不进入完整备份。导出的 JSON/ZIP 文件未加密，包含私人内容，请妥善保管。

取消确认会保留当前数据。损坏文件不能执行恢复。其他标签页已修改数据时，需重新选择备份文件。恢复前会在当前浏览器保留一份副本。

已开启同步时，恢复后的内容也可能同步到其他设备；操作前先核对恢复范围。

## 回收站与关于

在「设置 → 回收站」管理已删除的便笺和稍后读。在「设置 → 关于」查看版本更新、隐私政策和隐私自查。

测试范围与未覆盖项目见[收口记录](verification/0.3-closeout.md)。

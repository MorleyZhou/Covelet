# 命令面板：浏览器搜索与本机会话

设计日期：2026-11-25。先读取现有命令面板、结构化搜索、内容搜索和后台入口，再写本设计；权限和实现修改在本文之后进行。现有本地内容搜索及命令保持为默认来源。

## 权限理由与申请方式

新增能力使用三个 **可选权限**，不加入安装时的必需权限，不扩大主机范围：

| 权限 | 用途与理由 |
| --- | --- |
| `history` | 用户选择“历史”来源后，按输入词查询浏览器已有历史；不抓取网页、不存副本、不监听浏览活动。 |
| `bookmarks` | 用户选择“书签”来源后搜索浏览器书签；只读结果，不修改、删除或导入整个书签树。 |
| `tabs` | 这是 `history`、`bookmarks` 以外需要说明的额外权限：读取所有打开标签的标题、URL，以及保存当前窗口全部标签的链接清单。已有 `activeTab` 只临时授权当前标签，不能提供其余标签的敏感字段；不能用全站主机权限替代。 |

`tabs.update/remove/create` 以及 `windows.update({focused:true})` 只处理用户选中的标签或恢复操作。窗口 API 没有额外的 `windows` 权限要求，不增加 `sessions`、`tabGroups`、`tabCapture`、`downloads`、`webNavigation`、`scripting` 等新权限。会话是自己的链接列表，不调用浏览器关闭会话数据库，也不休眠或冻结标签。[Chrome Tabs 权限说明](https://developer.chrome.com/docs/extensions/reference/api/tabs)、[Chrome 标签管理示例](https://developer.chrome.com/docs/extensions/get-started/tutorial/popup-tabs-manager)、[Firefox 可选权限](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/optional_permissions)

切换到某个浏览器来源时先检查授权；没有授权则显示用途和“授权”按钮，由直接点击申请对应权限。输入查询、打开面板、后台启动均不弹出权限请求。拒绝或撤销权限时清空该来源的结果并提示，其余内容搜索继续可用。

## 搜索、键盘与隐私

面板提供“内容 / 标签页 / 历史 / 书签 / 会话”来源。默认内容保留 `tag:`、`type:`、`is:`、`domain:` 的既有语义，不把浏览器数据混入本地资料库、全局搜索计数或保存清单。浏览器来源按普通文字匹配标题和 URL，所有查询都在本机浏览器 API 完成。

标签结果不去重：同一 URL 的两个真实标签仍可分别切换或关闭。历史只在有查询时调用 API，查询覆盖浏览器仍保留的时间范围且有结果上限；书签只返回有效 HTTP(S) 链接，不显示无 URL 的文件夹。查询有长度、结果数和去抖限制，迟到响应不能覆盖新查询、已切换来源或已关闭的面板。关闭面板即释放浏览器结果；不建立浏览器历史/书签的持久索引。

切换标签前重新验证其 ID、窗口和 URL，再激活标签及窗口。关闭是独立、可键盘聚焦的按钮，重新核对目标，不能因搜索结果过期而关闭另一个页面。保存窗口不会关闭原标签。

上下键选择，回车执行当前结果，Esc 关闭面板；输入法组合期间及 keyCode 229 不执行提交、选择跳转或 Escape 关闭。关闭按钮、来源切换、标签关闭和会话操作均可用 Tab 键访问，不在按钮中嵌套按钮。异步错误保留面板并以可见状态提示。

默认排除隐私窗口、内部页面、扩展页面、`file:`、`data:`、`javascript:` 和带 URL 用户名/密码的链接。隐藏模式下不读取或展示这些新的浏览器来源及会话，也不泄露数量；解除隐藏后才可使用。浏览器结果不加载 favicon、页面正文或缩略图，不写入遥测、日志、导航历史或云端。

## 本机会话模型

使用新的 `covelet.browser-sessions.v1` 设备专属键，通过现有 `localData` 的 AES-GCM 设备密钥加密 IndexedDB 写入。集合有 version/revision；会话有随机 ID、记录 revision、名称、创建/更新时间以及有序的 `{url,title,pinned}` 链接数组。只保存链接元数据，不保存页面内容、Cookie、表单、截图、浏览器标签 ID 或访问凭据。

不复活 `personal-tools` 中退休的 `snapshots` 捕获/恢复入口；旧历史仍只读。新键明确从 `sync-data-rules.js` 的上传和接收边界排除，不纳入现有普通导出或完整备份，以免浏览器数据随原有内容流程外发。命名、删除、恢复均只针对用户主动创建的新会话。

保存先完整读取当前普通窗口的标签，在保存前预览可保存、重复及不支持链接的数量。HTTP(S) URL 用既有规则规范化，保留查询和片段，按规范化后的完整 URL 去重，保留首次出现的标题、顺序和固定状态。不能保存失败的部分读取结果。名称上限 80 字符；最多 50 个会话、每会话 500 个唯一链接、总共 2,000 个链接、集合 4 MiB。达到上限明确拒绝，旧会话不被自动淘汰。

保存、改名、删除使用加密存储的原子更新和预期版本检查；另一页面修改后要求重新加载，不覆盖较新结果。删除前确认，不把隐私 URL 写入普通回收站。

## 恢复与失败处理

点击恢复先生成带能力令牌的预览，显示会话名称、待打开链接、已打开或重复的链接；允许用户取消或选择部分链接。只有明确确认后才开始打开。预览绑定会话版本及所选链接，改名、删除或内容变化使旧预览失效。

每次确认最多打开 **10 个后台标签**，按顺序逐个创建，不并发打开几十个页面，不抢焦点；30 条链接需用户确认并继续三批。每批前检查普通目标窗口及现有 URL，重复的已打开链接跳过，成功创建立即记入本次进度。网络加载由浏览器正常处理，Covelet 不扫描失效链接或预取页面。

关闭预览停止后续批次，不撤销已经打开的标签。创建中途失败时显示已完成/失败/剩余数量，保留原会话；重试会重新查询已打开 URL，避免重复。跨面板并发恢复必须串行并在每次创建前检查当前实际 URL。权限撤销或目标变为隐私窗口时停止，不修改会话数据。

## 验证计划

新增单元测试覆盖保存、规范化去重、版本冲突、容量拒绝、预览取消不打开、三批恢复、已打开去重、中途失败/重试、权限拒绝与撤销、过期查询和过期标签 ID。界面测试覆盖来源切换、异步失败、键盘和中文输入法保护。

实际浏览器用隔离配置创建 30 个测试标签，通过生产面板保存、命名、预览、三批恢复，再核对 URL 集合与数量、重复恢复不新增、改名删除和重启持久化。浏览器自动交互与人工手动验证分别记录，不宣称脚本等同人工。沿用 `output/playwright/` 测试输出目录，但本轮不使用 Playwright。

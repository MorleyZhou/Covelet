# Covelet 0.4.0 功能范围

0.4.0 确定 12 项功能，集中在一个日常场景。用户把已有链接带进 Covelet，按工作、个人或项目布置桌面。打开新标签时，能直接去对应桌面、启动常用网站，再把遇到的新页面存回合适的位置。目标用户是已经有一批常用链接、每天会重复打开其中几组的人。

## 调研与取舍

功能按使用频率、与现有流程的衔接、所需权限和数据兼容成本筛选。基线是 `v0.3.1`，已有编号分页、统一搜索、书签 HTML 和粘贴导入及预览去重、工具栏保存当前页、稍后读、完整备份和可选自备存储同步。下表按用户能完成的新动作计数。 [0.3.1 使用说明](0.3使用说明.md) · [0.3.1 源码](https://github.com/MorleyZhou/Covelet/tree/v0.3.1)

## 12 项功能与验收

| 编号 | 功能 | 首版范围与验收 |
| --- | --- | --- |
| 01 | 桌面命名与搜索跳转 | 在屏幕管理给现有分页命名，搜索中出现桌面结果。输入唯一的完整桌面名并回车，跳到对应桌面。重名时列出可选结果，保留网址直达、网页搜索和中文输入法的行为。 |
| 02 | 指定新标签默认桌面 | 用户选定一个桌面作为本机新标签的起点。重开浏览器后生效，目标改名、移动后仍指向同一桌面，删除后回到第一屏。 |
| 03 | 一键打开文件夹内的网站 | 从文件夹触发，显示将打开的数量，可选要打开的站点。用户确认后按顺序打开最多 10 个可见、有效且互不重复的链接。只处理 Covelet 已保存的链接。 |
| 04 | 浏览器快捷键打开 Covelet 搜索 | 在浏览器的扩展快捷键设置中绑定按键，从当前窗口唤起 Covelet 并聚焦搜索。Chrome、Edge 实测，键位占用时可在浏览器中改绑。 |
| 05 | 按当前桌面或内容类型筛选搜索 | 现有统一搜索增加「当前桌面」导航范围和全局内容类型筛选。导航结果显示所属桌面或文件夹，同名网站能靠路径区分。隐藏条目的名称和路径遵循现有隐藏规则。 |
| 06 | 工具栏收藏到指定位置 | 从网页点扩展按钮时，可把当前页存到选定桌面或文件夹，保存后在目标位置可见。若目标已删除或被隐藏，提示重选。 |
| 07 | 把稍后读加入桌面 | 从一条稍后读记录选择「添加到桌面」和目标位置，建立导航链接。保留原记录及其阅读状态，隐藏条目生成的链接继承隐藏标记。 |
| 08 | 多选移动或复制网站 | 在布局编辑中选中多个网站，用菜单移动或复制到目标桌面或文件夹。跨桌面复制可用于同一网站的多个用途。同一目标中的重复项先提示，取消或撤销时恢复原布局。 |
| 09 | 调整桌面顺序 | 在屏幕管理用按钮前移或后移整屏，重开后顺序正确。桌面名称、默认桌面、所属网站和文件夹随原屏保留，编辑中的调整可撤销。 |
| 10 | 首次打开引导 | 在空桌面提供「添加常用网站」「导入书签」「空白开始」。沿用已有导入预览，记住空白开始的选择。目标是新用户能在约一分钟内放入 3 个真实常用站点。 |
| 11 | 导入 Markdown 链接文件 | 读取用户选的 `.md` 文件，把标题下的 HTTP(S) 链接分组，沿用导入预览、选项、去重和确认。使用真实格式样本验证 Arc 导出兼容后再标注支持范围。Arc 的官方导出按 Space 列出 Markdown 链接。 [Arc 导出说明](https://resources.arc.net/hc/en-us/articles/25583851606039-How-Do-I-Export-My-Data-from-Arc) |
| 12 | 导出书签 HTML | 可导出一个桌面、一个文件夹或全部导航。文件在离线环境生成，只含网站名称、URL 和分组。即使已经解锁，导出范围也排除标记为隐藏的内容。生成的文件可导入 Chrome 和 Edge。 |

## 开发顺序与发布验收

1. 先做 **01、02、03、10**。用一个真实项目桌面验证从首次布置到每天启动的完整流程。
2. 再做 **04、05、06、07**。让键盘搜索、收藏和稍后读衔接同一套桌面与文件夹选择器。
3. 最后做 **08、09、11、12**。用多桌面、大书签文件和含重复项的样本验证整理及迁移。

各项在独立功能分支开发并合回 `feature/0.3.2-for-0.4`。整批验收后使用 `0.4.0` 正式版本号。 [分支与发布流程](store/release-ci.md)

- **数据兼容。** 用真实解压安装验证 0.3.1 原地升级、旧版备份恢复和混合版本同步。桌面名称、默认桌面与排序绑定逻辑桌面，缩放产生的临时分页不改变归属。遇到不兼容的数据格式要能安全停下，并保全两端数据。
- **权限与界面。** 整批运行单元测试、浏览器测试和扩展包检查。Chrome、Edge 都加载实际解压包，确认新增路径沿用现有权限。批量启动通过用户确认后的 `tabs.create()` 创建标签页。隐私验证覆盖搜索、导入、复制、批量打开和导出。检查八种语言及 390×540、1280×620 下的浅色、深色和键盘操作。 [Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs#permissions) · [快捷键 API](https://developer.chrome.com/docs/extensions/reference/api/commands) · [产品验收清单](产品验收checklist.md)
- **试用。** 邀请 5–8 位已有常用书签的人，用自己的链接完成一次布置、切屏、打开一组和收藏。记录首次完成时间，一周后回访他们实际重复的动作。用观察和自愿反馈核对可发现性与使用价值。

## 后续候选

- **直接导入浏览器书签。** 等试用确认 HTML 导出步骤是主要流失点，再评估一次性授权。Chrome 的 `bookmarks` 权限提示包含读取和修改书签。 [Chrome 权限提示](https://developer.chrome.com/docs/extensions/reference/permissions-list#bookmarks)
- **Infinity 和 WeTab 专用迁移。** 取得可再分发的当前版本样本，再评估格式兼容。已有 Infinity 调研只验证了社区转换器读取的一种结构，WeTab 格式尚待样本。 [Infinity 调研](spikes/2026-10-31-infinity-import.md) · [WeTab 调研](spikes/2026-10-31-wetab-import.md)
- **密码加密的完整备份。** 另立可移植备份项目，验证版本化文件格式、错密码和损坏文件处理，以及离线恢复。0.4 的书签 HTML 解决导航迁移，完整备份由现有入口承担。 [备份与恢复说明](0.3使用说明.md#备份与恢复)

# 核心扩展与组件 · 0.2.2

包内目录仅有五项：时钟、便笺、稍后读、GitHub 贡献、自定义存储同步。前四项可放到桌面；同步为功能设置。组件中心只管理介绍、非交互预览、尺寸及添加／移除，工作区由桌面打开。移除组件保留内容。

时钟含世界时钟、时区对照、倒计时和秒表，无专用闹钟。倒计时使用 alarms，通知需可选授权。GitHub 组件读取所选用户的公开贡献日历，逐来源授权并缓存，普通目录预览不发网络请求。便笺与手动稍后读使用本机加密存储，支持独立导出与合并导入。

自选存储同步默认关闭，使用独立密码加密业务数据和图片；浏览器原生同步停用。详见[同步协议](自定义存储同步.md)。17 项扩展工具包、标签快照、浏览器阅读清单导入及所有入口不属于 A+。已有历史记录保留以兼容保存／导出，不重新开放操作。

所有模块和五个 WASM 核心随包提供，不下载执行代码。八种语言保留。权限以 [manifest](../app/extension.manifest.json) 和[隐私说明](隐私说明.md)为准。0.2.2 是尚未提交的候选，Chrome 线上为 0.2.0。

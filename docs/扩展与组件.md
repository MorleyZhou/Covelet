# 扩展与组件

2026-10-21 开发迭代。此页覆盖先前“扩展中心为空”“自定义存储同步放在增强”的约定。本轮只改功能，未运行测试、检查、构建或浏览器验收；具体范围见[开发改动](开发改动-2026-10-21.md)。

## 分类和入口

设置按钮左侧的扩展入口默认展示“全部扩展”，按用途提供“开发工具”“时间工具”“记录与阅读”“浏览管理”“数据同步”分类。桌面组件和功能扩展是使用形式，只作为条目属性，不作为目录分类；不列空分类或未实现的产品。

| 使用形式 | 使用方式 | 当前内容 |
| --- | --- | --- |
| 组件型 | 配置后在桌面展示；点击打开工具，右键配置或移除 | GitHub 贡献、时钟、便笺、稍后读 |
| 功能型 | 在扩展详情管理，不生成桌面组件 | 自定义存储同步、标签快照 |

“增强”仍在设置中，用一个“视觉增强”开关统一控制壁纸界面配色、局部导航文字明暗和图标视觉适配，作为免费基础能力。扩展延续 6 美元／年的订阅产品方向；本轮按用户要求暂缓账号、支付和部署，开发版尚未实现付费校验，不显示虚构的购买、登录或解锁结果。

## GitHub 贡献组件

1. 扩展 → 全部扩展／开发工具 → GitHub 贡献，填写 GitHub 用户名，选择迷你／小／中／大尺寸后点击“使用”。不填 GitHub 访问令牌，也不登录 GitHub。
2. 正式扩展在该点击中申请 `https://github.com/*` 的精确来源访问。拒绝时保留表单且不保存新组件；从其他设备同步配置不会自动申请权限，用户可在组件刷新操作中授权。
3. 尺寸统一按“行 × 列”：迷你 1×1、小 2×2、中 2×4、大 4×4，与图标、文件夹共用方形网格。最新外观参考用户提供的 iOS GitHub 小组件：整张卡片以热力图为主体，移除内部标题、总数、统计、图例及日期栏。格子为轻圆角正方形、等比例间距与柔和绿阶，随实际可用宽高自动选取最近的完整星期列；迷你／小／中为七行，大为两段七行。未到的日期仅作为低对比留白位置，不伪造贡献记录。下方组件名称保留并遵循显示名称设置。
4. 不再提供时间范围设置，展示量由尺寸和实际空间决定。缩放、调整列数或切换尺寸只裁切内存中的完整日历，不额外请求 GitHub、不重新调用 WASM，也不改写用户配置。每屏四行，默认八列，可调 2–12 列；窄窗口自适应不覆盖保存偏好。
5. 格子悬停提供原生日期／贡献数提示；键盘左右移动一周、上下移动一天，Home／End 跳至当前可见首末日期。常态不画选中框，键盘焦点仍可见。刷新按钮在悬停、焦点或错误时显示，刷新及错误不改变卡片排版；读取失败仍保留有效缓存，不把失败呈现为真实的零贡献日历。
6. 通过组件空白区或布局编辑模式自由拖动，保留完整尺寸的冻结跟手预览；组件不能放入文件夹或叠放建文件夹。右键提供“打开”对应 GitHub 个人页、“配置组件”“移除组件”，Shift+F10 同样可打开；移除可以撤销。
7. 用户名、尺寸和行列位置通过正常配置保存，并随 ZIP 及已开启的同步传播。旧的合法 `range` 字段仍可读取和校验，但展示不再使用；不在加载时写回或删除数据，用户下一次明确保存组件配置时省略它。组件 ID、布局、缓存与同步协议保持原范围。没有默认示例组件，不为新安装用户预填测试账号。

此轮热力图调整仅修改宿主源码与说明，未运行测试、静态检查、构建或浏览器验收；既有 WASM 二进制不变。扩展详情预览和桌面复用相同热力图布局。

这里显示的是 GitHub 个人页的**贡献**，包含符合 GitHub 规则的提交及其他贡献活动，不能等同于所有 Git 提交次数；也可能包括用户主动公开显示的私有贡献数量，不读取私有仓库详情。[GitHub 贡献说明](https://docs.github.com/en/account-and-profile/concepts/contributions-on-your-profile)、[贡献统计规则](https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference)

## 数据和运行边界

- 请求地址固定为 `https://github.com/users/{经过校验的用户名}/contributions`。不携带 Cookie、Referer、访问令牌；不跟随重定向，不读取其他来源或页面中的链接、脚本、图片。
- 该地址来自 GitHub 自己的公开页面，当前可读取，但不是承诺稳定性的官方数据 API。GitHub GraphQL 有正式的贡献日历类型，需要另行认证；本轮未加入该认证方案。[GraphQL 类型](https://docs.github.com/en/graphql/reference/users)、[认证说明](https://docs.github.com/en/enterprise-cloud@latest/graphql/guides/forming-calls-with-graphql)
- HTML 只作为文本解析日历日期、贡献数和等级，不进入 DOM。请求期限 12 秒，响应最多 512 KiB，完整日历接受 350 至 378 个连续日期；格式变化、用户不存在、权限拒绝或部分响应均报错，不伪造零贡献。
- 正常缓存一小时，强制刷新最短间隔一分钟。失败保留上一份有效日历；缓存最多八个用户名，仅存本机，既不进入 ZIP 也不进入同步。页面不可见时不主动刷新，移除组件后停止该组件的定时刷新。
- `github-core.wasm` 随安装包提交，计算星期对齐、总贡献、活跃天数和连续贡献等统计，大小 1,202 字节、零宿主导入、固定 512 KiB 内存。浏览器宿主负责权限、网络、缓存和 React 界面；没有远程模块下载、上传 WASM 或通用执行入口。
- 开发网页使用 Vite 的固定 `/__github/users/{用户名}/contributions` 本地代理帮助预览。该代理只接 GitHub 日历路径，剥离 Cookie、Origin、Referer 和响应 Set-Cookie；不进入生产扩展。网页预览不能证明安装扩展后的权限行为。
- 保留既有 v1 数据封装和同步协议，新增严格校验的 `widget` 条目。新版能读取旧配置；不支持组件的旧构建可能拒绝含组件的新数据，需要升级后再同步／恢复，不宣称旧构建已兼容。

## 时钟组件

从“时间工具 → 时钟”选择迷你 1×1／小 2×2／中 2×4／大 4×4、指针／数字、桌面时区和 1–8 个世界时钟。桌面只展示时间，点击打开时钟、世界时钟、时区对照、倒计时、计时五个页签，按所选日期处理夏令时的缺失／重复时间。独立闹钟仍移除，旧模式及计划按原规则清理；关闭弹窗不停止计时或倒计时。保留 Esc、焦点返回、拖拽／多选和独立门户事件处理。

`clock-core.wasm` 固定随包提供，计算已用／剩余时间与表针角度，零宿主导入、无远程模块入口。浏览器宿主负责系统时间、React 界面、本机持久化、权限和提醒。当前时间、倒计时／计时运行状态和通知开关不进入 ZIP 或任何配置同步；仅组件样式、尺寸和位置可移植。

视觉增强统一控制时钟和 GitHub 组件的背景：本地 WASM 分析组件下方壁纸，显示带壁纸色调的半透明底色及匹配的文字、表针和贡献色阶；桌面表盘不再套固定白色内盘。支持全部尺寸、拖动位置和切屏，关闭增强恢复主题底色。此显示结果不写入配置，不额外请求图片。

正式扩展按需申请通知权限，并用 `chrome.alarms` 在浏览器运行时调度，重启后重建有效计划。浏览器可能延迟提醒且不会唤醒休眠设备，不承诺系统精确闹钟；开发网页仅在页面打开时提醒。相关行为尚未在安装扩展中验收。[Chrome alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms)

## 功能型同步

自定义存储同步沿用现有 WASM、网络适配器及会话密钥管理，本轮只迁移入口，不重置用户已保存的连接。保存配置不代表连接成功；解锁、真实同步、错误、冲突和待上传记录依照既有控制器处理。功能型不会在主界面生成同步卡片。[自定义存储同步](自定义存储同步.md)

当前只接受包内登记的 GitHub 贡献、时钟、便笺、稍后读、自定义存储同步、标签快照六项扩展，名称和配置不构成代码注册机制。世界时钟／时区对照已加入时钟弹窗，闹钟仍移除；同步支持版本浏览与选择性恢复。工具内容仅本机，可独立导出／导入。最新实现、权限与历史兼容边界见[扩展升级与本机工具](扩展升级与本机工具-2026-10-21.md)，本次不更新线上商店或隐私页。

## 扩展窗口与主屏幕排版

扩展窗口参考 App Store 的紧凑应用目录，宽窗口并排显示多个条目，每项只保留图标、名称、简介、属性和胶囊操作；取消目录中的大海报和预览卡片。仅一个条目时也保持原列宽，不自动拉满内容区。宽窗口使用用途分类侧栏，窄窗口使用分段分类控件和单列条目。

搜索在当前分类内匹配名称、用途、使用形式和关键词，例如 WebDAV、R2、绿点；全部在本地完成。切换分类清空搜索，详情返回保留原搜索和入口焦点；有搜索词时 Escape 先清空搜索。分类支持方向键及 Home／End。仅展示实际已提供的扩展，不添加评分、下载量、排行或占位产品。

详情将介绍和配置放在同一页，GitHub 的组件预览默认折叠，按需展开；正文滚动时保留标题、返回和底部操作。目录窗口缩至 560px 高，长配置详情仍可独立滚动。

GitHub 详情中的折叠预览是安装包内固定的公开数字快照（`torvalds`，2026-10-20），由同一包内 WASM 和日历组件渲染。浏览目录、搜索和查看预览不请求 GitHub，不创建桌面条目，也不预填用户名；真实组件仍由用户显式配置和使用。快照来源为 `https://github.com/users/torvalds/contributions`，367 天、3,762 次贡献；预览使用完整快照，与尺寸不绑定日期范围。

图标、文件夹和组件统一使用网格轨道与间距，组件名称位于下方并跟随“显示名称”设置。中、大组件宽度相同，可保存独立行列位置和空格；先保留显式位置，再安置尚未定位的条目，发生碰撞时仅迁移受影响项。DOM 按显示位置排序，不用 dense 回填改变阅读顺序，不增加整块导航背景。少列布局收拢网格；组件内保留滚动、控件和键盘焦点。

## 主屏幕分页与初始导航

- 圆点、左右按钮、聚焦主屏后的方向键及 Home／End 可切屏；支持滚轮、鼠标与触摸横向滑动。拖拽过程中滚轮也切屏，普通组件内部滚动优先。添加一屏只在编辑布局时提供，显式空白屏可以保存。
- 拖至分页圆点或屏幕边缘可跨屏移动，停留边缘后可切换到目标屏继续排放。中心叠放仍建文件夹，边缘排序；组件只能留在主屏幕。
- 添加网站位于右上角，不再占网格单元。添加、使用组件和拖动后显示条目所在屏；设置中的书签导入保留。
- 新安装及 `?demo` 预置 Google、YouTube、GitHub、X、ChatGPT、Grok 六个普通网址，可编辑、删除、撤销；已有配置、恢复和同步不重新补入。默认图标使用随包提供的官网高清图片，来源记录随源码提供，不增加网站内容权限。
- `entry.page` 为可选的 0–1999 整数，缺省为第一屏；`entry.position` 保存零起始的 row（0–3）和 column（0–11）。保留 v1 封装及迁移；窄窗溢出只是显示结果，不自动重写配置，主动编辑时才固化显示位置。未保存的编辑草稿不进入备份或同步，已保存的显式空屏属于普通配置。
- 页面位置与尺寸随普通本地、ZIP、原生／自定义存储配置同步。初始默认条目的删除在首次启用同步前也可形成删除记录；新设备的未修改默认条目不能覆盖并发的用户编辑，冲突仍可恢复。
- 较矮窗口收紧时间、图标和组件内部排版，保留分页与名称之间的空间。默认大小、间距、宽度仍是保存偏好。旧构建的严格校验可能拒绝含新页面字段的数据，需要升级后再恢复或同步。

## 布局编辑和删除屏幕

导航区域长按左键或右键提供“编辑布局”，普通图标菜单也能进入。图标与组件轻微晃动，减少动态效果时禁用动画；普通点击／触摸或空格键增减选择，无需 Shift，选中仅显示蓝色勾选标记。可批量拖动，用叠层、数量及冻结的组件画面反馈。普通单项拖拽和叠放文件夹仍可直接使用。极简模式已移除，旧字段仅兼容读取并关闭。

编辑先保存在内存草稿，Enter／完成提交，Esc／取消放弃未保存布局；无常驻保存进度，真实保存失败和其他页面的修订冲突仍提示。编辑期间暂停普通搜索、添加网站及组件内控件的交互，避免跳页或绕过草稿保存；退出后恢复。

完成按钮右侧为垃圾桶区域，可拖入或点击后确认删除所选项。默认焦点在取消，确认仅修改草稿，取消编辑可恢复；文件夹包含的网站数量明确显示。时钟运行状态和提醒仅在提交成功后清理；删除屏幕只撤下组件，不触发这类清理。

屏幕管理显示实际布局缩略图，可前往、添加或删除，至少保留一屏。新增 `settings.pages`（非空、去重、最多 2000 项，值为 0–1999）记录显式屏幕，随正常配置备份和同步。进入编辑时将显示中的溢出屏固化为独立屏幕；一般窗口变化仍不自动写回布局。

删除屏幕时，网站和整个文件夹按阅读顺序追加到最后一屏最后一个导航之后，跳过已有组件，尾部满后续屏；保留网址、文件夹关系、ID 和图标设置。原屏组件设置为 `detached:true`，不再参与布局或占用页面，但保留原 ID、配置、本机时钟状态及原缓存。扩展目录重新显示“使用”，表单沿用原配置，放回时复用原记录。时钟的后台计划也继续归属于原记录，删屏不执行组件数据清理；贡献缓存仍按既有上限和失效规则处理。

此轮没有新增网络、权限或 WASM 模块；保存后沿用既有本地、备份和同步流程。含 `pages`／`detached` 的新配置需要支持这些字段的构建读取。本轮按用户要求未运行测试、检查、构建或浏览器验收。

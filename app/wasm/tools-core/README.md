# Covelet tools core

包内 Rust `no_std` 运算模块。无依赖、无网络或宿主导入；宿主负责 Chrome 权限、持久化、原生时区数据库与 React 界面。没有下载、注册或上传用户代码的入口。

- 便笺：UTF-8 字符／行数统计、本地文字匹配。
- 稍后读：本地标题／网址匹配。
- 标签快照：完整网址去重，保留首次出现的顺序，不删除查询参数或片段。
- 同步历史：UTF-8 公共前后缀差异，用于高亮修改；因果合并、签名及摘要继续使用 `sync-core.wasm`。

ABI 1，编译参数声明固定 1 MiB 线性内存。双输入区各 256 KiB，结果区 2048 个 u32；宿主使用重叠分块处理扩展后的 Unicode 文本，按批处理长网址，并在每次调用后清空输入和输出。模块内部不保存用户数据。浏览器宿主验证记录类型、数量、长度和恢复修订，不把 WASM 当成权限或持久化的替代。

本地已安装的 Rust 1.85.1 / `wasm32-unknown-unknown` 可生成资源：

```powershell
node scripts/build-tools-wasm.mjs --generate
```

此模式只生成 `src/wasm/tools-core.wasm` 和源码／二进制摘要，不运行模块检查、单元测试、应用构建或浏览器验收。另有 `--check` 供后续明确要求的构建使用；本轮没有运行它。
